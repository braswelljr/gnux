---
title: "-r, --reference"
description: "Display the last modification time of FILE."
---

An option of [datex](/docs/tools/datex).

## Usage

```bash
datex -r FILE [+FORMAT]
datex --reference=FILE [+FORMAT]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-r` | `--reference` | `FILE` |  | display the last modification time of FILE |

## Examples

### Print a file's modification time

```bash tab="bash" tab-group="shell"
datex -r report.txt
```

```powershell tab="PowerShell" tab-group="shell"
datex -r report.txt
```

## Help in the terminal

```bash
gnux help datex --reference
```
