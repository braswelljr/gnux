---
title: "--resolution"
description: "Output the available resolution of timestamps."
---

An option of [datex](/docs/tools/datex).

## Usage

```bash
datex --resolution [+FORMAT]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--resolution` | none |  | output the available resolution of timestamps |

## Examples

### Check how finely this system's clock measures time

```bash tab="bash" tab-group="shell"
datex --resolution
```

```powershell tab="PowerShell" tab-group="shell"
datex --resolution
```

## Help in the terminal

```bash
gnux help datex --resolution
```
