---

An option of [datex](/docs/tools/datex).

## Usage

```bash
datex -f DATEFILE [+FORMAT]
datex --file=DATEFILE [+FORMAT]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-f` | `--file` | `DATEFILE` |  | like --`date`; once for each line of DATEFILE |

## Examples

### Convert a list of dates

```bash tab="bash" tab-group="shell"
datex -f dates.txt +%s
```

```powershell tab="PowerShell" tab-group="shell"
datex -f dates.txt +%s
```
