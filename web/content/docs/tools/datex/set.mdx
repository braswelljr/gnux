---
title: "-s, --set"
description: "Set time described by STRING (not supported)."
---

An option of [datex](/docs/tools/datex).

## Usage

```bash
datex -s STRING [+FORMAT]
datex --set=STRING [+FORMAT]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-s` | `--set` | `STRING` |  | set time described by STRING (not supported) |

## Examples

### Print an ISO 8601 timestamp to the second

```bash tab="bash" tab-group="shell"
datex -Iseconds
```

```powershell tab="PowerShell" tab-group="shell"
datex -Iseconds
```

## Help in the terminal

```bash
gnux help datex --set
```
