---
title: "-u, --utc"
description: "Print or set Coordinated Universal Time (UTC)."
---

An option of [datex](/docs/tools/datex).

## Usage

```bash
datex -u [+FORMAT]
datex --utc [+FORMAT]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-u` | `--utc` | none |  | print or set Coordinated Universal Time (UTC) |

## Examples

### Print the time in UTC

```bash tab="bash" tab-group="shell"
datex -u
```

```powershell tab="PowerShell" tab-group="shell"
datex -u
```

### Convert epoch seconds to a date

```bash tab="bash" tab-group="shell"
datex -u -d @1700000000
```

```powershell tab="PowerShell" tab-group="shell"
datex -u -d '@1700000000'
```

gnux help datex --utc
