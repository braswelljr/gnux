---
title: "--rfc-3339"
description: "Output date/time in RFC 3339 format. FMT='date', 'seconds', or 'ns'."
---

An option of [datex](/docs/tools/datex).

## Usage

```bash
datex --rfc-3339=FMT [+FORMAT]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--rfc-3339` | `FMT` |  | output `date`/time in RFC 3339 format. FMT='`date`', 'seconds', or 'ns' |

## Examples

### Produce a timestamp an API expects in RFC 3339

```bash tab="bash" tab-group="shell"
datex --rfc-3339=seconds
```

```powershell tab="PowerShell" tab-group="shell"
datex --rfc-3339=seconds
```
