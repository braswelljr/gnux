---
title: "-I, --iso-8601"
description: "Output date/time in ISO 8601 format. FMT='date' for date only (the default), 'hours', 'minutes', 'seconds', or 'ns'."
---

An option of [datex](/docs/tools/datex).

## Usage

```bash
datex -I [+FORMAT]
datex --iso-8601[=FMT] [+FORMAT]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-I` | `--iso-8601` | `FMT` (optional) |  | output `date`/time in ISO 8601 format. FMT='`date`' for `date` only (the default), 'hours', 'minutes', 'seconds', or 'ns' |

## Examples

### Print the date in ISO 8601

```bash tab="bash" tab-group="shell"
datex -I
```

```powershell tab="PowerShell" tab-group="shell"
datex -I
```

### Print an ISO 8601 timestamp to the second

```bash tab="bash" tab-group="shell"
datex -Iseconds
```

```powershell tab="PowerShell" tab-group="shell"
datex -Iseconds
```

## Help in the terminal

gnux help datex --iso-8601
