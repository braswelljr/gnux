---
title: "-A, --apparent-size"
description: "Print apparent sizes rather than device usage."
---

An option of [dux](/docs/tools/dux).

## Usage

```bash
dux -A [FILE]...
dux --apparent-size [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-A` | `--apparent-size` | none |  | print apparent sizes rather than device usage |

## Examples

### Spot a sparse VM disk image: it takes far less space than its size

```bash tab="bash" tab-group="shell"
dux -h vm.qcow2 && dux -h --apparent-size vm.qcow2
```

```powershell tab="PowerShell" tab-group="shell"
dux -h vm.vhdx; dux -h --apparent-size vm.vhdx
```

```text title="Output"
2.1G	vm.qcow2
40G	vm.qcow2
```
