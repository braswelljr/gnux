---
title: "--files0-from"
description: "Summarize device usage of the NUL-terminated file names specified in file F; if F is -, then read names from standard input."
---

An option of [dux](/docs/tools/dux).

## Usage

```bash
dux --files0-from=F [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--files0-from` | `F` |  | summarize device usage of the NUL-terminated file names specified in file F; if F is -, then read names from standard input |

## Examples

### Measure a list of paths produced by another program

```bash tab="bash" tab-group="shell"
find . -name '*.log' -print0 | dux -ch --files0-from=-
```

```powershell tab="PowerShell" tab-group="shell"
dux -ch --files0-from=paths.lst
```
