---
title: "-x, --one-file-system"
description: "Skip directories on different file systems."
---

An option of [dux](/docs/tools/dux).

## Usage

```bash
dux -x [FILE]...
dux --one-file-system [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-x` | `--one-file-system` | none |  | skip directories on different file systems |

## Help in the terminal

```bash
gnux help dux --one-file-system
```
