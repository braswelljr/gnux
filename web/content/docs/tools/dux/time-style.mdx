An option of [dux](/docs/tools/dux).

## Usage

```bash
dux --time-style=STYLE [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--time-style` | `STYLE` |  | show times using STYLE, which can be: full-iso, long-iso, iso, or +FORMAT |

## Help in the terminal

```bash
gnux help dux --time-style
```
