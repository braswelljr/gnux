---
title: "--preserve-status"
description: "Exit with the same status as COMMAND, even when the command times out."
---

An option of [timeoutx](/docs/tools/timeoutx).

## Usage

```bash
timeoutx --preserve-status [OPTION] DURATION COMMAND [ARG]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--preserve-status` | none |  | exit with the same status as COMMAND, even when the command times out |

## Examples

### Keep the command's own exit status after a timeout

```bash tab="bash" tab-group="shell"
timeoutx --preserve-status 1m ./bench.sh
```

```powershell tab="PowerShell" tab-group="shell"
timeoutx --preserve-status 1m .\bench.ps1
```

## Help in the terminal

```bash
gnux help timeoutx --preserve-status
```
