---
title: "-i, --input"
description: "Adjust standard input stream buffering to MODE."
---

An option of [stdbufx](/docs/tools/stdbufx).

## Usage

```bash
stdbufx -i MODE OPTION... COMMAND [ARG]...
stdbufx --input=MODE OPTION... COMMAND [ARG]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-i` | `--input` | `MODE` |  | adjust standard input stream buffering to MODE |

## Help in the terminal

```bash
gnux help stdbufx --input
```
