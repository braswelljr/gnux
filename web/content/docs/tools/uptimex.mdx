title: "uptimex"

---

Mirrors GNU `uptime`. Run it as `uptimex`, or as `gnux uptimex`.

## Synopsis

```bash
uptimex [OPTION]... [FILE]
```

## GNU reference

- [GNU coreutils manual: uptime invocation](https://www.gnu.org/software/coreutils/manual/html_node/uptime-invocation.html)
- [Source: src/uptime.c in coreutils/coreutils](https://github.com/coreutils/coreutils/blob/master/src/uptime.c)

## Description

`uptimex` prints, on one line, the current time, how long the system has been up, how many users are logged in, and the load averages: the average number of processes running or waiting to run over the last 1, 5 and 15 minutes (on Linux, processes waiting on disk count too). A load average above the number of CPUs (`nprocx`) means work is queuing. With FILE, the users and the boot time are read from that utmp file instead of the current records. The boot time comes from /proc on Linux, kern.boottime on macOS and FreeBSD, and the tick count on Windows, where the users are the signed-in sessions; Windows keeps no load average, so that part is left out there, as GNU `uptime` leaves it out wherever the system cannot report it. If the boot time cannot be found the time up is shown as '????' and the exit status is 1.

## Permissions

Needs no permissions.

## Use cases

- Checking whether a server rebooted unexpectedly.
- Seeing at a glance whether a machine is overloaded.
- Recording `uptime` and load in monitoring logs.
- Comparing the load with the CPU count before starting a heavy job.
- Getting the same summary on Linux, macOS and Windows.

## Flags

```text
      --help      display this help and exit
      --version   output version information and exit
```

## Examples

### Check how long the machine has been up and how loaded it is

```bash tab="bash" tab-group="shell"
uptimex
```

```powershell tab="PowerShell" tab-group="shell"
uptimex
```

```text title="Output"
 14:03:22  up 3 days  3:19,  2 users,  load average: 0.42, 0.37, 0.31
```

### A server feels slow: compare the load with the number of CPUs

```bash tab="bash" tab-group="shell"
uptimex && nprocx
```

```powershell tab="PowerShell" tab-group="shell"
uptimex; nprocx
```

```text title="Output"
 10:12:40  up 41 days  2:07,  1 user,  load average: 15.83, 14.90, 12.02
8
```

### Did the server reboot overnight? Check the time up

```bash tab="bash" tab-group="shell"
uptimex
```

```powershell tab="PowerShell" tab-group="shell"
uptimex
```

```text title="Output"
 07:58:01  up  2:11,  0 users,  load average: 0.08, 0.05, 0.01
```

### Log the load every 5 minutes from cron

```bash tab="bash" tab-group="shell"
*/5 * * * * uptimex >> /var/log/load.log
```

```powershell tab="PowerShell" tab-group="shell"
uptimex >> load.log
```

### Extract just the 1-minute load average

```bash tab="bash" tab-group="shell"
uptimex | trx -s ' ' | cutx -d, -f4 | cutx -d: -f2
```

```powershell tab="PowerShell" tab-group="shell"
((uptimex) -split 'load average: ')[1].Split(',')[0]
```

```text title="Output"
 0.42
```

### Show the boot time itself rather than the time since

```bash tab="bash" tab-group="shell"
whox -b
```

```powershell tab="PowerShell" tab-group="shell"
whox -b
```

```text title="Output"
         system boot  Oct  9 10:44
```

### Read the users and boot time from a saved utmp file

```bash tab="bash" tab-group="shell"
uptimex /var/run/utmp
```

```powershell tab="PowerShell" tab-group="shell"
uptimex
```

### Wait until the load drops below 1 before starting a backup

```bash tab="bash" tab-group="shell"
until uptimex | grep -q 'load average: 0\.'; do sleepx 60; done; ./backup.sh
```

```powershell tab="PowerShell" tab-group="shell"
while (-not ((uptimex) -match 'load average: 0\.')) { sleepx 60 }; .\backup.ps1
```

### Record the uptime in a status report

```bash tab="bash" tab-group="shell"
echox "$(hostnamex): $(uptimex)" >> status.txt
```

```powershell tab="PowerShell" tab-group="shell"
"$(hostnamex): $(uptimex)" >> status.txt
```

### Check several machines' uptime over SSH

```bash tab="bash" tab-group="shell"
for h in web1 web2 db1; do ssh "$h" uptimex; done
```

```powershell tab="PowerShell" tab-group="shell"
foreach ($h in 'web1','web2','db1') { ssh $h uptimex }
```

### Show the uptime in the portable gnux shell, the same on every OS

```bash tab="bash" tab-group="shell"
gnux shell -c 'uptimex && whox -q'
```

```powershell tab="PowerShell" tab-group="shell"
gnux shell -c 'uptimex && whox -q'
```

## Exit status

| Status | Meaning |
|--------|---------|
| 0 | success: every operand was processed |
| 1 | failure: an operand could not be processed (diagnosed on standard error), or a command-line mistake |
