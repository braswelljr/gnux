---
title: "--check-order"
description: "Check that the input is correctly sorted, even if all input lines are pairable."
---

An option of [joinx](/docs/tools/joinx).

## Usage

```bash
joinx --check-order FILE1 FILE2
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--check-order` | none |  | check that the input is correctly sorted, even if all input lines are pairable |

## Examples

### Fail at the first line out of order

```bash tab="bash" tab-group="shell"
joinx --check-order a.txt b.txt || echox 'not sorted'
```

```powershell tab="PowerShell" tab-group="shell"
joinx --check-order a.txt b.txt; if ($LASTEXITCODE -ne 0) { 'not sorted' }
```
