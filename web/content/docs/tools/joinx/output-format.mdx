---
title: "-o, --output-format"
description: "Obey FORMAT while constructing output line."
---

An option of [joinx](/docs/tools/joinx).

## Usage

```bash
joinx -o FORMAT FILE1 FILE2
joinx --output-format=FORMAT FILE1 FILE2
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-o` | `--output-format` | `FORMAT` |  | obey FORMAT while constructing output line |

## Examples

### Full outer join, filling missing fields with NULL

```bash tab="bash" tab-group="shell"
joinx -a 1 -a 2 -e NULL -o auto a.txt b.txt
```

```powershell tab="PowerShell" tab-group="shell"
joinx -a 1 -a 2 -e NULL -o auto a.txt b.txt
```

### Choose the output fields

```bash tab="bash" tab-group="shell"
joinx -o 1.2,2.3,0 a.txt b.txt
```

```powershell tab="PowerShell" tab-group="shell"
joinx -o 1.2,2.3,0 a.txt b.txt
```
