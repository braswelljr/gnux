An option of [joinx](/docs/tools/joinx).

## Usage

```bash
joinx -v stringArray FILE1 FILE2
joinx --only-unpaired=stringArray FILE1 FILE2
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-v` | `--only-unpaired` | `stringArray` |  | like `-a` FILENUM, but suppress joined output lines |

## Examples

### Find the tasks in the full list that are not marked done yet

```bash tab="bash" tab-group="shell"
joinx -v 1 all.txt done.txt
```

```powershell tab="PowerShell" tab-group="shell"
joinx -v 1 all.txt done.txt
```
