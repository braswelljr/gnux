---
title: "--nocheck-order"
description: "Do not check that the input is correctly sorted."
---

An option of [joinx](/docs/tools/joinx).

## Usage

```bash
joinx --nocheck-order FILE1 FILE2
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--nocheck-order` | none |  | do not check that the input is correctly sorted |

## Help in the terminal

```bash
gnux help joinx --nocheck-order
```
