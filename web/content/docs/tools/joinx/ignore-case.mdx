---
title: "-i, --ignore-case"
description: "Ignore differences in case when comparing fields."
---

An option of [joinx](/docs/tools/joinx).

## Usage

```bash
joinx -i FILE1 FILE2
joinx --ignore-case FILE1 FILE2
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-i` | `--ignore-case` | none |  | ignore differences in case when comparing fields |

## Examples

### Compare join fields without regard to case

```bash tab="bash" tab-group="shell"
joinx -i a.txt b.txt
```

```powershell tab="PowerShell" tab-group="shell"
joinx -i a.txt b.txt
```
