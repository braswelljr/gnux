---
title: "-e, --empty"
description: "Replace missing input fields with EMPTY."
---

An option of [joinx](/docs/tools/joinx).

## Usage

```bash
joinx -e EMPTY FILE1 FILE2
joinx --empty=EMPTY FILE1 FILE2
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-e` | `--empty` | `EMPTY` |  | replace missing input fields with EMPTY |

## Examples

### Merge two inventories into one table, marking missing values as NULL

```bash tab="bash" tab-group="shell"
joinx -a 1 -a 2 -e NULL -o auto a.txt b.txt
```

```powershell tab="PowerShell" tab-group="shell"
joinx -a 1 -a 2 -e NULL -o auto a.txt b.txt
```
