title: "-a, --unpaired"
description: "Also print unpairable lines from file FILENUM, where FILENUM is 1 or 2."
---

An option of [joinx](/docs/tools/joinx).

## Usage

```bash
joinx -a FILENUM FILE1 FILE2
joinx --unpaired=FILENUM FILE1 FILE2
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-a` | `--unpaired` | `FILENUM` |  | also print unpairable lines from file FILENUM, where FILENUM is 1 or 2 |

## Examples

### Also print the lines of the first file that have no match

```bash tab="bash" tab-group="shell"
joinx -a 1 names.txt ages.txt
```

```powershell tab="PowerShell" tab-group="shell"
joinx -a 1 names.txt ages.txt
```

### Full outer join, filling missing fields with NULL

```bash tab="bash" tab-group="shell"
joinx -a 1 -a 2 -e NULL -o auto a.txt b.txt
```

```powershell tab="PowerShell" tab-group="shell"
joinx -a 1 -a 2 -e NULL -o auto a.txt b.txt
```
