---
title: "-a, --suffix-length"
description: "Generate suffixes of length N (default 2)."
---

An option of [splitx](/docs/tools/splitx).

## Usage

```bash
splitx -a N [FILE [PREFIX]]
splitx --suffix-length=N [FILE [PREFIX]]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-a` | `--suffix-length` | `N` |  | generate suffixes of length N (default 2) |

## Examples

### Number the pieces from 1 instead of 0

```bash tab="bash" tab-group="shell"
splitx -l 500 --numeric-suffixes=1 -a 3 list.txt list-
```

```powershell tab="PowerShell" tab-group="shell"
splitx -l 500 --numeric-suffixes=1 -a 3 list.txt list-
```

```text title="Output"
(creates list-001, list-002, ...)
```
