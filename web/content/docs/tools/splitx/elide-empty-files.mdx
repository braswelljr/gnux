---
title: "-e, --elide-empty-files"
description: "Do not generate empty output files with '-n'."
---

An option of [splitx](/docs/tools/splitx).

## Usage

```bash
splitx -e [FILE [PREFIX]]
splitx --elide-empty-files [FILE [PREFIX]]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-e` | `--elide-empty-files` | none |  | do not generate empty output files with '`-n`' |

## Help in the terminal

```bash
gnux help splitx --elide-empty-files
```
