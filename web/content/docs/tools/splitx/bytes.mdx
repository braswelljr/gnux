title: "-b, --bytes"

---

An option of [splitx](/docs/tools/splitx).

## Usage

```bash
splitx -b SIZE [FILE [PREFIX]]
splitx --bytes=SIZE [FILE [PREFIX]]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-b` | `--bytes` | `SIZE` |  | put SIZE bytes per output file |

## Examples

### Cut a 10 GB backup into 2 GB pieces that fit on a FAT32 USB drive

```bash tab="bash" tab-group="shell"
splitx -b 2G backup.tar.gz backup.tar.gz.part-
```

```powershell tab="PowerShell" tab-group="shell"
splitx -b 2G backup.tar.gz backup.tar.gz.part-
```

```text title="Output"
(creates backup.tar.gz.part-aa ... backup.tar.gz.part-ae)
```
