An option of [splitx](/docs/tools/splitx).

## Usage

```bash
splitx -d [FILE [PREFIX]]
splitx --numeric-suffixes[=FROM] [FILE [PREFIX]]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-d` | `--numeric-suffixes` | `FROM` (optional) |  | use numeric suffixes starting at 0, not alphabetic; `--numeric-suffixes`=FROM starts at FROM |

## Examples

### Break a million-row CSV into files of 100,000 rows for an import tool that chokes on big files

```bash tab="bash" tab-group="shell"
tailx -n +2 users.csv | splitx -l 100000 -d --additional-suffix=.csv - users-
```

```powershell tab="PowerShell" tab-group="shell"
tailx -n +2 users.csv | splitx -l 100000 -d --additional-suffix=.csv - users-
```

```text title="Output"
(creates users-00.csv ... users-09.csv)
```

### Number the pieces from 1 instead of 0

```bash tab="bash" tab-group="shell"
splitx -l 500 --numeric-suffixes=1 -a 3 list.txt list-
```

```powershell tab="PowerShell" tab-group="shell"
splitx -l 500 --numeric-suffixes=1 -a 3 list.txt list-
```

```text title="Output"
(creates list-001, list-002, ...)
```
