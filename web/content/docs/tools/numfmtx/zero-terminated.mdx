title: "-z, --zero-terminated"

An option of [numfmtx](/docs/tools/numfmtx).

## Usage

```bash
numfmtx -z [NUMBER]...
numfmtx --zero-terminated [NUMBER]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-z` | `--zero-terminated` | none |  | line delimiter is NUL, not newline |

## Help in the terminal

```bash
gnux help numfmtx --zero-terminated
```
