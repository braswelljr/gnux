An option of [numfmtx](/docs/tools/numfmtx).

## Usage

```bash
numfmtx --invalid=MODE [NUMBER]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--invalid` | `MODE` |  | failure mode for invalid numbers: MODE can be: abort (default), fail, warn, ignore |

## Examples

### Keep going past values that are not numbers, but say which

```bash tab="bash" tab-group="shell"
numfmtx --invalid=warn --to=si 1000 n/a 2000
```

```powershell tab="PowerShell" tab-group="shell"
numfmtx --invalid=warn --to=si 1000 n/a 2000
```

## Help in the terminal

```bash
gnux help numfmtx --invalid
```
