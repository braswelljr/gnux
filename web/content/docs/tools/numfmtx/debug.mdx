An option of [numfmtx](/docs/tools/numfmtx).

## Usage

```bash
numfmtx --debug [NUMBER]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--debug` | none |  | print warnings about invalid input |

## Help in the terminal

```bash
gnux help numfmtx --debug
```
