---
title: "--suffix"
description: "Add SUFFIX to output numbers, and accept optional SUFFIX in input numbers."
---

An option of [numfmtx](/docs/tools/numfmtx).

## Usage

```bash
numfmtx --suffix=SUFFIX [NUMBER]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--suffix` | `SUFFIX` |  | add SUFFIX to output numbers, and accept optional SUFFIX in input numbers |

## Examples

### Add a unit and pad the numbers to a column

```bash tab="bash" tab-group="shell"
numfmtx --to=iec --suffix=B --padding=7 1024 2048000
```

```powershell tab="PowerShell" tab-group="shell"
numfmtx --to=iec --suffix=B --padding=7 1024 2048000
```

```text title="Output"
  1.0KB
  2.0MB
```
