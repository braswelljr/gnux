---
title: "--grouping"
description: "Use locale-defined grouping of digits, e.g. 1,000,000 (which means it has no effect in the C/POSIX locale)."
---

An option of [numfmtx](/docs/tools/numfmtx).

## Usage

```bash
numfmtx --grouping [NUMBER]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--grouping` | none |  | use locale-defined grouping of digits, e.g. 1,000,000 (which means it has no effect in the C/POSIX locale) |

## Help in the terminal

```bash
gnux help numfmtx --grouping
```
