title: "--to-unit"
description: "The output unit size (instead of the default 1)."
---

An option of [numfmtx](/docs/tools/numfmtx).

## Usage

```bash
numfmtx --to-unit=string [NUMBER]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--to-unit` | `string` |  | the output unit size (instead of the default 1) |

## Help in the terminal

```bash
gnux help numfmtx --to-unit
```
