---
title: "--ignore-missing"
description: "Don't fail or report status for missing files."
---

An option of [sha256sumx](/docs/tools/sha256sumx).

## Usage

```bash
sha256sumx --ignore-missing [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--ignore-missing` | none |  | don't fail or report status for missing files |

## Examples

### Verify only the listed files that exist

```bash tab="bash" tab-group="shell"
sha256sumx -c --ignore-missing sha256.sums
```

```powershell tab="PowerShell" tab-group="shell"
sha256sumx -c --ignore-missing sha256.sums
```

## Help in the terminal

```bash
gnux help sha256sumx --ignore-missing
```
