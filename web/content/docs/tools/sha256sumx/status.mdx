---
title: "--status"
description: "Don't output anything, status code shows success."
---

An option of [sha256sumx](/docs/tools/sha256sumx).

## Usage

```bash
sha256sumx --status [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--status` | none |  | don't output anything, status code shows success |

## Examples

### In CI, fail the build when a vendored file was changed by hand

```bash tab="bash" tab-group="shell"
sha256sumx -c --status vendor.sha256sums || { echox 'vendored files changed' >&2; exit 1; }
```

```powershell tab="PowerShell" tab-group="shell"
sha256sumx -c --status vendor.sha256sums; if ($LASTEXITCODE -ne 0) { Write-Error 'vendored files changed'; exit 1 }
```
