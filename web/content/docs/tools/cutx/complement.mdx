title: "--complement"
description: "Complement the set of selected bytes, characters or fields."
---

An option of [cutx](/docs/tools/cutx).

## Usage

```bash
cutx --complement OPTION... [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--complement` | none |  | complement the set of selected bytes, characters or fields |

## Examples

### Drop the second column, keeping the rest

```bash tab="bash" tab-group="shell"
cutx -d , -f 2 --complement people.csv
```

```powershell tab="PowerShell" tab-group="shell"
cutx -d , -f 2 --complement people.csv
```
