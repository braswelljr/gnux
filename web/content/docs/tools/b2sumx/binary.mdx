---
title: "-b, --binary"
description: "Read in binary mode."
---

An option of [b2sumx](/docs/tools/b2sumx).

## Usage

```bash
b2sumx -b [FILE]...
b2sumx --binary [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-b` | `--binary` | none |  | read in binary mode |

## Examples

### Mark the files as read in binary mode

```bash tab="bash" tab-group="shell"
b2sumx -b file.iso
```

```powershell tab="PowerShell" tab-group="shell"
b2sumx -b file.iso
```

## Help in the terminal

```bash
gnux help b2sumx --binary
```
