---
title: "--quiet"
description: "Don't print OK for each successfully verified file."
---

An option of [b2sumx](/docs/tools/b2sumx).

## Usage

```bash
b2sumx --quiet [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--quiet` | none |  | don't print OK for each successfully verified file |

## Examples

### Re-check a large archive set and show only what no longer matches

```bash tab="bash" tab-group="shell"
b2sumx -c --quiet b2.sums
```

```powershell tab="PowerShell" tab-group="shell"
b2sumx -c --quiet b2.sums
```

```text title="Output"
notes.txt: FAILED
b2sumx: WARNING: 1 computed checksum did NOT match
```

## Help in the terminal

```bash
gnux help b2sumx --quiet
```
