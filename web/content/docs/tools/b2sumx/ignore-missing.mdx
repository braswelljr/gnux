---
title: "--ignore-missing"
description: "Don't fail or report status for missing files."
---

An option of [b2sumx](/docs/tools/b2sumx).

## Usage

```bash
b2sumx --ignore-missing [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--ignore-missing` | none |  | don't fail or report status for missing files |

## Examples

### Verify only the listed files that exist

```bash tab="bash" tab-group="shell"
b2sumx -c --ignore-missing b2.sums
```

```powershell tab="PowerShell" tab-group="shell"
b2sumx -c --ignore-missing b2.sums
```

## Help in the terminal

```bash
gnux help b2sumx --ignore-missing
```
