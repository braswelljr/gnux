---
title: "--status"
description: "Don't output anything, status code shows success."
---

An option of [b2sumx](/docs/tools/b2sumx).

## Usage

```bash
b2sumx --status [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--status` | none |  | don't output anything, status code shows success |

## Examples

### Verify silently and branch on the result

```bash tab="bash" tab-group="shell"
b2sumx -c --status b2.sums && echox verified
```

```powershell tab="PowerShell" tab-group="shell"
b2sumx -c --status b2.sums; if ($LASTEXITCODE -eq 0) { 'verified' }
```

## Help in the terminal

```bash
gnux help b2sumx --status
```
