---
title: "--strict"
description: "Exit non-zero for improperly formatted checksum lines."
---

An option of [b2sumx](/docs/tools/b2sumx).

## Usage

```bash
b2sumx --strict [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--strict` | none |  | exit non-zero for improperly formatted checksum lines |

## Examples

### Fail on malformed lines in the list

```bash tab="bash" tab-group="shell"
b2sumx -c --strict -w b2.sums
```

```powershell tab="PowerShell" tab-group="shell"
b2sumx -c --strict -w b2.sums
```

## Help in the terminal

```bash
gnux help b2sumx --strict
```
