---
title: "--header"
description: "With -l, print a row naming each column."
---

An option of [vdirx](/docs/tools/vdirx).

## Usage

```bash
vdirx --header [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--header` | none |  | with `-l`, print a row naming each column |

## Help in the terminal

```bash
gnux help vdirx --header
```
