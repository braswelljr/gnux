---
title: "-s, --size"
description: "Print the allocated size of each file, in blocks."
---

An option of [vdirx](/docs/tools/vdirx).

## Usage

```bash
vdirx -s [FILE]...
vdirx --size [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-s` | `--size` | none |  | print the allocated size of each file, in blocks |

## Help in the terminal

```bash
gnux help vdirx --size
```
