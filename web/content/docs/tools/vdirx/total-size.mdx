---
title: "--total-size"
description: "Show a directory's size as the total of everything in it."
---

An option of [vdirx](/docs/tools/vdirx).

## Usage

```bash
vdirx --total-size [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--total-size` | none |  | show a directory's size as the total of everything in it |

## Help in the terminal

```bash
gnux help vdirx --total-size
```
