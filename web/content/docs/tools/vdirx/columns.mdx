---
title: "-C, --columns"
description: "List entries by columns."
---

An option of [vdirx](/docs/tools/vdirx).

## Usage

```bash
vdirx -C [FILE]...
vdirx --columns [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-C` | `--columns` | none |  | list entries by columns |

## Help in the terminal

```bash
gnux help vdirx --columns
```
