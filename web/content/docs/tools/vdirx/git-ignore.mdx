---
title: "--git-ignore"
description: "Do not list entries that .gitignore rules exclude."
---

An option of [vdirx](/docs/tools/vdirx).

## Usage

```bash
vdirx --git-ignore [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--git-ignore` | none |  | do not list entries that .gitignore rules exclude |

## Help in the terminal

```bash
gnux help vdirx --git-ignore
```
