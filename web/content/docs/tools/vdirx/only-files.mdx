---
title: "--only-files"
description: "List only files, not directories."
---

An option of [vdirx](/docs/tools/vdirx).

## Usage

```bash
vdirx --only-files [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--only-files` | none |  | list only files, not directories |

## Help in the terminal

```bash
gnux help vdirx --only-files
```
