---
title: "-R, --recursive"
description: "List subdirectories recursively."
---

An option of [vdirx](/docs/tools/vdirx).

## Usage

```bash
vdirx -R [FILE]...
vdirx --recursive [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-R` | `--recursive` | none |  | list subdirectories recursively |

## Help in the terminal

```bash
gnux help vdirx --recursive
```
