An option of [vdirx](/docs/tools/vdirx).

## Usage

```bash
vdirx -m [FILE]...
vdirx --commas [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-m` | `--commas` | none |  | fill width with a comma separated list of entries |
