An option of [vdirx](/docs/tools/vdirx).

## Usage

```bash
vdirx -A [FILE]...
vdirx --almost-all [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-A` | `--almost-all` | none |  | do not list implied . and .. |
