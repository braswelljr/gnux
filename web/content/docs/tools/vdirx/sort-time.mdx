An option of [vdirx](/docs/tools/vdirx).

## Usage

```bash
vdirx -t [FILE]...
vdirx --sort-time [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-t` | `--sort-time` | none |  | sort by time, newest first; see `--time` |

## Examples

### Newest files first

```bash tab="bash" tab-group="shell"
vdirx -t
```

```powershell tab="PowerShell" tab-group="shell"
vdirx -t
```

gnux help vdirx --sort-time
