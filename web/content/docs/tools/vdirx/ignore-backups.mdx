An option of [vdirx](/docs/tools/vdirx).

## Usage

```bash
vdirx -B [FILE]...
vdirx --ignore-backups [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-B` | `--ignore-backups` | none |  | do not list implied entries ending with ~ |

## Help in the terminal

```bash
gnux help vdirx --ignore-backups
```
