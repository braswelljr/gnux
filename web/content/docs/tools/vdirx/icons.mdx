---
title: "--icons"
description: "Show an icon (Nerd Font) before each name WHEN: 'always' (the default when WHEN is omitted), 'auto', or 'never'; GNUX_ICONS sets the default."
---

An option of [vdirx](/docs/tools/vdirx).

## Usage

```bash
vdirx --icons[=WHEN] [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--icons` | `WHEN` (optional) |  | show an icon (Nerd Font) before each name WHEN: 'always' (the default when WHEN is omitted), 'auto', or 'never'; GNUX_ICONS sets the default |

## Help in the terminal

```bash
gnux help vdirx --icons
```
