---
title: "-n, --numeric-uid-gid"
description: "Like -l, but list numeric user and group IDs."
---

An option of [vdirx](/docs/tools/vdirx).

## Usage

```bash
vdirx -n [FILE]...
vdirx --numeric-uid-gid [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-n` | `--numeric-uid-gid` | none |  | like `-l`, but list numeric user and group IDs |

## Examples

### Show numeric user and group IDs

```bash tab="bash" tab-group="shell"
vdirx -n
```

```powershell tab="PowerShell" tab-group="shell"
vdirx -n
```

## Help in the terminal

```bash
gnux help vdirx --numeric-uid-gid
```
