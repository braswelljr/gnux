---
title: "-S, --sort-size"
description: "Sort by file size, largest first."
---

An option of [vdirx](/docs/tools/vdirx).

## Usage

```bash
vdirx -S [FILE]...
vdirx --sort-size [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-S` | `--sort-size` | none |  | sort by file size, largest first |

## Examples

### Largest files first

```bash tab="bash" tab-group="shell"
vdirx -S
```

```powershell tab="PowerShell" tab-group="shell"
vdirx -S
```

## Help in the terminal

```bash
gnux help vdirx --sort-size
```
