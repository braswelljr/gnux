---
title: "-T, --tabsize"
description: "Assume tab stops at each COLS instead of 8."
---

An option of [vdirx](/docs/tools/vdirx).

## Usage

```bash
vdirx -T COLS [FILE]...
vdirx --tabsize=COLS [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-T` | `--tabsize` | `COLS` |  | assume tab stops at each COLS instead of 8 |

## Help in the terminal

```bash
gnux help vdirx --tabsize
```
