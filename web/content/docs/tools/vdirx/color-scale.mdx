An option of [vdirx](/docs/tools/vdirx).

## Usage

```bash
vdirx --color-scale[=WHICH] [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--color-scale` | `WHICH` (optional) |  | color WHICH columns on a gradient by value: 'all' (the default when WHICH is omitted), 'size', 'age' or 'none' |

## Help in the terminal

```bash
gnux help vdirx --color-scale
```
