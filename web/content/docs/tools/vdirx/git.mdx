---
title: "--git"
description: "With -l, print each file's git status (staged, then unstaged)."
---

An option of [vdirx](/docs/tools/vdirx).

## Usage

```bash
vdirx --git [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--git` | none |  | with `-l`, print each file's git status (staged, then unstaged) |

## Help in the terminal

```bash
gnux help vdirx --git
```
