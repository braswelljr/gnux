---
title: "-r, --reverse"
description: "Reverse order while sorting."
---

An option of [vdirx](/docs/tools/vdirx).

## Usage

```bash
vdirx -r [FILE]...
vdirx --reverse [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-r` | `--reverse` | none |  | reverse order while sorting |

## Help in the terminal

```bash
gnux help vdirx --reverse
```
