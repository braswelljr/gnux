---
title: "-i, --inode"
description: "Print the index number of each file."
---

An option of [vdirx](/docs/tools/vdirx).

## Usage

```bash
vdirx -i [FILE]...
vdirx --inode [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-i` | `--inode` | none |  | print the index number of each file |

## Help in the terminal

```bash
gnux help vdirx --inode
```
