---
title: "-n, --number"
description: "Same as -s, with a NUMBER."
---

An option of [killx](/docs/tools/killx).

## Usage

```bash
killx -n NUMBER [-s SIGNAL | -SIGNAL] PID...
killx --number=NUMBER [-s SIGNAL | -SIGNAL] PID...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-n` | `--number` | `NUMBER` |  | same as `-s`, with a NUMBER |

## Help in the terminal

```bash
gnux help killx --number
```
