---
title: "-n, --no-dereference"
description: "Treat LINK_NAME as a normal file if it is a symbolic link to a directory."
---

An option of [lnx](/docs/tools/lnx).

## Usage

```bash
lnx -n TARGET... [LINK_NAME|DIRECTORY]
lnx --no-dereference TARGET... [LINK_NAME|DIRECTORY]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-n` | `--no-dereference` | none |  | treat LINK_NAME as a normal file if it is a symbolic link to a directory |

## Examples

Repoint an existing symlink to a directory, in one atomic step:

```bash
lnx -sfn releases/v3 current
```

```powershell
lnx -sfn releases\v3 current
```

Create a release directory and point current at it with the `gnux shell`:

```bash
gnux shell -c 'mkdirx -p releases/v4 && lnx -sfnv releases/v4 current'
```

```powershell
gnux shell -c 'mkdirx -p releases/v4 && lnx -sfnv releases/v4 current'
```

## Help in the terminal

```bash
gnux help lnx --no-dereference
```
