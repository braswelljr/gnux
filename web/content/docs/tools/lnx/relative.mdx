---
title: "-r, --relative"
description: "With -s, create links relative to link location."
---

An option of [lnx](/docs/tools/lnx).

## Usage

```bash
lnx -r TARGET... [LINK_NAME|DIRECTORY]
lnx --relative TARGET... [LINK_NAME|DIRECTORY]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-r` | `--relative` | none |  | with `-s`, create links relative to `link` location |

## Examples

### Link several files into a directory with relative symlinks

```bash tab="bash" tab-group="shell"
lnx -sr -t ~/bin tools/build tools/deploy
```

```powershell tab="PowerShell" tab-group="shell"
lnx -sr -t $HOME\bin tools\build tools\deploy
```
