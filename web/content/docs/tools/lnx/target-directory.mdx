---
title: "-t, --target-directory"
description: "Specify the DIRECTORY in which to create the links."
---

An option of [lnx](/docs/tools/lnx).

## Usage

```bash
lnx -t string TARGET... [LINK_NAME|DIRECTORY]
lnx --target-directory=string TARGET... [LINK_NAME|DIRECTORY]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-t` | `--target-directory` | `string` |  | specify the DIRECTORY in which to create the links |

## Examples

Link several files into a directory with relative symlinks:

```bash
lnx -sr -t ~/bin tools/build tools/deploy
```

```powershell
lnx -sr -t $HOME\bin tools\build tools\deploy
```

## Help in the terminal

```bash
gnux help lnx --target-directory
```
