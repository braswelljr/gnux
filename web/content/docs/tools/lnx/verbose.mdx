---
title: "-v, --verbose"
description: "Print name of each linked file."
---

An option of [lnx](/docs/tools/lnx).

## Usage

```bash
lnx -v TARGET... [LINK_NAME|DIRECTORY]
lnx --verbose TARGET... [LINK_NAME|DIRECTORY]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-v` | `--verbose` | none |  | print name of each linked file |

## Examples

Create a hard link, reporting what was done:

```bash
lnx -v data.db data.db.snapshot
```

```powershell
lnx -v data.db data.db.snapshot
```

Link several targets into an existing directory:

```bash
lnx -sv ../dotfiles/.vimrc ../dotfiles/.gitconfig home/
```

```powershell
lnx -sv ..\dotfiles\.vimrc ..\dotfiles\.gitconfig home
```

Create a release directory and point current at it with the `gnux shell`:

```bash
gnux shell -c 'mkdirx -p releases/v4 && lnx -sfnv releases/v4 current'
```

```powershell
gnux shell -c 'mkdirx -p releases/v4 && lnx -sfnv releases/v4 current'
```

## Help in the terminal

```bash
gnux help lnx --verbose
```
