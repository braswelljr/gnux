---
title: "-i, --interactive"
description: "Prompt whether to remove destinations."
---

An option of [lnx](/docs/tools/lnx).

## Usage

```bash
lnx -i TARGET... [LINK_NAME|DIRECTORY]
lnx --interactive TARGET... [LINK_NAME|DIRECTORY]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-i` | `--interactive` | none |  | prompt whether to remove destinations |

## Examples

### Ask before replacing an existing link

```bash tab="bash" tab-group="shell"
lnx -si settings.prod.json settings.json
```

```powershell tab="PowerShell" tab-group="shell"
lnx -si settings.prod.json settings.json
```

## Help in the terminal

```bash
gnux help lnx --interactive
```
