---
title: "-f, --force"
description: "Remove existing destination files."
---

An option of [lnx](/docs/tools/lnx).

## Usage

```bash
lnx -f TARGET... [LINK_NAME|DIRECTORY]
lnx --force TARGET... [LINK_NAME|DIRECTORY]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-f` | `--force` | none |  | remove existing destination files |

## Examples

Repoint an existing symlink to a directory, in one atomic step:

```bash
lnx -sfn releases/v3 current
```

```powershell
lnx -sfn releases\v3 current
```

Replace an existing file with a link:

```bash
lnx -sf app-v2.conf app.conf
```

```powershell
lnx -sf app-v2.conf app.conf
```

Create a release directory and point current at it with the `gnux shell`:

```bash
gnux shell -c 'mkdirx -p releases/v4 && lnx -sfnv releases/v4 current'
```

```powershell
gnux shell -c 'mkdirx -p releases/v4 && lnx -sfnv releases/v4 current'
```

## Help in the terminal

```bash
gnux help lnx --force
```
