---
title: "-b, --backup-default"
description: "Like --backup but does not accept an argument."
---

An option of [lnx](/docs/tools/lnx).

## Usage

```bash
lnx -b TARGET... [LINK_NAME|DIRECTORY]
lnx --backup-default TARGET... [LINK_NAME|DIRECTORY]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-b` | `--backup-default` | none |  | like `--backup` but does not accept an argument |

## Examples

### Repoint a symbolic link, keeping the old one as current~ in case you need to roll back

```bash tab="bash" tab-group="shell"
lnx -sbv releases/v5 current
```

```powershell tab="PowerShell" tab-group="shell"
lnx -sbv releases\v5 current
```

## Help in the terminal

gnux help lnx --backup-default
