---
title: "-q, --quiet"
description: "Suppress diagnostics about file/dir-creation failure."
---

An option of [mktempx](/docs/tools/mktempx).

## Usage

```bash
mktempx -q [TEMPLATE]
mktempx --quiet [TEMPLATE]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-q` | `--quiet` | none |  | suppress diagnostics about file/dir-creation failure |

## Examples

### Fail quietly and handle it yourself

```bash tab="bash" tab-group="shell"
mktempx -q -p /nonexistent || echox 'no temp dir'
```

```powershell tab="PowerShell" tab-group="shell"
mktempx -q -p C:\nonexistent; if ($LASTEXITCODE -ne 0) { echox 'no temp dir' }
```

## Help in the terminal

```bash
gnux help mktempx --quiet
```
