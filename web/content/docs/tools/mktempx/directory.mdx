---
title: "-d, --directory"
description: "Create a directory, not a file."
---

An option of [mktempx](/docs/tools/mktempx).

## Usage

```bash
mktempx -d [TEMPLATE]
mktempx --directory [TEMPLATE]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-d` | `--directory` | none |  | create a directory, not a file |

## Examples

### Create a temporary directory

```bash tab="bash" tab-group="shell"
mktempx -d
```

```powershell tab="PowerShell" tab-group="shell"
mktempx -d
```

## Help in the terminal

```bash
gnux help mktempx --directory
```
