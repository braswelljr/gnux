---
title: "--total"
description: "Elide all entries insignificant to available space, and produce a grand total."
---

An option of [dfx](/docs/tools/dfx).

## Usage

```bash
dfx --total [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--total` | none |  | elide all entries insignificant to available space, and produce a grand total |

## Examples

### Total the space across all local disks

```bash tab="bash" tab-group="shell"
dfx -hl --total
```

```powershell tab="PowerShell" tab-group="shell"
dfx -hl --total
```

## Help in the terminal

```bash
gnux help dfx --total
```
