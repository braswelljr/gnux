---
title: "-x, --exclude-type"
description: "Limit listing to file systems not of type TYPE."
---

An option of [dfx](/docs/tools/dfx).

## Usage

```bash
dfx -x TYPE [FILE]...
dfx --exclude-type=TYPE [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-x` | `--exclude-type` | `TYPE` |  | limit listing to file systems not of type TYPE |

## Examples

### Leave temporary file systems out of the report

```bash tab="bash" tab-group="shell"
dfx -h -x tmpfs -x devtmpfs
```

```powershell tab="PowerShell" tab-group="shell"
dfx -h
```

## Help in the terminal

```bash
gnux help dfx --exclude-type
```
