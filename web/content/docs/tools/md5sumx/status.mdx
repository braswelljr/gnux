---
title: "--status"
description: "Don't output anything, status code shows success."
---

An option of [md5sumx](/docs/tools/md5sumx).

## Usage

```bash
md5sumx --status [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--status` | none |  | don't output anything, status code shows success |

## Examples

### Verify silently and branch on the result

```bash tab="bash" tab-group="shell"
md5sumx -c --status md5.sums && echox verified
```

```powershell tab="PowerShell" tab-group="shell"
md5sumx -c --status md5.sums; if ($LASTEXITCODE -eq 0) { 'verified' }
```

## Help in the terminal

```bash
gnux help md5sumx --status
```
