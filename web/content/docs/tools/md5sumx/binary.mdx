---
title: "-b, --binary"
description: "Read in binary mode."
---

An option of [md5sumx](/docs/tools/md5sumx).

## Usage

```bash
md5sumx -b [FILE]...
md5sumx --binary [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-b` | `--binary` | none |  | read in binary mode |

## Examples

### Mark the files as read in binary mode

```bash tab="bash" tab-group="shell"
md5sumx -b file.iso
```

```powershell tab="PowerShell" tab-group="shell"
md5sumx -b file.iso
```

## Help in the terminal

```bash
gnux help md5sumx --binary
```
