An option of [md5sumx](/docs/tools/md5sumx).

## Usage

```bash
md5sumx -z [FILE]...
md5sumx --zero [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-z` | `--zero` | none |  | end each output line with NUL, not newline, and disable file name escaping |

## Help in the terminal

```bash
gnux help md5sumx --zero
```
