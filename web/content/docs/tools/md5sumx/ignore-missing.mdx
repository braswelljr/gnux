---
title: "--ignore-missing"
description: "Don't fail or report status for missing files."
---

An option of [md5sumx](/docs/tools/md5sumx).

## Usage

```bash
md5sumx --ignore-missing [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--ignore-missing` | none |  | don't fail or report status for missing files |

## Examples

### Verify the download against the publisher's checksum file, which lists other files too

```bash tab="bash" tab-group="shell"
md5sumx -c --ignore-missing md5.sums
```

```powershell tab="PowerShell" tab-group="shell"
md5sumx -c --ignore-missing md5.sums
```

```text title="Output"
ubuntu-24.04-desktop-amd64.iso: OK
```

## Help in the terminal

```bash
gnux help md5sumx --ignore-missing
```
