---
title: "-c, --count"
description: "Prefix lines by the number of occurrences."
---

An option of [uniqx](/docs/tools/uniqx).

## Usage

```bash
uniqx -c [INPUT [OUTPUT]]
uniqx --count [INPUT [OUTPUT]]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-c` | `--count` | none |  | prefix lines by the number of occurrences |

## Examples

### Users report errors from your web server: see how its responses split between status codes, drawn as a histogram on the terminal

```bash tab="bash" tab-group="shell"
cutx -d' ' -f9 access.log | sortx | uniqx -c
```

```powershell tab="PowerShell" tab-group="shell"
cutx -d' ' -f9 access.log | sortx | uniqx -c
```

### Count the occurrences of each line

```bash tab="bash" tab-group="shell"
uniqx -c sorted.txt
```

```powershell tab="PowerShell" tab-group="shell"
uniqx -c sorted.txt
```

### Deduplicate in the portable gnux shell

```bash tab="bash" tab-group="shell"
gnux shell -c 'catx sorted.txt | uniqx -c'
```

```powershell tab="PowerShell" tab-group="shell"
gnux shell -c 'catx sorted.txt | uniqx -c'
```

## Help in the terminal

```bash
gnux help uniqx --count
```
