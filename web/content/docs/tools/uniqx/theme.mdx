---
title: "--theme"
description: "Color the view with the built-in theme NAME (gnux theme picks and saves one); GNUX_THEME sets the default."
---

An option of [uniqx](/docs/tools/uniqx).

## Usage

```bash
uniqx --theme=NAME [INPUT [OUTPUT]]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--theme` | `NAME` |  | color the view with the built-in theme NAME (`gnux` theme picks and saves one); GNUX_THEME sets the default |

## Help in the terminal

```bash
gnux help uniqx --theme
```
