---
title: "-z, --zero-terminated"
description: "Line delimiter is NUL, not newline."
---

An option of [uniqx](/docs/tools/uniqx).

## Usage

```bash
uniqx -z [INPUT [OUTPUT]]
uniqx --zero-terminated [INPUT [OUTPUT]]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-z` | `--zero-terminated` | none |  | line delimiter is NUL, not newline |

## Examples

### Deduplicate a NUL-separated list

```bash tab="bash" tab-group="shell"
uniqx -z files.lst
```

```powershell tab="PowerShell" tab-group="shell"
uniqx -z files.lst
```

## Help in the terminal

```bash
gnux help uniqx --zero-terminated
```
