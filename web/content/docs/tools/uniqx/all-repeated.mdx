title: "-D, --all-repeated"
description: "Print all duplicate lines; groups can be delimited with an empty line; METHOD is none (the default), prepend or separate."
---

An option of [uniqx](/docs/tools/uniqx).

## Usage

```bash
uniqx -D [INPUT [OUTPUT]]
uniqx --all-repeated[=METHOD] [INPUT [OUTPUT]]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-D` | `--all-repeated` | `METHOD` (optional) |  | print all duplicate lines; groups can be delimited with an empty line; METHOD is none (the default), prepend or separate |

## Examples

Print every repeated line, the groups separated by an empty line:

```bash
uniqx --all-repeated=separate sorted.txt
```

```powershell
uniqx --all-repeated=separate sorted.txt
```
