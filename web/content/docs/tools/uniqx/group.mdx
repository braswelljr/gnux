title: "--group"

---

An option of [uniqx](/docs/tools/uniqx).

## Usage

```bash
uniqx --group[=METHOD] [INPUT [OUTPUT]]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--group` | `METHOD` (optional) |  | show all items, separating groups with an empty line; METHOD is separate (the default), prepend, append or both |

## Examples

Print all lines with each group of equal lines set apart:

```bash
uniqx --group sorted.txt
```

```powershell
uniqx --group sorted.txt
```

gnux help uniqx --group
