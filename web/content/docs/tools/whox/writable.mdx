title: "-w, --writable"
description: "Same as -T."
---

An option of [whox](/docs/tools/whox).

## Usage

```bash
whox -w [ FILE | ARG1 ARG2 ]
whox --writable [ FILE | ARG1 ARG2 ]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-w` | `--writable` | none |  | same as `-T` |

## Help in the terminal

```bash
gnux help whox --writable
```
