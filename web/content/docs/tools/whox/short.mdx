An option of [whox](/docs/tools/whox).

## Usage

```bash
whox -s [ FILE | ARG1 ARG2 ]
whox --short [ FILE | ARG1 ARG2 ]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-s` | `--short` | none |  | print only name, line, and time (default) |

## Help in the terminal

```bash
gnux help whox --short
```
