An option of [whox](/docs/tools/whox).

## Usage

```bash
whox -m [ FILE | ARG1 ARG2 ]
whox --my-line [ FILE | ARG1 ARG2 ]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-m` | `--my-line` | none |  | only `hostname` and user associated with stdin |
