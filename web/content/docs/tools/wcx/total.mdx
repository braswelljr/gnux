title: "--total"
description: "When to print a line with total counts; WHEN can be: auto, always, only, never."
---

An option of [wcx](/docs/tools/wcx).

## Usage

```bash
wcx --total=WHEN [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--total` | `WHEN` | `auto` | when to print a line with total counts; WHEN can be: auto, always, only, never |

## Examples

### Count several files without the total line, or force it for a single file

```bash tab="bash" tab-group="shell"
wcx -l --total=never *.go && wcx -l --total=always main.go
```

```powershell tab="PowerShell" tab-group="shell"
wcx -l --total=never (Get-ChildItem *.go -Name); wcx -l --total=always main.go
```

### Print only the grand total for a list of files found elsewhere

```bash tab="bash" tab-group="shell"
find . -name '*.go' -print0 | wcx -l --files0-from=- --total=only
```

```powershell tab="PowerShell" tab-group="shell"
wcx -l --total=only (Get-ChildItem -Recurse *.go).FullName
```
