---
title: "-c, --bytes"
description: "Print the byte counts."
---

An option of [wcx](/docs/tools/wcx).

## Usage

```bash
wcx -c [FILE]...
wcx --bytes [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-c` | `--bytes` | none |  | print the byte counts |

## Examples

Print the size of a file in bytes:

```bash
wcx -c image.png
```

```powershell
wcx -c image.png
```

## Help in the terminal

```bash
gnux help wcx --bytes
```
