---
title: "-w, --words"
description: "Print the word counts."
---

An option of [wcx](/docs/tools/wcx).

## Usage

```bash
wcx -w [FILE]...
wcx --words [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-w` | `--words` | none |  | print the word counts |

## Examples

### Count the words of an essay

```bash tab="bash" tab-group="shell"
wcx -w essay.txt
```

```powershell tab="PowerShell" tab-group="shell"
wcx -w essay.txt
```

### Print lines and words together (always in that order, whatever the flag order)

```bash tab="bash" tab-group="shell"
wcx -wl essay.txt
```

```powershell tab="PowerShell" tab-group="shell"
wcx -wl essay.txt
```

### Count the words of text from standard input

```bash tab="bash" tab-group="shell"
echox 'the quick brown fox' | wcx -w
```

```powershell tab="PowerShell" tab-group="shell"
'the quick brown fox' | wcx -w
```
