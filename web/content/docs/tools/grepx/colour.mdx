An option of [grepx](/docs/tools/grepx).

## Usage

```bash
grepx --colour[=WHEN] PATTERNS [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--colour` | `WHEN` (optional) |  | same as `--color`=WHEN |

## Help in the terminal

```bash
gnux help grepx --colour
```
