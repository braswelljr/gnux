---
title: "-B, --before-context"
description: "Print NUM lines of leading context."
---

An option of [grepx](/docs/tools/grepx).

## Usage

```bash
grepx -B NUM PATTERNS [FILE]...
grepx --before-context=NUM PATTERNS [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-B` | `--before-context` | `NUM` |  | print NUM lines of leading context |

## Help in the terminal

```bash
gnux help grepx --before-context
```
