An option of [grepx](/docs/tools/grepx).

## Usage

```bash
grepx --color[=WHEN] PATTERNS [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--color` | `WHEN` (optional) |  | highlight matches, names and separators; WHEN is always, never or auto |

## Help in the terminal

```bash
gnux help grepx --color
```
