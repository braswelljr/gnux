---
title: "-a, --text"
description: "Equivalent to --binary-files=text."
---

An option of [grepx](/docs/tools/grepx).

## Usage

```bash
grepx -a PATTERNS [FILE]...
grepx --text PATTERNS [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-a` | `--text` | none |  | equivalent to `--binary-files`=text |

## Help in the terminal

```bash
gnux help grepx --text
```
