An option of [grepx](/docs/tools/grepx).

## Usage

```bash
grepx -P PATTERNS [FILE]...
grepx --perl-regexp PATTERNS [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-P` | `--perl-regexp` | none |  | PATTERNS are Perl regular expressions |
