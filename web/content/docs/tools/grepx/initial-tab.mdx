---
title: "-T, --initial-tab"
description: "Make tabs line up (put a tab before the line)."
---

An option of [grepx](/docs/tools/grepx).

## Usage

```bash
grepx -T PATTERNS [FILE]...
grepx --initial-tab PATTERNS [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-T` | `--initial-tab` | none |  | make tabs line up (put a tab before the line) |

## Help in the terminal

```bash
gnux help grepx --initial-tab
```
