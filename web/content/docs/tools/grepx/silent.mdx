An option of [grepx](/docs/tools/grepx).

## Usage

```bash
grepx --silent PATTERNS [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--silent` | none |  | same as `--quiet` |

## Help in the terminal

```bash
gnux help grepx --silent
```
