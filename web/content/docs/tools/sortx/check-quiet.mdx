---
title: "-C, --check-quiet"
description: "Like -c, but do not report first bad line."
---

An option of [sortx](/docs/tools/sortx).

## Usage

```bash
sortx -C [FILE]...
sortx --check-quiet [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-C` | `--check-quiet` | none |  | like `-c`, but do not report first bad line |

## Examples

### Fail a script when a file is not sorted (exit status 1)

```bash tab="bash" tab-group="shell"
sortx -C names.txt || echox 'names.txt is not sorted'
```

```powershell tab="PowerShell" tab-group="shell"
sortx -C names.txt; if ($LASTEXITCODE -ne 0) { 'names.txt is not sorted' }
```

## Help in the terminal

```bash
gnux help sortx --check-quiet
```
