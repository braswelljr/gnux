An option of [sortx](/docs/tools/sortx).

## Usage

```bash
sortx -T DIR [FILE]...
sortx --temporary-directory=DIR [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-T` | `--temporary-directory` | `DIR` |  | accepted for compatibility and ignored (DIR for temporaries) |

## Help in the terminal

```bash
gnux help sortx --temporary-directory
```
