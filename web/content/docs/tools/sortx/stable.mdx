---
title: "-s, --stable"
description: "Stabilize sort by disabling last-resort comparison."
---

An option of [sortx](/docs/tools/sortx).

## Usage

```bash
sortx -s [FILE]...
sortx --stable [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-s` | `--stable` | none |  | stabilize sort by disabling last-resort comparison |

## Help in the terminal

```bash
gnux help sortx --stable
```
