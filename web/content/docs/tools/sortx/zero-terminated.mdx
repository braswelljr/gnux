---
title: "-z, --zero-terminated"
description: "Line delimiter is NUL, not newline."
---

An option of [sortx](/docs/tools/sortx).

## Usage

```bash
sortx -z [FILE]...
sortx --zero-terminated [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-z` | `--zero-terminated` | none |  | line delimiter is NUL, not newline |

## Examples

Sort a NUL-separated list of file names:

```bash
find . -print0 | sortx -z
```

```powershell
sortx -z list0.bin
```

## Help in the terminal

```bash
gnux help sortx --zero-terminated
```
