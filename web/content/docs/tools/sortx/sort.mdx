An option of [sortx](/docs/tools/sortx).

## Usage

```bash
sortx --sort=WORD [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--sort` | `WORD` |  | sort according to WORD: general-numeric `-g`, human-numeric `-h`, month `-M`, numeric `-n`, version `-V` |

## Help in the terminal

```bash
gnux help sortx --sort
```
