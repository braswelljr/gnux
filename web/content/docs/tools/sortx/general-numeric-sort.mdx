An option of [sortx](/docs/tools/sortx).

## Usage

```bash
sortx -g [FILE]...
sortx --general-numeric-sort [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-g` | `--general-numeric-sort` | none |  | compare according to general numerical value |
