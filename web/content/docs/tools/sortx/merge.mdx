---
title: "-m, --merge"
description: "Merge already sorted files; do not sort."
---

An option of [sortx](/docs/tools/sortx).

## Usage

```bash
sortx -m [FILE]...
sortx --merge [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-m` | `--merge` | none |  | merge already sorted files; do not sort |

## Examples

Merge files that are already sorted:

```bash
sortx -m jan.txt feb.txt mar.txt
```

```powershell
sortx -m jan.txt feb.txt mar.txt
```

## Help in the terminal

```bash
gnux help sortx --merge
```
