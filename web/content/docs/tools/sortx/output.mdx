---
title: "-o, --output"
description: "Write result to FILE instead of standard output."
---

An option of [sortx](/docs/tools/sortx).

## Usage

```bash
sortx -o FILE [FILE]...
sortx --output=FILE [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-o` | `--output` | `FILE` |  | write result to FILE instead of standard output |

## Examples

Sort a file in place:

```bash
sortx -o names.txt names.txt
```

```powershell
sortx -o names.txt names.txt
```

## Help in the terminal

```bash
gnux help sortx --output
```
