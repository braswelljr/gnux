An option of [sortx](/docs/tools/sortx).

## Usage

```bash
sortx -S SIZE [FILE]...
sortx --buffer-size=SIZE [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-S` | `--buffer-size` | `SIZE` |  | accepted for compatibility and ignored (SIZE of the main memory buffer) |

## Help in the terminal

```bash
gnux help sortx --buffer-size
```
