title: "-v, --verbose"
description: "Always print headers giving file names."
---

An option of [headx](/docs/tools/headx).

## Usage

```bash
headx -v [FILE]...
headx --verbose [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-v` | `--verbose` | none |  | always print headers giving file names |

## Examples

### Show the file name header even for a single file (--silent is the long spelling of -q)

```bash tab="bash" tab-group="shell"
headx -v -n 2 config.ini
```

```powershell tab="PowerShell" tab-group="shell"
headx -v -n 2 config.ini
```

## Help in the terminal

```bash
gnux help headx --verbose
```
