---
title: "-s, --suffix"
description: "Remove a trailing SUFFIX; implies -a."
---

An option of [basenamex](/docs/tools/basenamex).

## Usage

```bash
basenamex -s SUFFIX NAME [SUFFIX]
basenamex --suffix=SUFFIX NAME [SUFFIX]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-s` | `--suffix` | `SUFFIX` |  | remove a trailing SUFFIX; implies `-a` |

## Examples

### Remove a multi-part extension

```bash tab="bash" tab-group="shell"
basenamex --suffix=.tar.gz release/gnux-1.0.tar.gz
```

```powershell tab="PowerShell" tab-group="shell"
basenamex --suffix=.tar.gz release\gnux-1.0.tar.gz
```

### Strip a suffix from several names at once

```bash tab="bash" tab-group="shell"
basenamex -s .go cmd/main.go core/core.go
```

```powershell tab="PowerShell" tab-group="shell"
basenamex -s .go cmd\main.go core\core.go
```

### Strip an extension from every match of a glob

```bash tab="bash" tab-group="shell"
basenamex -s .jpg photos/*.jpg
```

```powershell tab="PowerShell" tab-group="shell"
basenamex -s .jpg (Get-ChildItem photos\*.jpg)
```
