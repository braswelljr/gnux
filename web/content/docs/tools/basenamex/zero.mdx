---
title: "-z, --zero"
description: "End each output line with NUL, not newline."
---

An option of [basenamex](/docs/tools/basenamex).

## Usage

```bash
basenamex -z NAME [SUFFIX]
basenamex --zero NAME [SUFFIX]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-z` | `--zero` | none |  | end each output line with NUL, not newline |

## Examples

### Separate the output with NUL bytes instead of newlines

```bash tab="bash" tab-group="shell"
basenamex -a -z a/b c/d | od -c
```

```powershell tab="PowerShell" tab-group="shell"
basenamex -a -z a\b c\d | Format-Hex
```

## Help in the terminal

```bash
gnux help basenamex --zero
```
