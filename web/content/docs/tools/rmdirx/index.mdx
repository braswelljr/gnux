---
title: "rmdirx"
description: "Remove the DIRECTORY(ies), if they are empty."
---

Mirrors GNU `rmdir`. Run it as `rmdirx`, or as `gnux rmdirx`.

## Synopsis

```bash
rmdirx [OPTION]... DIRECTORY...
```

## Description

`rmdirx` removes each DIRECTORY, but only when it is empty: a directory that still has entries is reported and left untouched, and so is anything that is not a directory. That makes it the safe counterpart to a recursive delete - it can never destroy file contents. `-p` also removes each parent named in the operand, so '`rmdirx -p` a/b/c' behaves like '`rmdirx` a/b/c a/b a', stopping at the first one that cannot be removed. `--ignore-fail-on-non-empty` silences the not-empty failure (and only that one), and `-v` reports every directory processed.

## Permissions

Removing a directory needs write and search permission on its parent, not on the directory itself. A symbolic link to a directory is not a directory: it is refused rather than followed.

## Use cases

- Removing a directory while guaranteeing nothing inside it is lost.
- Pruning a chain of now-empty parents after moving files out with `-p`.
- Best-effort cleanup in scripts with `--ignore-fail-on-non-empty`.
- Checking that a directory really is empty: `rmdirx` fails, and says why, if it is not.
- Tidying up the empty leftovers of a build or an extraction with find.
- Undoing a '`mkdirx -p`' of a tree that never received any files.
- Auditing a cleanup with `-v`, which names every directory removed.

## Flags

```text
      --help                       display this help and exit
      --ignore-fail-on-non-empty   ignore each failure that is solely because a directory is non-empty
  -p, --parents                    remove DIRECTORY and its ancestors; e.g., 'rmdirx -p a/b/c' is similar to 'rmdirx a/b/c a/b a'
  -v, --verbose                    output a diagnostic for every directory processed
      --version                    output version information and exit
```

## Examples

Remove an empty directory:

```bash
rmdirx build
```

```powershell
rmdirx build
```

Remove several empty directories at once:

```bash
rmdirx a b c
```

```powershell
rmdirx a b c
```

Report each directory as it is removed:

```bash
rmdirx -v empty1 empty2
```

```powershell
rmdirx -v empty1 empty2
```

Remove a directory and its now-empty parents, reporting each:

```bash
rmdirx -pv out/reports/2024
```

```powershell
rmdirx -pv out\reports\2024
```

Remove a chain of parents and confirm the top one is gone:

```bash
rmdirx -p x/y/z && echox 'x is gone'
```

```powershell
rmdirx -p x\y\z; if ($LASTEXITCODE -eq 0) { echox 'x is gone' }
```

Clean up whatever is empty without failing on the rest:

```bash
rmdirx --ignore-fail-on-non-empty cache logs tmp
```

```powershell
rmdirx --ignore-fail-on-non-empty cache logs tmp
```

Prune parents as far as they are empty, stopping quietly at the first that is not:

```bash
rmdirx -p --ignore-fail-on-non-empty keep/sub
```

```powershell
rmdirx -p --ignore-fail-on-non-empty keep\sub
```

Refuse to remove a directory that still has files (exit status 1):

```bash
rmdirx logs; echox "exit $?"
```

```powershell
rmdirx logs; echox "exit $LASTEXITCODE"
```

Use the failure as an emptiness test:

```bash
rmdirx logs 2>/dev/null || echox 'logs still has files'
```

```powershell
rmdirx logs 2>$null; if ($LASTEXITCODE -ne 0) { echox 'logs still has files' }
```

Remove every empty directory below a tree, deepest first:

```bash
find tree -depth -type d -empty -exec rmdirx -v {} \;
```

```powershell
Get-ChildItem tree -Directory -Recurse | Sort-Object { $_.FullName.Length } -Descending | Where-Object { -not (Get-ChildItem $_.FullName -Force) } | ForEach-Object { rmdirx -v $_.FullName }
```

Create and then remove a temporary staging tree with the `gnux shell`:

```bash
gnux shell -c 'mkdirx -p staging/a && rmdirx -pv staging/a'
```

```powershell
gnux shell -c 'mkdirx -p staging/a && rmdirx -pv staging/a'
```

## Options

Each option has a page of its own, with its usage and examples.

- [--ignore-fail-on-non-empty](/docs/tools/rmdirx/ignore-fail-on-non-empty): Ignore each failure that is solely because a directory is non-empty.
- [-p, --parents](/docs/tools/rmdirx/parents): Remove DIRECTORY and its ancestors; e.g., '`rmdirx -p` a/b/c' is similar to '`rmdirx` a/b/c a/b a'.
- [-v, --verbose](/docs/tools/rmdirx/verbose): Output a diagnostic for every directory processed.

## Exit status

| Status | Meaning |
|--------|---------|
| 0 | success: every operand was processed |
| 1 | failure: an operand could not be processed (diagnosed on standard error), or a command-line mistake |

## Help in the terminal

```bash
rmdirx --help                # options, first examples, exit status
gnux help rmdirx             # this page: the full manual
gnux help rmdirx --OPTION    # one option in depth, with its examples
```
