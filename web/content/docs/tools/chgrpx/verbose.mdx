---
title: "-v, --verbose"
description: "Output a diagnostic for every file processed."
---

An option of [chgrpx](/docs/tools/chgrpx).

## Usage

```bash
chgrpx -v GROUP FILE...
chgrpx --verbose GROUP FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-v` | `--verbose` | none |  | output a diagnostic for every file processed |

## Examples

### Report every file processed

```bash tab="bash" tab-group="shell"
chgrpx -v staff a.txt b.txt
```

```powershell tab="PowerShell" tab-group="shell"
chgrpx -v staff a.txt b.txt
```

## Help in the terminal

```bash
gnux help chgrpx --verbose
```
