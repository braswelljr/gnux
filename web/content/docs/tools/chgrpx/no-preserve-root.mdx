---
title: "--no-preserve-root"
description: "Do not treat '/' specially."
---

An option of [chgrpx](/docs/tools/chgrpx).

## Usage

```bash
chgrpx --no-preserve-root GROUP FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--no-preserve-root` | none |  | do not treat '/' specially |

## Help in the terminal

```bash
gnux help chgrpx --no-preserve-root
```
