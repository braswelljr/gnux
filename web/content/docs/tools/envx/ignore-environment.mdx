---
title: "-i, --ignore-environment"
description: "Start with an empty environment."
---

An option of [envx](/docs/tools/envx).

## Usage

```bash
envx -i [-] [NAME=VALUE]... [COMMAND [ARG]...]
envx --ignore-environment [-] [NAME=VALUE]... [COMMAND [ARG]...]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-i` | `--ignore-environment` | none |  | start with an empty environment |

## Examples

Run a command with nothing but the variables given:

```bash
envx -i PATH=/usr/bin HOME=/tmp make test
```

```powershell
envx -i "PATH=$env:PATH" "TEMP=$env:TEMP" make test
```

Print an empty environment plus a single variable:

```bash
envx -i LANG=C.UTF-8
```

```powershell
envx -i LANG=C.UTF-8
```

Print the environment NUL-separated, with the NULs made visible:

```bash
envx -0 -i A=1 B=2 | catx -v
```

```powershell
envx -0 -i A=1 B=2 | catx -v
```

## Help in the terminal
