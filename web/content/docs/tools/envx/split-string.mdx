An option of [envx](/docs/tools/envx).

## Usage

```bash
envx -S S [-] [NAME=VALUE]... [COMMAND [ARG]...]
envx --split-string=S [-] [NAME=VALUE]... [COMMAND [ARG]...]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-S` | `--split-string` | `S` |  | process and split S into separate arguments; used to pass multiple arguments on shebang lines |

## Examples

Split one string into a command and its arguments, as on a '#!' line:

```bash
envx -S 'gnux shell -e' build.sh
```

```powershell
envx -S 'gnux shell -e' build.sh
```

## Help in the terminal

```bash
gnux help envx --split-string
```
