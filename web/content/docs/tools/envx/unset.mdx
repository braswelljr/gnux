---
title: "-u, --unset"
description: "Remove variable NAME from the environment."
---

An option of [envx](/docs/tools/envx).

## Usage

```bash
envx -u NAME [-] [NAME=VALUE]... [COMMAND [ARG]...]
envx --unset=NAME [-] [NAME=VALUE]... [COMMAND [ARG]...]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-u` | `--unset` | `NAME` |  | remove variable NAME from the environment |

## Examples

Drop variables for one command (`-u` may be repeated):

```bash
envx -u HOME -u USER gnux shell -c 'echox "[$HOME] [$USER]"'
```

```powershell
envx -u HOME -u USER gnux shell -c 'echox "[$HOME] [$USER]"'
```

Drop a variable and run in another directory:

```bash
envx -u DEBUG -C build ./configure
```

```powershell
envx -u DEBUG -C build cmake ..
```

## Help in the terminal

```bash
gnux help envx --unset
```
