---
title: "-C, --chdir"
description: "Change working directory to DIR."
---

An option of [envx](/docs/tools/envx).

## Usage

```bash
envx -C DIR [-] [NAME=VALUE]... [COMMAND [ARG]...]
envx --chdir=DIR [-] [NAME=VALUE]... [COMMAND [ARG]...]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-C` | `--chdir` | `DIR` |  | change working directory to DIR |

## Examples

Run a tool in another directory without leaving this one:

```bash
envx -C build pwdx
```

```powershell
envx -C build pwdx
```

Trace each step `envx` takes before running the command:

```bash
envx -v -C build pwdx
```

```powershell
envx -v -C build pwdx
```

## Help in the terminal

```bash
gnux help envx --chdir
```
