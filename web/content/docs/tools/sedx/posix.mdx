---
title: "--posix"
description: "Print nothing when n or N finds no next line, as POSIX has it."
---

An option of [sedx](/docs/tools/sedx).

## Usage

```bash
sedx --posix {script-only-if-no-other-script} [input-file]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--posix` | none |  | print nothing when n or N finds no next line, as POSIX has it |

## Help in the terminal

```bash
gnux help sedx --posix
```
