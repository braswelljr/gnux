---
title: "-u, --unbuffered"
description: "Flush the output after every line."
---

An option of [sedx](/docs/tools/sedx).

## Usage

```bash
sedx -u {script-only-if-no-other-script} [input-file]...
sedx --unbuffered {script-only-if-no-other-script} [input-file]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-u` | `--unbuffered` | none |  | flush the output after every line |

## Help in the terminal

```bash
gnux help sedx --unbuffered
```
