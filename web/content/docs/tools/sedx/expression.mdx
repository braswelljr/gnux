---
title: "-e, --expression"
description: "Add the SCRIPT to the commands to be executed."
---

An option of [sedx](/docs/tools/sedx).

## Usage

```bash
sedx -e SCRIPT {script-only-if-no-other-script} [input-file]...
sedx --expression=SCRIPT {script-only-if-no-other-script} [input-file]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-e` | `--expression` | `SCRIPT` |  | add the SCRIPT to the commands to be executed |

## Examples

### Strip comments and blank lines from a config file

```bash tab="bash" tab-group="shell"
sedx -e 's/#.*//' -e '/^[[:space:]]*$/d' nginx.conf
```

```powershell tab="PowerShell" tab-group="shell"
sedx -e 's/#.*//' -e '/^[[:space:]]*$/d' nginx.conf
```
