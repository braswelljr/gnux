---
title: "--silent"
description: "Same as --quiet."
---

An option of [sedx](/docs/tools/sedx).

## Usage

```bash
sedx --silent {script-only-if-no-other-script} [input-file]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--silent` | none |  | same as `--quiet` |

## Help in the terminal

```bash
gnux help sedx --silent
```
