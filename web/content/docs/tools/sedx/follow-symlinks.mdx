---
title: "--follow-symlinks"
description: "Follow symlinks when processing in place."
---

An option of [sedx](/docs/tools/sedx).

## Usage

```bash
sedx --follow-symlinks {script-only-if-no-other-script} [input-file]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--follow-symlinks` | none |  | follow symlinks when processing in place |

## Help in the terminal

```bash
gnux help sedx --follow-symlinks
```
