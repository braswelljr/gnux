title: "-E, --regexp-extended"
description: "Use extended regular expressions in the script (-r is accepted too)."
---

An option of [sedx](/docs/tools/sedx).

## Usage

```bash
sedx -E {script-only-if-no-other-script} [input-file]...
sedx --regexp-extended {script-only-if-no-other-script} [input-file]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-E` | `--regexp-extended` | none |  | use extended regular expressions in the script (`-r` is accepted too) |

## Examples

### Swap the first two comma-separated fields with extended regular expressions

```bash tab="bash" tab-group="shell"
sedx -E 's/^([^,]*),([^,]*)/\2,\1/' people.csv
```

```powershell tab="PowerShell" tab-group="shell"
sedx -E 's/^([^,]*),([^,]*)/\2,\1/' people.csv
```

```text title="Output"
Lovelace,Ada,1815
Hopper,Grace,1906
```
