---
title: "--strip-trailing-slashes"
description: "Remove any trailing slashes from each SOURCE argument."
---

An option of [mvx](/docs/tools/mvx).

## Usage

```bash
mvx --strip-trailing-slashes SOURCE... DIRECTORY
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--strip-trailing-slashes` | none |  | remove any trailing slashes from each SOURCE argument |

## Examples

### Move a directory given with a trailing slash

```bash tab="bash" tab-group="shell"
mvx --strip-trailing-slashes logs/ old-logs
```

```powershell tab="PowerShell" tab-group="shell"
mvx --strip-trailing-slashes logs\ old-logs
```

```bash
gnux help mvx --strip-trailing-slashes
```
