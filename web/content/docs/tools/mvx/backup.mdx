---

An option of [mvx](/docs/tools/mvx).

## Usage

```bash
mvx --backup[=CONTROL] SOURCE... DIRECTORY
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--backup` | `CONTROL` (optional) |  | make a backup of each existing destination file; CONTROL is none (off), simple (never), existing (nil) or numbered (t) |

## Help in the terminal

```bash
gnux help mvx --backup
```
