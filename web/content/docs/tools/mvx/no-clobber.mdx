---
title: "-n, --no-clobber"
description: "Do not overwrite an existing file."
---

An option of [mvx](/docs/tools/mvx).

## Usage

```bash
mvx -n SOURCE... DIRECTORY
mvx --no-clobber SOURCE... DIRECTORY
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-n` | `--no-clobber` | none |  | do not overwrite an existing file |

## Examples

Move without ever overwriting an existing file:

```bash
mvx -n photo.jpg ~/Pictures/
```

```powershell
mvx -n photo.jpg $HOME\Pictures
```

## Help in the terminal

```bash
gnux help mvx --no-clobber
```
