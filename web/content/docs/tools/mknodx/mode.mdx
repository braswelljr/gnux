---
title: "-m, --mode"
description: "Set file permission bits to MODE, not a=rw - umask."
---

An option of [mknodx](/docs/tools/mknodx).

## Usage

```bash
mknodx -m MODE NAME TYPE [MAJOR MINOR]
mknodx --mode=MODE NAME TYPE [MAJOR MINOR]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-m` | `--mode` | `MODE` |  | set file permission bits to MODE, not a=rw - umask |

## Examples

### Recreate /dev/null in a chroot (Linux, as root)

```bash tab="bash" tab-group="shell"
mknodx -m 666 /srv/chroot/dev/null c 1 3
```

### Create a loop device node (Linux, as root)

```bash tab="bash" tab-group="shell"
mknodx -m 660 /dev/loop8 b 7 8
```
