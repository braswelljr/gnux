title: "-i, --ignore-interrupts"

An option of [teex](/docs/tools/teex).

## Usage

```bash
teex -i [FILE]...
teex --ignore-interrupts [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-i` | `--ignore-interrupts` | none |  | ignore interrupt signals (accepted; no effect in `gnux`) |

## Help in the terminal

```bash
gnux help teex --ignore-interrupts
```
