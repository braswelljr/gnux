---
title: "--endian"
description: "Swap input bytes according the specified ORDER: little or big."
---

An option of [odx](/docs/tools/odx).

## Usage

```bash
odx --endian=ORDER [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--endian` | `ORDER` |  | swap input bytes according the specified ORDER: little or big |

## Examples

### Decode big-endian 32-bit integers

```bash tab="bash" tab-group="shell"
odx --endian=big -t u4 counts.bin
```

```powershell tab="PowerShell" tab-group="shell"
odx --endian=big -t u4 counts.bin
```
