An option of [odx](/docs/tools/odx).

## Usage

```bash
odx -s [FILE]...
odx --decimal-2-bytes[=string] [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-s` | `--decimal-2-bytes` | `string` (optional) |  | same as `-t` d2, select decimal 2-byte units |
