---
title: "-N, --read-bytes"
description: "Limit dump to BYTES input bytes."
---

An option of [odx](/docs/tools/odx).

## Usage

```bash
odx -N BYTES [FILE]...
odx --read-bytes=BYTES [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-N` | `--read-bytes` | `BYTES` |  | limit dump to BYTES input bytes |

## Examples

### Read the first four bytes (a magic number)

```bash tab="bash" tab-group="shell"
odx -A n -t x1 -N 4 image.png
```

```powershell tab="PowerShell" tab-group="shell"
odx -A n -t x1 -N 4 image.png
```

### Skip a 512-byte header and dump the next 64 bytes

```bash tab="bash" tab-group="shell"
odx -j 512 -N 64 -t x1 disk.img
```

```powershell tab="PowerShell" tab-group="shell"
odx -j 512 -N 64 -t x1 disk.img
```
