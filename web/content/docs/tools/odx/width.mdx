---
title: "-w, --width"
description: "Output BYTES bytes per output line."
---

An option of [odx](/docs/tools/odx).

## Usage

```bash
odx -w BYTES [FILE]...
odx --width=BYTES [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-w` | `--width` | `BYTES` |  | output BYTES bytes per output line |

## Examples

### Eight bytes per line

```bash tab="bash" tab-group="shell"
odx -w8 -t x1 data.bin
```

```powershell tab="PowerShell" tab-group="shell"
odx -w8 -t x1 data.bin
```

```bash
gnux help odx --width
```
