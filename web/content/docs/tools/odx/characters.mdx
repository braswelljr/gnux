---
title: "-c, --characters"
description: "Same as -t c, select printable characters or backslash escapes."
---

An option of [odx](/docs/tools/odx).

## Usage

```bash
odx -c [FILE]...
odx --characters[=string] [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-c` | `--characters` | `string` (optional) |  | same as `-t` c, select printable characters or backslash escapes |

## Examples

### Show every character, with escapes for invisible ones

```bash tab="bash" tab-group="shell"
odx -c notes.txt
```

```powershell tab="PowerShell" tab-group="shell"
odx -c notes.txt
```

### Look for Windows line endings in standard input

```bash tab="bash" tab-group="shell"
printfx 'a\r\nb\n' | odx -c
```

```powershell tab="PowerShell" tab-group="shell"
'a' | odx -c
```

## Help in the terminal

```bash
gnux help odx --characters
```
