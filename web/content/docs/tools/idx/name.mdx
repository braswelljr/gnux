---

An option of [idx](/docs/tools/idx).

## Usage

```bash
idx -n [USER]...
idx --name [USER]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-n` | `--name` | none |  | print a name instead of a number, for `-u`,`-g`,`-G` |

## Examples

### Print your user name

```bash tab="bash" tab-group="shell"
idx -un
```

```powershell tab="PowerShell" tab-group="shell"
idx -un
```

### List your groups by name

```bash tab="bash" tab-group="shell"
idx -Gn
```

```powershell tab="PowerShell" tab-group="shell"
idx -Gn
```

### Check membership of a group

```bash tab="bash" tab-group="shell"
idx -Gn | trx ' ' '\n' | grep -qx docker && echox member
```

```powershell tab="PowerShell" tab-group="shell"
if ((idx -Gn) -split ' ' -contains 'docker') { 'member' }
```

### Print IDs in the portable gnux shell

```bash tab="bash" tab-group="shell"
gnux shell -c 'idx -un && idx -Gn'
```

```powershell tab="PowerShell" tab-group="shell"
gnux shell -c 'idx -un && idx -Gn'
```

## Help in the terminal

```bash
gnux help idx --name
```
