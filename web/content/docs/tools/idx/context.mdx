---
title: "-Z, --context"
description: "Print only the security context of the process (not supported)."
---

An option of [idx](/docs/tools/idx).

## Usage

```bash
idx -Z [USER]...
idx --context [USER]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-Z` | `--context` | none |  | print only the security context of the process (not supported) |

## Help in the terminal

```bash
gnux help idx --context
```
