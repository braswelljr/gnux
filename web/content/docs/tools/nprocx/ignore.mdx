---
title: "--ignore"
description: "If possible, exclude N processing units."
---

An option of [nprocx](/docs/tools/nprocx).

## Usage

```bash
nprocx --ignore=N
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--ignore` | `N` | `0` | if possible, exclude N processing units |

## Examples

### Leave one core free

```bash tab="bash" tab-group="shell"
nprocx --ignore=1
```

```powershell tab="PowerShell" tab-group="shell"
nprocx --ignore=1
```

## Help in the terminal

```bash
gnux help nprocx --ignore
```
