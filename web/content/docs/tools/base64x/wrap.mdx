title: "-w, --wrap"
description: "Wrap encoded lines after COLS character (default 76); use 0 to disable line wrapping."
---

An option of [base64x](/docs/tools/base64x).

## Usage

```bash
base64x -w COLS [FILE]
base64x --wrap=COLS [FILE]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-w` | `--wrap` | `COLS` |  | wrap encoded lines after COLS character (default 76); use 0 to disable line wrapping |

## Examples

### Encode on a single line, without a newline

```bash tab="bash" tab-group="shell"
base64x -w 0 key.bin
```

```powershell tab="PowerShell" tab-group="shell"
base64x -w 0 key.bin
```

### Wrap encoded lines at 64 characters

```bash tab="bash" tab-group="shell"
base64x -w 64 cert.der
```

```powershell tab="PowerShell" tab-group="shell"
base64x -w 64 cert.der
```
