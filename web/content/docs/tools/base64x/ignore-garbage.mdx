An option of [base64x](/docs/tools/base64x).

## Usage

```bash
base64x -i [FILE]
base64x --ignore-garbage [FILE]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-i` | `--ignore-garbage` | none |  | when decoding, ignore non-alphabet characters |

## Examples

### Decode, skipping characters outside the alphabet

```bash tab="bash" tab-group="shell"
base64x -d -i messy.txt
```

```powershell tab="PowerShell" tab-group="shell"
base64x -d -i messy.txt
```
