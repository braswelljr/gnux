---
title: "-a, --all"
description: "Print all current settings in human-readable form."
---

An option of [sttyx](/docs/tools/sttyx).

## Usage

```bash
sttyx -a [-F DEVICE | --file=DEVICE] [SETTING]...
sttyx [-F DEVICE | --file=DEVICE] [-a|--all]
sttyx [-F DEVICE | --file=DEVICE] [-g|--save]
sttyx --all [-F DEVICE | --file=DEVICE] [SETTING]...
sttyx [-F DEVICE | --file=DEVICE] [-a|--all]
sttyx [-F DEVICE | --file=DEVICE] [-g|--save]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-a` | `--all` | none |  | print all current settings in human-readable form |

## Examples

### Set a serial line to 115200 baud, 8 data bits, no parity

```bash tab="bash" tab-group="shell"
sttyx -F /dev/ttyUSB0 115200 cs8 -parenb -cstopb
```

### See every setting

```bash tab="bash" tab-group="shell"
sttyx -a
```

## Help in the terminal

```bash
gnux help sttyx --all
```
