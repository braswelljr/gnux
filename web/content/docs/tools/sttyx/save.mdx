---
title: "-g, --save"
description: "Print all current settings in a stty-readable form."
---

An option of [sttyx](/docs/tools/sttyx).

## Usage

```bash
sttyx -g [-F DEVICE | --file=DEVICE] [SETTING]...
sttyx [-F DEVICE | --file=DEVICE] [-a|--all]
sttyx [-F DEVICE | --file=DEVICE] [-g|--save]
sttyx --save [-F DEVICE | --file=DEVICE] [SETTING]...
sttyx [-F DEVICE | --file=DEVICE] [-a|--all]
sttyx [-F DEVICE | --file=DEVICE] [-g|--save]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-g` | `--save` | none |  | print all current settings in a `stty``-readable` form |

## Help in the terminal

```bash
gnux help sttyx --save
```
