---
title: "-a, --all"
description: "Convert all blanks, instead of just initial blanks."
---

An option of [unexpandx](/docs/tools/unexpandx).

## Usage

```bash
unexpandx -a [FILE]...
unexpandx --all [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-a` | `--all` | none |  | convert all blanks, instead of just initial blanks |

## Examples

### Shrink a space-padded table by using tabs throughout

```bash tab="bash" tab-group="shell"
unexpandx -a table.txt
```

```powershell tab="PowerShell" tab-group="shell"
unexpandx -a table.txt
```

### See how many bytes tabs would save in a large file

```bash tab="bash" tab-group="shell"
unexpandx -a big.txt | wcx -c
```

```powershell tab="PowerShell" tab-group="shell"
unexpandx -a big.txt | wcx -c
```
