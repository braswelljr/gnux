---
title: "-t, --tabs"
description: "Have tabs N characters apart instead of 8 (enables -a), or use comma separated list of explicit tab positions."
---

An option of [unexpandx](/docs/tools/unexpandx).

## Usage

```bash
unexpandx -t N, LIST [FILE]...
unexpandx --tabs=N, LIST [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-t` | `--tabs` | `N, LIST` |  | have tabs N characters apart instead of 8 (enables `-a`), or use comma separated list of explicit tab positions |

## Examples

### Convert 4-space indentation and alignment to tabs

```bash tab="bash" tab-group="shell"
unexpandx -t 4 main.go
```

```powershell tab="PowerShell" tab-group="shell"
unexpandx -t 4 main.go
```

### Retab a Go file for gofmt, leaving alignment inside lines alone

```bash tab="bash" tab-group="shell"
unexpandx -t 4 --first-only main.go
```

```powershell tab="PowerShell" tab-group="shell"
unexpandx -t 4 --first-only main.go
```

### Retab a report laid out in fixed columns

```bash tab="bash" tab-group="shell"
unexpandx -t 10,20,40 report.txt
```

```powershell tab="PowerShell" tab-group="shell"
unexpandx -t 10,20,40 report.txt
```

### Edit with spaces, then hand the file back with tabs

```bash tab="bash" tab-group="shell"
expandx -t 4 a.go | unexpandx -t 4 --first-only > b.go
```

```powershell tab="PowerShell" tab-group="shell"
expandx -t 4 a.go | unexpandx -t 4 --first-only > b.go
```

### Restore the tabs a Makefile needs after an editor turned them into spaces

```bash tab="bash" tab-group="shell"
unexpandx -t 8 spaces.mk > Makefile
```

```powershell tab="PowerShell" tab-group="shell"
unexpandx -t 8 spaces.mk > Makefile
```
