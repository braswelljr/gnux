---
title: "--first-only"
description: "Convert only leading sequences of blanks (overrides -a)."
---

An option of [unexpandx](/docs/tools/unexpandx).

## Usage

```bash
unexpandx --first-only [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--first-only` | none |  | convert only leading sequences of blanks (overrides `-a`) |

## Examples

### Use 4-column stops but only for indentation

```bash tab="bash" tab-group="shell"
unexpandx -t 4 --first-only main.go
```

```powershell tab="PowerShell" tab-group="shell"
unexpandx -t 4 --first-only main.go
```

### Round-trip a file through expandx

```bash tab="bash" tab-group="shell"
expandx -t 4 a.go | unexpandx -t 4 --first-only > b.go
```

```powershell tab="PowerShell" tab-group="shell"
expandx -t 4 a.go | unexpandx -t 4 --first-only > b.go
```
