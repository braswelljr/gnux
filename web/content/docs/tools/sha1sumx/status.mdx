---
title: "--status"
description: "Don't output anything, status code shows success."
---

An option of [sha1sumx](/docs/tools/sha1sumx).

## Usage

```bash
sha1sumx --status [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--status` | none |  | don't output anything, status code shows success |

## Examples

### In CI, fail the build when a vendored file was changed by hand

```bash tab="bash" tab-group="shell"
sha1sumx -c --status vendor.sha1sums || { echox 'vendored files changed' >&2; exit 1; }
```

```powershell tab="PowerShell" tab-group="shell"
sha1sumx -c --status vendor.sha1sums; if ($LASTEXITCODE -ne 0) { Write-Error 'vendored files changed'; exit 1 }
```
