---
title: "-b, --binary"
description: "Read in binary mode."
---

An option of [sha1sumx](/docs/tools/sha1sumx).

## Usage

```bash
sha1sumx -b [FILE]...
sha1sumx --binary [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-b` | `--binary` | none |  | read in binary mode |

## Examples

### Mark the files as read in binary mode

```bash tab="bash" tab-group="shell"
sha1sumx -b file.iso
```

```powershell tab="PowerShell" tab-group="shell"
sha1sumx -b file.iso
```

## Help in the terminal

```bash
gnux help sha1sumx --binary
```
