---
title: "-d, --delimiters"
description: "Reuse characters from LIST instead of TABs."
---

An option of [pastex](/docs/tools/pastex).

## Usage

```bash
pastex -d LIST [FILE]...
pastex --delimiters=LIST [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-d` | `--delimiters` | `LIST` |  | reuse characters from LIST instead of TABs |

## Examples

### Use a comma instead of a TAB

```bash tab="bash" tab-group="shell"
pastex -d , names.txt ages.txt
```

```powershell tab="PowerShell" tab-group="shell"
pastex -d , names.txt ages.txt
```

### Join all the lines of a file into one comma-separated line

```bash tab="bash" tab-group="shell"
pastex -s -d , hosts.txt
```

```powershell tab="PowerShell" tab-group="shell"
pastex -s -d , hosts.txt
```

### Cycle through several delimiters

```bash tab="bash" tab-group="shell"
pastex -d ',;' a.txt b.txt c.txt
```

```powershell tab="PowerShell" tab-group="shell"
pastex -d ',;' a.txt b.txt c.txt
```

### Join columns with no delimiter at all

```bash tab="bash" tab-group="shell"
pastex -d '\0' first.txt last.txt
```

```powershell tab="PowerShell" tab-group="shell"
pastex -d '\0' first.txt last.txt
```

### Turn a column of numbers into one sum expression (1+2+3+4+5)

```bash tab="bash" tab-group="shell"
seqx 5 | pastex -s -d +
```

```powershell tab="PowerShell" tab-group="shell"
seqx 5 | pastex -s -d +
```
