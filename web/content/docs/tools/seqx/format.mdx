---
title: "-f, --format"
description: "Use printf style floating-point FORMAT."
---

An option of [seqx](/docs/tools/seqx).

## Usage

```bash
seqx -f FORMAT [FIRST [INCREMENT]] LAST
seqx --format=FORMAT [FIRST [INCREMENT]] LAST
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-f` | `--format` | `FORMAT` |  | use `printf` style floating-point FORMAT |

## Examples

Format each number with a prefix and fixed precision:

```bash
seqx -f 'item-%03.0f' 1 3
```

```powershell
seqx -f 'item-%03.0f' 1 3
```

Print percentages, with %% for a literal percent sign:

```bash
seqx -f '%.0f%%' 0 25 100
```

```powershell
seqx -f '%.0f%%' 0 25 100
```
