---
title: "-e, --canonicalize-existing"
description: "Canonicalize by following every symlink in every component recursively; all components must exist."
---

An option of [readlinkx](/docs/tools/readlinkx).

## Usage

```bash
readlinkx -e FILE...
readlinkx --canonicalize-existing FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-e` | `--canonicalize-existing` | none |  | canonicalize by following every symlink in every component recursively; all components must exist |

## Examples

### Require the whole path to exist

```bash tab="bash" tab-group="shell"
readlinkx -e config/app.yaml
```

```powershell tab="PowerShell" tab-group="shell"
readlinkx -e config/app.yaml
```

### Explain why a name cannot be resolved

```bash tab="bash" tab-group="shell"
readlinkx -v -e missing/file
```

```powershell tab="PowerShell" tab-group="shell"
readlinkx -v -e missing/file
```

gnux help readlinkx --canonicalize-existing
