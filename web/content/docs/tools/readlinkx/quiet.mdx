---
title: "-q, --quiet"
description: "Suppress most error messages (on by default)."
---

An option of [readlinkx](/docs/tools/readlinkx).

## Usage

```bash
readlinkx -q FILE...
readlinkx --quiet FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-q` | `--quiet` | none |  | suppress most error messages (on by default) |

## Help in the terminal

```bash
gnux help readlinkx --quiet
```
