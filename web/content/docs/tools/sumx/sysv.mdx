---
title: "-s, --sysv"
description: "Use the System V sum algorithm, use 512-byte blocks."
---

An option of [sumx](/docs/tools/sumx).

## Usage

```bash
sumx -s [FILE]...
sumx --sysv [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-s` | `--sysv` | none |  | use the System V `sum` algorithm, use 512-byte blocks |

## Examples

### Print the System V checksum and 512-byte block count

```bash tab="bash" tab-group="shell"
sumx -s README.md
```

```powershell tab="PowerShell" tab-group="shell"
sumx -s README.md
```

### Keep a checksum list for later comparison

```bash tab="bash" tab-group="shell"
sumx -s *.cfg > sums.txt
```

```powershell tab="PowerShell" tab-group="shell"
sumx -s (Get-ChildItem *.cfg).Name > sums.txt
```
