---
title: "-o, --operating-system"
description: "Print the operating system."
---

An option of [unamex](/docs/tools/unamex).

## Usage

```bash
unamex -o
unamex --operating-system
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-o` | `--operating-system` | none |  | print the operating system |

## Examples

### Print the operating system

```bash tab="bash" tab-group="shell"
unamex -o
```

```powershell tab="PowerShell" tab-group="shell"
unamex -o
```

## Help in the terminal

```bash
gnux help unamex --operating-system
```
