An option of [unamex](/docs/tools/unamex).

## Usage

```bash
unamex -a
unamex --all
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-a` | `--all` | none |  | print all information, in the following order, except omit `-p` and `-i` if unknown |

## Examples

### Print everything

```bash tab="bash" tab-group="shell"
unamex -a
```

```powershell tab="PowerShell" tab-group="shell"
unamex -a
```

### Record the platform in a log

```bash tab="bash" tab-group="shell"
unamex -a >> build.log
```

```powershell tab="PowerShell" tab-group="shell"
unamex -a >> build.log
```
