---
title: "-z, --zero"
description: "End each output line with NUL, not newline."
---

An option of [dirnamex](/docs/tools/dirnamex).

## Usage

```bash
dirnamex -z [OPTION] NAME...
dirnamex --zero [OPTION] NAME...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-z` | `--zero` | none |  | end each output line with NUL, not newline |

## Examples

Separate the output with NUL bytes instead of newlines:

```bash
dirnamex -z a/b c/d | od -c
```

```powershell
dirnamex -z a\b c\d | Format-Hex
```

## Help in the terminal

```bash
gnux help dirnamex --zero
```
