An option of [pathchkx](/docs/tools/pathchkx).

## Usage

```bash
pathchkx -p NAME...
pathchkx --basic NAME...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-p` | `--basic` | none |  | check for most POSIX systems |

## Examples

### Catch a name that will not travel to other systems

```bash tab="bash" tab-group="shell"
pathchkx -p 'Quarterly report.pdf'
```

```powershell tab="PowerShell" tab-group="shell"
pathchkx -p 'Quarterly report.pdf'
```

```text title="Output"
pathchkx: non-portable character ' ' in file name 'Quarterly report.pdf'
```
