---

An option of [fmtx](/docs/tools/fmtx).

## Usage

```bash
fmtx [-WIDTH] -p STRING [FILE]...
fmtx [-WIDTH] --prefix=STRING [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-p` | `--prefix` | `STRING` |  | reformat only lines beginning with STRING, reattaching the prefix to reformatted lines |

## Examples

### Reflow a block of shell comments after editing them

```bash tab="bash" tab-group="shell"
fmtx -p '#' -w 72 config.sh
```

```powershell tab="PowerShell" tab-group="shell"
fmtx -p '#' -w 72 config.sh
```
