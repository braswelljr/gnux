An option of [fmtx](/docs/tools/fmtx).

## Usage

```bash
fmtx [-WIDTH] -t [FILE]...
fmtx [-WIDTH] --tagged-paragraph [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-t` | `--tagged-paragraph` | none |  | indentation of first line different from second |

## Examples

### Keep a hanging indent

```bash tab="bash" tab-group="shell"
fmtx -t list.txt
```

```powershell tab="PowerShell" tab-group="shell"
fmtx -t list.txt
```

## Help in the terminal

```bash
gnux help fmtx --tagged-paragraph
```
