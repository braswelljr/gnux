---
title: "-i, --initial"
description: "Do not convert tabs after non blanks."
---

An option of [expandx](/docs/tools/expandx).

## Usage

```bash
expandx -i [FILE]...
expandx --initial [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-i` | `--initial` | none |  | do not convert tabs after non blanks |

## Examples

### Fix YAML indentation (tabs are invalid there) without touching tabs inside values

```bash tab="bash" tab-group="shell"
expandx -i -t 2 config.yml
```

```powershell tab="PowerShell" tab-group="shell"
expandx -i -t 2 config.yml
```
