---
title: "-o, --io-blocks"
description: "Treat SIZE as number of IO blocks instead of bytes."
---

An option of [truncatex](/docs/tools/truncatex).

## Usage

```bash
truncatex -o OPTION... FILE...
truncatex --io-blocks OPTION... FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-o` | `--io-blocks` | none |  | treat SIZE as number of IO blocks instead of bytes |

## Examples

### Size a file in I/O blocks rather than bytes

```bash tab="bash" tab-group="shell"
truncatex -o -s 8 blocks.bin
```

```powershell tab="PowerShell" tab-group="shell"
truncatex -o -s 8 blocks.bin
```
