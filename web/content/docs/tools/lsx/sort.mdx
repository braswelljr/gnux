title: "--sort"
description: "Sort by WORD instead of name: none (-U), size (-S), time (-t), version (-v), extension (-X), name, width."
---

An option of [lsx](/docs/tools/lsx).

## Usage

```bash
lsx --sort=WORD [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--sort` | `WORD` |  | sort by WORD instead of name: none (`-U`), size (`-S`), time (`-t`), version (`-v`), extension (`-X`), name, width |

## Examples

List in directory order without sorting, or sort with a word instead of a letter:

```bash
lsx -U && lsx --sort=size -l
```

```powershell
lsx -U; lsx --sort=size -l
```

## Help in the terminal

```bash
gnux help lsx --sort
```
