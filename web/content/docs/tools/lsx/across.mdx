---
title: "-x, --across"
description: "List entries by lines instead of by columns."
---

An option of [lsx](/docs/tools/lsx).

## Usage

```bash
lsx -x [FILE]...
lsx --across [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-x` | `--across` | none |  | list entries by lines instead of by columns |

## Examples

Fill rows across rather than down columns, in at most 60 columns:

```bash
lsx -x -w 60 /usr/bin
```

```powershell
lsx -x -w 60 C:\Windows\System32
```

## Help in the terminal

```bash
gnux help lsx --across
```
