---
title: "-p, --slash"
description: "Append / indicator to directories."
---

An option of [lsx](/docs/tools/lsx).

## Usage

```bash
lsx -p [FILE]...
lsx --slash [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-p` | `--slash` | none |  | append / indicator to directories |

## Examples

Show inode numbers and allocated blocks, with directories marked by a slash:

```bash
lsx -isp
```

```powershell
lsx -isp
```

## Help in the terminal

```bash
gnux help lsx --slash
```
