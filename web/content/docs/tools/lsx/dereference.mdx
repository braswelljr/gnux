---
title: "-L, --dereference"
description: "When showing file information for a symbolic link, show information for the file the link references rather than for the link itself."
---

An option of [lsx](/docs/tools/lsx).

## Usage

```bash
lsx -L [FILE]...
lsx --dereference [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-L` | `--dereference` | none |  | when showing file information for a symbolic link, show information for the file the link references rather than for the link itself |

## Examples

Follow symbolic links: those named on the command line (`-H`), or all of them (`-L`):

```bash
lsx -lH current && lsx -lL lib/
```

```powershell
lsx -lH current; lsx -lL lib
```

## Help in the terminal

```bash
gnux help lsx --dereference
```
