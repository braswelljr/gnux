---
title: "--si"
description: "Likewise, but use powers of 1000 not 1024."
---

An option of [lsx](/docs/tools/lsx).

## Usage

```bash
lsx --si [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--si` | none |  | likewise, but use powers of 1000 not 1024 |

## Examples

Largest files first, with sizes in powers of 1000:

```bash
lsx -lS --si downloads/
```

```powershell
lsx -lS --si downloads
```

## Help in the terminal

```bash
gnux help lsx --si
```
