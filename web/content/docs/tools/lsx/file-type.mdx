An option of [lsx](/docs/tools/lsx).

## Usage

```bash
lsx --file-type [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--file-type` | none |  | likewise, except do not append '*' |

## Examples

### Color by file type and mark types (but not executables) when writing to a terminal

```bash tab="bash" tab-group="shell"
lsx --color=auto --file-type -C -T 4
```

```powershell tab="PowerShell" tab-group="shell"
lsx --color=auto --file-type -C -T 4
```

## Help in the terminal

```bash
gnux help lsx --file-type
```
