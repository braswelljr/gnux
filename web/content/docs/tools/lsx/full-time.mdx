An option of [lsx](/docs/tools/lsx).

## Usage

```bash
lsx --full-time [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--full-time` | none |  | like `-l --time-style`=full-iso |

## Examples

### Show complete timestamps, or a custom format

```bash tab="bash" tab-group="shell"
lsx --full-time notes.txt && lsx -l --time-style=+%Y-%m-%d notes.txt
```

```powershell tab="PowerShell" tab-group="shell"
lsx --full-time notes.txt; lsx -l --time-style=+%Y-%m-%d notes.txt
```
