An option of [lsx](/docs/tools/lsx).

## Usage

```bash
lsx -A [FILE]...
lsx --almost-all [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-A` | `--almost-all` | none |  | do not list implied . and .. |

## Examples

### Count the entries in a directory, hidden ones included

```bash tab="bash" tab-group="shell"
lsx -A | wcx -l
```

```powershell tab="PowerShell" tab-group="shell"
lsx -A | wcx -l
```

## Help in the terminal

```bash
gnux help lsx --almost-all
```
