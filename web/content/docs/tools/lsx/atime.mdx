An option of [lsx](/docs/tools/lsx).

## Usage

```bash
lsx -u [FILE]...
lsx --atime [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-u` | `--atime` | none |  | with `-lt`: sort by, and show, access time; with `-l`: show access time and sort by name; otherwise: sort by access time, newest first |

## Examples

Sort by last access time (`-u`) or status change time (`-c`), showing that time:

```bash
lsx -ltu cache/ && lsx -lt --time=ctime cache/
```

```powershell
lsx -ltu cache; lsx -lt --time=ctime cache
```
