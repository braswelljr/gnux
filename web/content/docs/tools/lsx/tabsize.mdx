---
title: "-T, --tabsize"
description: "Assume tab stops at each COLS instead of 8."
---

An option of [lsx](/docs/tools/lsx).

## Usage

```bash
lsx -T COLS [FILE]...
lsx --tabsize=COLS [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-T` | `--tabsize` | `COLS` |  | assume tab stops at each COLS instead of 8 |

## Examples

Color by file type and mark types (but not executables) when writing to a terminal:

```bash
lsx --color=auto --file-type -C -T 4
```

```powershell
lsx --color=auto --file-type -C -T 4
```

## Help in the terminal

```bash
gnux help lsx --tabsize
```
