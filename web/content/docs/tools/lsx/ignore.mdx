---
title: "-I, --ignore"
description: "Do not list implied entries matching shell PATTERN."
---

An option of [lsx](/docs/tools/lsx).

## Usage

```bash
lsx -I PATTERN [FILE]...
lsx --ignore=PATTERN [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-I` | `--ignore` | `PATTERN` |  | do not list implied entries matching shell PATTERN |

## Examples

### One name per line, directories first, skipping object files

```bash tab="bash" tab-group="shell"
lsx -1 --group-directories-first -I '*.o' build/
```

```powershell tab="PowerShell" tab-group="shell"
lsx -1 --group-directories-first -I '*.o' build
```

## Help in the terminal

```bash
gnux help lsx --ignore
```
