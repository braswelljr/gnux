title: "lsx"
description: "List information about files and directory contents."
---

Mirrors GNU `ls`. Run it as `lsx`, or as `gnux lsx`.

## Synopsis

```bash
lsx [OPTION]... [FILE]...
```

## GNU reference

- [GNU coreutils manual: ls invocation](https://www.gnu.org/software/coreutils/manual/html_node/ls-invocation.html)
- [Source: src/ls.c in coreutils/coreutils](https://github.com/coreutils/coreutils/blob/master/src/ls.c)

## Description

`lsx` lists each FILE, or the current directory when none is given. Operands that are not directories are listed first, then the contents of each directory under a 'dir:' header. Entries whose names start with '.' are hidden unless `-a` or `-A` is given. On a terminal the names are arranged in columns sized to the window; when the output is piped or redirected there is one name per line. `-l` selects the long format (mode, `link` count, owner, group, size, timestamp and name), where timestamps from the last six months show the time of day and older ones show the year. Entries are sorted by name using plain byte comparison - the C locale's collation, so uppercase sorts before lowercase regardless of the environment's locale - or by time (`-t`), size (`-S`), extension (`-X`) or version (`-v`), optionally reversed with `-r`. When several flags of one family are given (`-l`/-1/`-C`/`-x`/`-m`, the sort keys, `-a`/`-A`, `-c`/`-u`/`--time`, …) the last one on the command line wins, as in GNU `ls`. Names are quoted in GNU's styles: on a terminal, for the shell where a shell would need it ('a b', 'new'$'\n''line'), with an unquoted name moved one column right to line up with quoted ones; otherwise as they are. `--quoting-style`=WORD picks literal (`-N`), shell, shell-always, shell-escape, shell-escape-always, c (`-Q`), c-maybe, escape (`-b`), locale or clocale, and the QUOTING_STYLE variable does when no option does. On a terminal `-q`, or a style that leaves control characters as they are, prints '?' for them, unless `--show-control-chars`. `--format`=WORD and `--indicator-style`=WORD are the long forms of the format and indicator options. `--zero` ends each line with NUL instead of a newline (and implies -1, `-N`, `--show-control-chars` and no color unless later options say otherwise). `--block-size`=SIZE scales sizes in the long format and the `-s` counts (K, 1M, KB, human-readable, si; LS_BLOCK_SIZE and BLOCK_SIZE when no option gives one), and `-k` counts `-s` blocks in KiB. `--author` adds the author column, which is the owner. `--hyperlink`[=WHEN] makes each name a terminal hyperlink to its file:// URL. `-D` (`--dired`) adds the marks Emacs' dired reads: each long-format line indented two spaces, then //DIRED// and //SUBDIRED// with the byte offsets of each name and directory header; it implies `-l`, turns `--hyperlink` off, and cannot be combined with `--zero`. Beyond GNU, `lsx` has `gnux`'s terminal view, all of it in options of `gnux`'s own that GNU `ls` does not have. On a terminal it is on by default (`--pretty`=auto): every column of the long format is colored (permission bits, owner, size, `date`, `link` count), with a `--header` row, `-h` sizes and `--group-directories-first`, each unless an option already decides it. When the output is piped or redirected nothing changes, so scripts and other programs still read GNU's output; `--pretty` (or GNUX_PRETTY=always) asks for the view anyway, and `--pretty`=never (or GNUX_PRETTY=never) turns it off everywhere. `--theme`=NAME, or GNUX_THEME=NAME[:KEY=CODE...], picks one of the built-in themes that `gnux` themes shows (vscode, github, one, solarized, gruvbox, catppuccin, tokyo-night and more, each in a dark and a light variant that the family's name picks from the background, or GNUX_BACKGROUND) and overrides single colors by their two-letter keys; NO_COLOR keeps the view uncolored. `--color-scale`[=size|age|all] colors sizes by magnitude and timestamps by age. `--tree` draws the operands as trees, as one table in the long format, and `--level`=DEPTH limits `--tree` and `-R`. `--icons`[=WHEN] (GNUX_ICONS) puts a Nerd Font icon before each name; it needs a Nerd Font in the terminal, so it is off unless asked for. `--git` adds a two-letter git status column (staged, then unstaged: - unchanged, N new, M modified, D deleted, T type changed, I ignored, U conflicted; a directory shows the most significant status inside it), read from the repository without running git, and `--git-ignore` leaves out what .gitignore rules exclude. `--only-dirs` and `--only-files` filter what is shown (the last one given wins; `-R` still descends), `--total-size` gives a directory the size of everything in it, and `--octal-permissions` adds the mode in octal. A tree's rows carry no `--dired` offsets. The exit status is 0 on success, 1 for minor problems such as an entry that cannot be examined, and 2 for serious trouble such as an operand that cannot be accessed.

## Permissions

Listing a directory needs read permission on it; examining its entries (anything beyond bare names: `-l`, `-s`, `-i`, `-F`, `--color`, sorting by time or size) also needs search permission. Entries that cannot be examined are still listed, with '?' in place of the unknown fields. On Windows, which has no POSIX owner, group, inode or block count, those columns hold placeholders, and with no POSIX permission bits every directory is colored as a plain directory, never as other-writable or sticky.

## Use cases

- Seeing what is in a directory at a glance.
- Inspecting permissions, ownership, sizes and timestamps with `-l`.
- Finding the newest or largest files with `-lt` or `-lS`.
- Walking a tree with `-R`, or feeding one name per line to a script with -1.
- Showing hidden files with `-A`, or telling file types apart with `-F` or `--color`.
- Checking that a build or download produced the expected files before the next step runs.
- Comparing versioned release directories in natural order with `-v`.
- Auditing which files changed recently by sorting on modification, access or change time.
- Producing stable, script-friendly listings (one per line, no colors) that behave the same on every platform.
- Spotting oddly named files (spaces, control characters) with `-Q`, `-b` or `-q`.
- Getting a colored overview of a project on a terminal, with no other tool installed.
- Seeing a project's layout at a glance with `--tree` and `--level`.
- Checking which files a change touched, and what git ignores, with `--git` and `--git-ignore`.

```text
  -D, --dired                       generate output designed for Emacs' dired mode
  -b, --escape                      print C-style escapes for nongraphic characters

      --git                         with -l, print each file's git status (staged, then unstaged)
      --git-ignore                  do not list entries that .gitignore rules exclude
      --group-directories-first     group directories before files; any use of --sort=none (-U) disables grouping
      --header                      with -l, print a row naming each column
      --help                        display this help and exit
      --hide PATTERN                do not list implied entries matching shell PATTERN (overridden by -a or -A)
  -q, --hide-control-chars          print ? instead of nongraphic characters

      --hyperlink WHEN[="always"]   hyperlink file names WHEN: 'always' (the default when WHEN is omitted), 'auto', or 'never'
      --icons WHEN[="always"]       show an icon (Nerd Font) before each name WHEN: 'always' (the default when WHEN is omitted), 'auto', or 'never'; GNUX_ICONS sets the default
  -I, --ignore PATTERN              do not list implied entries matching shell PATTERN
  -B, --ignore-backups              do not list implied entries ending with ~
      --indicator-style WORD        append indicator with style WORD to entry names: none (default), slash (-p), file-type (--file-type), classify (-F)
  -i, --inode                       print the index number of each file
  -k, --kibibytes                   default to 1024-byte blocks for file system usage; used only with -s and per directory totals
      --level DEPTH                 with -R or --tree, go at most DEPTH levels deep
  -N, --literal                     print entry names without quoting
  -l, --long                        use a long listing format
  -o, --long-no-group               like -l, but do not list group information
  -g, --long-no-owner               like -l, but do not list owner
  -G, --no-group                    in a long listing, don't print group names
  -n, --numeric-uid-gid             like -l, but list numeric user and group IDs
      --octal-permissions           with -l, print the permission bits in octal too
  -1, --one-per-line                list one file per line
      --only-dirs                   list only directories
      --only-files                  list only files, not directories
      --pretty WHEN[="always"]      the gnux terminal view WHEN: 'always' (the default when WHEN is omitted), 'auto' (the default: on a terminal), or 'never'; colors every column, adds --header, -h and --group-directories-first; GNUX_PRETTY sets the default
  -Q, --quote-name                  enclose entry names in double quotes
      --quoting-style WORD          use quoting style WORD for entry names: literal, locale, shell, shell-always, shell-escape, shell-escape-always, c, escape (overrides QUOTING_STYLE environment variable)
  -R, --recursive                   list subdirectories recursively
  -r, --reverse                     reverse order while sorting
      --show-control-chars          show nongraphic characters as-is (the default, unless program is 'ls' and output is a terminal)
      --si                          likewise, but use powers of 1000 not 1024
  -s, --size                        print the allocated size of each file, in blocks
  -p, --slash                       append / indicator to directories
      --sort WORD                   sort by WORD instead of name: none (-U), size (-S), time (-t), version (-v), extension (-X), name, width
  -X, --sort-extension              sort alphabetically by entry extension
  -S, --sort-size                   sort by file size, largest first
  -t, --sort-time                   sort by time, newest first; see --time
  -v, --sort-version                natural sort of (version) numbers within text
  -T, --tabsize COLS                assume tab stops at each COLS instead of 8
      --theme NAME                  color the view with the built-in theme NAME (gnux themes shows them all); GNUX_THEME sets the default
      --time WORD                   select which timestamp is shown or sorted on, WORD: access time (-u): atime, access, use; metadata change time (-c): ctime, status; modified time (default): mtime, modification; birth time: birth, creation
      --time-style TIME_STYLE       time/date format with -l, TIME_STYLE: full-iso, long-iso, iso, locale, or +FORMAT
      --total-size                  show a directory's size as the total of everything in it
      --tree                        list subdirectories recursively, drawn as a tree
  -U, --unsorted                    do not sort; list entries in directory order
      --version                     output version information and exit
  -w, --width COLS                  set output width to COLS; 0 means no limit
      --zero                        end each output line with NUL, not newline
```

## Examples

### List the current directory

```bash tab="bash" tab-group="shell"
lsx
```

```powershell tab="PowerShell" tab-group="shell"
lsx
```

### Long listing including hidden files, with human-readable sizes

```bash tab="bash" tab-group="shell"
lsx -lah
```

```powershell tab="PowerShell" tab-group="shell"
lsx -lah
```

### Newest files first, in the long format

```bash tab="bash" tab-group="shell"
lsx -lt /var/log
```

```powershell tab="PowerShell" tab-group="shell"
lsx -lt $env:TEMP
```

### Largest files first, with sizes in powers of 1000

```bash tab="bash" tab-group="shell"
lsx -lS --si downloads/
```

```powershell tab="PowerShell" tab-group="shell"
lsx -lS --si downloads
```

### Smallest files first (reverse the size sort)

```bash tab="bash" tab-group="shell"
lsx -lShr downloads/
```

```powershell tab="PowerShell" tab-group="shell"
lsx -lShr downloads
```

### Recursively list a tree, marking directories and executables

```bash tab="bash" tab-group="shell"
lsx -RF src/
```

```powershell tab="PowerShell" tab-group="shell"
lsx -RF src
```

### One name per line, directories first, skipping object files

```bash tab="bash" tab-group="shell"
lsx -1 --group-directories-first -I '*.o' build/
```

```powershell tab="PowerShell" tab-group="shell"
lsx -1 --group-directories-first -I '*.o' build
```

### List a directory itself rather than its contents, with ISO timestamps

```bash tab="bash" tab-group="shell"
lsx -ld --time-style=long-iso ~/projects
```

```powershell tab="PowerShell" tab-group="shell"
lsx -ld --time-style=long-iso $HOME\projects
```

### Sort release directories by version number, so v1.10 comes after v1.9

```bash tab="bash" tab-group="shell"
lsx -v releases/
```

```powershell tab="PowerShell" tab-group="shell"
lsx -v releases
```

### Group files by extension, as a comma-separated list

```bash tab="bash" tab-group="shell"
lsx -X -m assets/
```

```powershell tab="PowerShell" tab-group="shell"
lsx -X -m assets
```

### Fill rows across rather than down columns, in at most 60 columns

```bash tab="bash" tab-group="shell"
lsx -x -w 60 /usr/bin
```

```powershell tab="PowerShell" tab-group="shell"
lsx -x -w 60 C:\Windows\System32
```

### Show inode numbers and allocated blocks, with directories marked by a slash

```bash tab="bash" tab-group="shell"
lsx -isp
```

```powershell tab="PowerShell" tab-group="shell"
lsx -isp
```

### Long format with numeric user and group IDs, or without the owner or group columns

```bash tab="bash" tab-group="shell"
lsx -n data/ && lsx -g data/ && lsx -o data/ && lsx -lG data/
```

```powershell tab="PowerShell" tab-group="shell"
lsx -n data; lsx -g data; lsx -o data; lsx -lG data
```

### Sort by last access time (-u) or status change time (-c), showing that time

```bash tab="bash" tab-group="shell"
lsx -ltu cache/ && lsx -lt --time=ctime cache/
```

```powershell tab="PowerShell" tab-group="shell"
lsx -ltu cache; lsx -lt --time=ctime cache
```

### Show complete timestamps, or a custom format

```bash tab="bash" tab-group="shell"
lsx --full-time notes.txt && lsx -l --time-style=+%Y-%m-%d notes.txt
```

```powershell tab="PowerShell" tab-group="shell"
lsx --full-time notes.txt; lsx -l --time-style=+%Y-%m-%d notes.txt
```

### Hide temporary and backup files, unless -a or -A is also given

```bash tab="bash" tab-group="shell"
lsx -B --hide='*.tmp' work/
```

```powershell tab="PowerShell" tab-group="shell"
lsx -B --hide='*.tmp' work
```

### Quote names, or escape control characters, to spot odd file names

```bash tab="bash" tab-group="shell"
lsx -Q && lsx -b && lsx -q
```

```powershell tab="PowerShell" tab-group="shell"
lsx -Q; lsx -b; lsx -q
```

### Follow symbolic links: those named on the command line (-H), or all of them (-L)

```bash tab="bash" tab-group="shell"
lsx -lH current && lsx -lL lib/
```

```powershell tab="PowerShell" tab-group="shell"
lsx -lH current; lsx -lL lib
```

### List in directory order without sorting, or sort with a word instead of a letter

```bash tab="bash" tab-group="shell"
lsx -U && lsx --sort=size -l
```

```powershell tab="PowerShell" tab-group="shell"
lsx -U; lsx --sort=size -l
```

### Color by file type and mark types (but not executables) when writing to a terminal

```bash tab="bash" tab-group="shell"
lsx --color=auto --file-type -C -T 4
```

```powershell tab="PowerShell" tab-group="shell"
lsx --color=auto --file-type -C -T 4
```

### Count the entries in a directory, hidden ones included

```bash tab="bash" tab-group="shell"
lsx -A | wcx -l
```

```powershell tab="PowerShell" tab-group="shell"
lsx -A | wcx -l
```

### Print the name of the most recently modified file

```bash tab="bash" tab-group="shell"
lsx -t | headx -n 1
```

```powershell tab="PowerShell" tab-group="shell"
lsx -t | headx -n 1
```

### Fail a script when an expected file is missing (exit status 2)

```bash tab="bash" tab-group="shell"
lsx dist/app.js > /dev/null || echox 'build output missing'
```

```powershell tab="PowerShell" tab-group="shell"
lsx dist/app.js > $null; if ($LASTEXITCODE -ne 0) { 'build output missing' }
```

### Run the same listing through the portable gnux shell

```bash tab="bash" tab-group="shell"
gnux shell -c 'lsx -1 *.log | wcx -l'
```

```powershell tab="PowerShell" tab-group="shell"
gnux shell -c 'lsx -1 *.log | wcx -l'
```

### Pass every name to another tool safely, even ones with spaces or newlines

```bash tab="bash" tab-group="shell"
lsx --zero downloads | xargsx -0 sha256sumx
```

```powershell tab="PowerShell" tab-group="shell"
lsx --zero downloads | xargsx -0 sha256sumx
```

### Print names you can paste straight back into a shell command

```bash tab="bash" tab-group="shell"
lsx --quoting-style=shell-escape uploads
```

```powershell tab="PowerShell" tab-group="shell"
lsx --quoting-style=shell-escape uploads
```

### Show the size of each video in megabytes

```bash tab="bash" tab-group="shell"
lsx -l --block-size=M videos
```

```powershell tab="PowerShell" tab-group="shell"
lsx -l --block-size=M videos
```

### You open a project you have not seen before and want its layout two levels deep, directories first

```bash tab="bash" tab-group="shell"
lsx --tree --level=2 --group-directories-first ~/src/webapp
```

```powershell tab="PowerShell" tab-group="shell"
lsx --tree --level=2 --group-directories-first $HOME\src\webapp
```

### Before committing, see which files in src/ you changed, staged or created, with the files git ignores left out

```bash tab="bash" tab-group="shell"
lsx -l --git --git-ignore src/
```

```powershell tab="PowerShell" tab-group="shell"
lsx -l --git --git-ignore src
```

### Your downloads folder is full: find the biggest folders, each sized by everything in it, with the sizes colored by magnitude

```bash tab="bash" tab-group="shell"
lsx -lS --total-size --only-dirs --color-scale=size ~/Downloads
```

```powershell tab="PowerShell" tab-group="shell"
lsx -lS --total-size --only-dirs --color-scale=size $HOME\Downloads
```

### Your terminal has a Nerd Font and switches between light and dark with the system: make icons and the GitHub colors, in the matching variant, the default in every new shell

```bash tab="bash" tab-group="shell"
echox 'export GNUX_ICONS=auto GNUX_THEME=github' >> ~/.bashrc
```

```powershell tab="PowerShell" tab-group="shell"
Add-Content $PROFILE '$env:GNUX_ICONS = "auto"; $env:GNUX_THEME = "github"'
```

### Page through the colored view, which a pipe would otherwise turn off

```bash tab="bash" tab-group="shell"
lsx -l --pretty=always /etc | less -R
```

```powershell tab="PowerShell" tab-group="shell"
lsx -l --pretty=always C:\Windows | Out-Host -Paging
```

### You prefer GNU ls's plain look on your terminal too: switch the view off in every shell (pipes are always plain)

```bash tab="bash" tab-group="shell"
export GNUX_PRETTY=never
```

```powershell tab="PowerShell" tab-group="shell"
$env:GNUX_PRETTY = 'never'
```

### Make every name clickable in a terminal that supports hyperlinks

```bash tab="bash" tab-group="shell"
lsx --hyperlink=auto ~/projects
```

```powershell tab="PowerShell" tab-group="shell"
lsx --hyperlink=auto $HOME\projects
```

- [--only-dirs](/docs/tools/lsx/only-dirs): List only directories.
- [--only-files](/docs/tools/lsx/only-files): List only files, not directories.
- [--pretty](/docs/tools/lsx/pretty): The `gnux` terminal view WHEN: 'always' (the default when WHEN is omitted), 'auto' (the default: on a terminal), or 'never'; colors every column, adds `--header`, `-h` and `--group-directories-first`; GNUX_PRETTY sets the default.
- [-Q, --quote-name](/docs/tools/lsx/quote-name): Enclose entry names in double quotes.
- [--quoting-style](/docs/tools/lsx/quoting-style): Use quoting style WORD for entry names: literal, locale, shell, shell-always, shell-escape, shell-escape-always, c, escape (overrides QUOTING_STYLE environment variable).
- [-R, --recursive](/docs/tools/lsx/recursive): List subdirectories recursively.
- [-r, --reverse](/docs/tools/lsx/reverse): Reverse order while sorting.
- [--show-control-chars](/docs/tools/lsx/show-control-chars): Show nongraphic characters as-is (the default, unless program is '`ls`' and output is a terminal).
- [--si](/docs/tools/lsx/si): Likewise, but use powers of 1000 not 1024.
- [-s, --size](/docs/tools/lsx/size): Print the allocated size of each file, in blocks.
- [-p, --slash](/docs/tools/lsx/slash): Append / indicator to directories.
- [--sort](/docs/tools/lsx/sort): Sort by WORD instead of name: none (`-U`), size (`-S`), time (`-t`), version (`-v`), extension (`-X`), name, width.
- [-X, --sort-extension](/docs/tools/lsx/sort-extension): Sort alphabetically by entry extension.
- [-S, --sort-size](/docs/tools/lsx/sort-size): Sort by file size, largest first.
- [-t, --sort-time](/docs/tools/lsx/sort-time): Sort by time, newest first; see `--time`.
- [-v, --sort-version](/docs/tools/lsx/sort-version): Natural sort of (version) numbers within text.
- [-T, --tabsize](/docs/tools/lsx/tabsize): Assume tab stops at each COLS instead of 8.
- [--theme](/docs/tools/lsx/theme): Color the view with the built-in theme NAME (`gnux` themes shows them all); GNUX_THEME sets the default.
- [--time](/docs/tools/lsx/time): Select which timestamp is shown or sorted on, WORD: access time (`-u`): atime, access, use; metadata change time (`-c`): ctime, status; modified time (default): mtime, modification; birth time: birth, creation.
- [--time-style](/docs/tools/lsx/time-style): Time/`date` format with `-l`, TIME_STYLE: full-iso, long-iso, iso, locale, or +FORMAT.
- [--total-size](/docs/tools/lsx/total-size): Show a directory's size as the total of everything in it.
- [--tree](/docs/tools/lsx/tree): List subdirectories recursively, drawn as a tree.
- [-U, --unsorted](/docs/tools/lsx/unsorted): Do not sort; list entries in directory order.
- [-w, --width](/docs/tools/lsx/width): Set output width to COLS; 0 means no limit.
- [--zero](/docs/tools/lsx/zero): End each output line with NUL, not newline.

## Exit status

| Status | Meaning |
|--------|---------|
| 0 | success |
| 1 | minor trouble: an entry found while listing could not be examined |
| 2 | serious trouble: a command-line operand could not be accessed, a directory could not be read, or a command-line mistake |

```bash
lsx --help                # options, first examples, exit status

gnux help lsx --OPTION    # one option in depth, with its examples
```
