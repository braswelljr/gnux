---
title: "--hyperlink"
description: "Hyperlink file names WHEN: 'always' (the default when WHEN is omitted), 'auto', or 'never'."
---

An option of [lsx](/docs/tools/lsx).

## Usage

```bash
lsx --hyperlink[=WHEN] [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--hyperlink` | `WHEN` (optional) |  | hyperlink file names WHEN: 'always' (the default when WHEN is omitted), 'auto', or 'never' |

## Examples

### Make every name clickable in a terminal that supports hyperlinks

```bash tab="bash" tab-group="shell"
lsx --hyperlink=auto ~/projects
```

```powershell tab="PowerShell" tab-group="shell"
lsx --hyperlink=auto $HOME\projects
```

## Help in the terminal

```bash
gnux help lsx --hyperlink
```
