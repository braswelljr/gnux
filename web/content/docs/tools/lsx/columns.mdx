---
title: "-C, --columns"
description: "List entries by columns."
---

An option of [lsx](/docs/tools/lsx).

## Usage

```bash
lsx -C [FILE]...
lsx --columns [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-C` | `--columns` | none |  | list entries by columns |

## Examples

### Color by file type and mark types (but not executables) when writing to a terminal

```bash tab="bash" tab-group="shell"
lsx --color=auto --file-type -C -T 4
```

```powershell tab="PowerShell" tab-group="shell"
lsx --color=auto --file-type -C -T 4
```

## Help in the terminal

```bash
gnux help lsx --columns
```
