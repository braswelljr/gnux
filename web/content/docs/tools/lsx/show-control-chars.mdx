---
title: "--show-control-chars"
description: "Show nongraphic characters as-is (the default, unless program is 'ls' and output is a terminal)."
---

An option of [lsx](/docs/tools/lsx).

## Usage

```bash
lsx --show-control-chars [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--show-control-chars` | none |  | show nongraphic characters as-is (the default, unless program is '`ls`' and output is a terminal) |

## Help in the terminal

```bash
gnux help lsx --show-control-chars
```
