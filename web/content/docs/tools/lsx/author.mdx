---
title: "--author"
description: "With -l, print the author of each file."
---

An option of [lsx](/docs/tools/lsx).

## Usage

```bash
lsx --author [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--author` | none |  | with `-l`, print the author of each file |

## Help in the terminal

```bash
gnux help lsx --author
```
