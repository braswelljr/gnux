An option of [lsx](/docs/tools/lsx).

## Usage

```bash
lsx -h [FILE]...
lsx --human-readable [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-h` | `--human-readable` | none |  | with `-l` and `-s`, print sizes like 1K 234M 2G etc. |

## Examples

### Long listing including hidden files, with human-readable sizes

```bash tab="bash" tab-group="shell"
lsx -lah
```

```powershell tab="PowerShell" tab-group="shell"
lsx -lah
```

### Smallest files first (reverse the size sort)

```bash tab="bash" tab-group="shell"
lsx -lShr downloads/
```

```powershell tab="PowerShell" tab-group="shell"
lsx -lShr downloads
```

## Help in the terminal

```bash
gnux help lsx --human-readable
```
