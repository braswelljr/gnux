---
title: "-B, --ignore-backups"
description: "Do not list implied entries ending with ~."
---

An option of [lsx](/docs/tools/lsx).

## Usage

```bash
lsx -B [FILE]...
lsx --ignore-backups [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-B` | `--ignore-backups` | none |  | do not list implied entries ending with ~ |

## Examples

Hide temporary and backup files, unless `-a` or `-A` is also given:

```bash
lsx -B --hide='*.tmp' work/
```

```powershell
lsx -B --hide='*.tmp' work
```

## Help in the terminal

```bash
gnux help lsx --ignore-backups
```
