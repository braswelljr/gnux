---
title: "-H, --dereference-command-line"
description: "Follow symbolic links listed on the command line."
---

An option of [lsx](/docs/tools/lsx).

## Usage

```bash
lsx -H [FILE]...
lsx --dereference-command-line [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-H` | `--dereference-command-line` | none |  | follow symbolic links listed on the command line |

## Examples

### Follow symbolic links: those named on the command line (-H), or all of them (-L)

```bash tab="bash" tab-group="shell"
lsx -lH current && lsx -lL lib/
```

```powershell tab="PowerShell" tab-group="shell"
lsx -lH current; lsx -lL lib
```

## Help in the terminal

```bash
gnux help lsx --dereference-command-line
```
