title: "-a, --all"
description: "Do not ignore entries starting with ."
---

An option of [lsx](/docs/tools/lsx).

## Usage

```bash
lsx -a [FILE]...
lsx --all [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-a` | `--all` | none |  | do not ignore entries starting with . |

## Examples

### Long listing including hidden files, with human-readable sizes

```bash tab="bash" tab-group="shell"
lsx -lah
```

```powershell tab="PowerShell" tab-group="shell"
lsx -lah
```

## Help in the terminal

```bash
gnux help lsx --all
```
