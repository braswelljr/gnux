---
title: "-m, --commas"
description: "Fill width with a comma separated list of entries."
---

An option of [lsx](/docs/tools/lsx).

## Usage

```bash
lsx -m [FILE]...
lsx --commas [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-m` | `--commas` | none |  | fill width with a comma separated list of entries |

## Examples

### Group files by extension, as a comma-separated list

```bash tab="bash" tab-group="shell"
lsx -X -m assets/
```

```powershell tab="PowerShell" tab-group="shell"
lsx -X -m assets
```

## Help in the terminal

```bash
gnux help lsx --commas
```
