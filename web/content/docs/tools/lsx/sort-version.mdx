---
title: "-v, --sort-version"
description: "Natural sort of (version) numbers within text."
---

An option of [lsx](/docs/tools/lsx).

## Usage

```bash
lsx -v [FILE]...
lsx --sort-version [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-v` | `--sort-version` | none |  | natural sort of (version) numbers within text |

## Examples

Sort release directories by version number, so v1.10 comes after v1.9:

```bash
lsx -v releases/
```

```powershell
lsx -v releases
```

## Help in the terminal

```bash
gnux help lsx --sort-version
```
