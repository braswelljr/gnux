---
title: "--only-dirs"
description: "List only directories."
---

An option of [lsx](/docs/tools/lsx).

## Usage

```bash
lsx --only-dirs [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--only-dirs` | none |  | list only directories |

## Examples

### Your downloads folder is full: find the biggest folders, each sized by everything in it, with the sizes colored by magnitude

```bash tab="bash" tab-group="shell"
lsx -lS --total-size --only-dirs --color-scale=size ~/Downloads
```

```powershell tab="PowerShell" tab-group="shell"
lsx -lS --total-size --only-dirs --color-scale=size $HOME\Downloads
```

## Help in the terminal

gnux help lsx --only-dirs
