An option of [lsx](/docs/tools/lsx).

## Usage

```bash
lsx -k [FILE]...
lsx --kibibytes [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-k` | `--kibibytes` | none |  | default to 1024-byte blocks for file system usage; used only with `-s` and per directory totals |

## Help in the terminal

```bash
gnux help lsx --kibibytes
```
