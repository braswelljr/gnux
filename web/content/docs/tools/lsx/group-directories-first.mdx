---
title: "--group-directories-first"
description: "Group directories before files; any use of --sort=none (-U) disables grouping."
---

An option of [lsx](/docs/tools/lsx).

## Usage

```bash
lsx --group-directories-first [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--group-directories-first` | none |  | group directories before files; any use of `--sort`=none (`-U`) disables grouping |

## Examples

### One name per line, directories first, skipping object files

```bash tab="bash" tab-group="shell"
lsx -1 --group-directories-first -I '*.o' build/
```

```powershell tab="PowerShell" tab-group="shell"
lsx -1 --group-directories-first -I '*.o' build
```
