---
title: "-R, --recursive"
description: "List subdirectories recursively."
---

An option of [lsx](/docs/tools/lsx).

## Usage

```bash
lsx -R [FILE]...
lsx --recursive [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-R` | `--recursive` | none |  | list subdirectories recursively |

## Examples

Recursively list a tree, marking directories and executables:

```bash
lsx -RF src/
```

```powershell
lsx -RF src
```

## Help in the terminal

```bash
gnux help lsx --recursive
```
