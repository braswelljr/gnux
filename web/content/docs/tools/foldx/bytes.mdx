---
title: "-b, --bytes"
description: "Count bytes rather than columns."
---

An option of [foldx](/docs/tools/foldx).

## Usage

```bash
foldx -b [FILE]...
foldx --bytes [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-b` | `--bytes` | none |  | count bytes rather than columns |

## Examples

### Split a long string into 64-byte lines

```bash tab="bash" tab-group="shell"
foldx -b -w 64 key.txt
```

```powershell tab="PowerShell" tab-group="shell"
foldx -b -w 64 key.txt
```

## Help in the terminal

```bash
gnux help foldx --bytes
```
