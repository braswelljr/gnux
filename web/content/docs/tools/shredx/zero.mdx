---
title: "-z, --zero"
description: "Add a final overwrite with zeros to hide shredding."
---

An option of [shredx](/docs/tools/shredx).

## Usage

```bash
shredx -z FILE...
shredx --zero FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-z` | `--zero` | none |  | add a final overwrite with zeros to hide shredding |

## Examples

### One random pass and then zeros, quicker for a large file

```bash tab="bash" tab-group="shell"
shredx -n 1 -z backup.img
```

```powershell tab="PowerShell" tab-group="shell"
shredx -n 1 -z backup.img
```

## Help in the terminal

```bash
gnux help shredx --zero
```
