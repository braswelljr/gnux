---
title: "-s, --size"
description: "Shred this many bytes (suffixes like K, M, G accepted)."
---

An option of [shredx](/docs/tools/shredx).

## Usage

```bash
shredx -s string FILE...
shredx --size=string FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-s` | `--size` | `string` |  | `shred` this many bytes (suffixes like K, M, G accepted) |

## Help in the terminal

```bash
gnux help shredx --size
```
