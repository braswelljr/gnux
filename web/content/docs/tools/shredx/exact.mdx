An option of [shredx](/docs/tools/shredx).

## Usage

```bash
shredx -x FILE...
shredx --exact FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-x` | `--exact` | none |  | do not round file sizes up to the next full block; this is the default for non-regular files |

## Help in the terminal

```bash
gnux help shredx --exact
```
