---
title: "--random-source"
description: "Get random bytes from FILE."
---

An option of [shredx](/docs/tools/shredx).

## Usage

```bash
shredx --random-source=FILE FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--random-source` | `FILE` |  | get random bytes from FILE |

## Help in the terminal

```bash
gnux help shredx --random-source
```
