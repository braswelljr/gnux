An option of [pinkyx](/docs/tools/pinkyx).

## Usage

```bash
pinkyx -i [USER]...
pinkyx --omit-where [USER]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-i` | `--omit-where` | none |  | omit the user's full name and remote host in short format |

## Help in the terminal

```bash
gnux help pinkyx --omit-where
```
