---
title: "-w, --omit-name"
description: "Omit the user's full name in short format."
---

An option of [pinkyx](/docs/tools/pinkyx).

## Usage

```bash
pinkyx -w [USER]...
pinkyx --omit-name [USER]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-w` | `--omit-name` | none |  | omit the user's full name in short format |

## Help in the terminal

```bash
gnux help pinkyx --omit-name
```
