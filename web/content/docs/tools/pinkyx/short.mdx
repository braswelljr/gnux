An option of [pinkyx](/docs/tools/pinkyx).

## Usage

```bash
pinkyx -s [USER]...
pinkyx --short [USER]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-s` | `--short` | none | `true` | do short format output, this is the default |
