An option of [pinkyx](/docs/tools/pinkyx).

## Usage

```bash
pinkyx -h [USER]...
pinkyx --omit-project [USER]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-h` | `--omit-project` | none |  | omit the user's project file in long format |
