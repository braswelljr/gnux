An option of [pinkyx](/docs/tools/pinkyx).

## Usage

```bash
pinkyx -p [USER]...
pinkyx --omit-plan [USER]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-p` | `--omit-plan` | none |  | omit the user's plan file in long format |
