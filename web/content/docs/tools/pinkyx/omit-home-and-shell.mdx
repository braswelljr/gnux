An option of [pinkyx](/docs/tools/pinkyx).

## Usage

```bash
pinkyx -b [USER]...
pinkyx --omit-home-and-shell [USER]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-b` | `--omit-home-and-shell` | none |  | omit the user's home directory and shell in long format |
