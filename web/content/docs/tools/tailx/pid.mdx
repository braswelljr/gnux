---
title: "--pid"
description: "With -f, terminate after process ID, PID, dies."
---

An option of [tailx](/docs/tools/tailx).

## Usage

```bash
tailx --pid=PID [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--pid` | `PID` | `0` | with `-f`, terminate after process ID, PID, dies |

## Help in the terminal

```bash
gnux help tailx --pid
```
