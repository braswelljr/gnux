---
title: "-s, --sleep-interval"
description: "With -f, sleep for approximately N seconds (default 1.0) between iterations."
---

An option of [tailx](/docs/tools/tailx).

## Usage

```bash
tailx -s N [FILE]...
tailx --sleep-interval=N [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-s` | `--sleep-interval` | `N` | `1` | with `-f`, sleep for approximately N seconds (default 1.0) between iterations |

## Examples

### Follow a log across rotations, polling twice a second

```bash tab="bash" tab-group="shell"
tailx -F -s 0.5 /var/log/app.log
```

```powershell tab="PowerShell" tab-group="shell"
tailx -F -s 0.5 C:\logs\app.log
```
