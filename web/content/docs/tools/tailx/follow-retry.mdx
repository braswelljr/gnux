An option of [tailx](/docs/tools/tailx).

## Usage

```bash
tailx -F [FILE]...
tailx --follow-retry [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-F` | `--follow-retry` | none |  | same as `--follow`=name `--retry` |

## Examples

Follow a log across rotations, polling twice a second:

```bash
tailx -F -s 0.5 /var/log/app.log
```

```powershell
tailx -F -s 0.5 C:\logs\app.log
```
