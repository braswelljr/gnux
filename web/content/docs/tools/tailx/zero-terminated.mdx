---
title: "-z, --zero-terminated"
description: "Line delimiter is NUL, not newline."
---

An option of [tailx](/docs/tools/tailx).

## Usage

```bash
tailx -z [FILE]...
tailx --zero-terminated [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-z` | `--zero-terminated` | none |  | line delimiter is NUL, not newline |

## Examples

### Print the last entry of a NUL-separated list

```bash tab="bash" tab-group="shell"
tailx -z -n 1 names.lst | xargs -0 echox
```

```powershell tab="PowerShell" tab-group="shell"
tailx -z -n 1 names.lst
```

## Help in the terminal

```bash
gnux help tailx --zero-terminated
```
