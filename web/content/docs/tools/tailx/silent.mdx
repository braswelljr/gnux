An option of [tailx](/docs/tools/tailx).

## Usage

```bash
tailx --silent [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--silent` | none |  | same as `--quiet` |

## Help in the terminal

```bash
gnux help tailx --silent
```
