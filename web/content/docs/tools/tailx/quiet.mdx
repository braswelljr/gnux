---
title: "-q, --quiet"
description: "Never output headers giving file names."
---

An option of [tailx](/docs/tools/tailx).

## Usage

```bash
tailx -q [FILE]...
tailx --quiet [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-q` | `--quiet` | none |  | never output headers giving file names |

## Examples

### Print the last line of each log, with and without file name headers

```bash tab="bash" tab-group="shell"
tailx -n 1 a.log b.log && tailx -q -n 1 a.log b.log
```

```powershell tab="PowerShell" tab-group="shell"
tailx -n 1 a.log b.log; tailx -q -n 1 a.log b.log
```

## Help in the terminal

```bash
gnux help tailx --quiet
```
