title: "--print-ls-colors"
description: "Output fully escaped colors for display."

An option of [dircolorsx](/docs/tools/dircolorsx).

## Usage

```bash
dircolorsx --print-ls-colors [FILE]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--print-ls-colors` | none |  | output fully escaped colors for display |

## Examples

### See every color the database defines, in that color

```bash tab="bash" tab-group="shell"
dircolorsx --print-ls-colors
```

