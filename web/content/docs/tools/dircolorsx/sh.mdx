An option of [dircolorsx](/docs/tools/dircolorsx).

## Usage

```bash
dircolorsx -b [FILE]
dircolorsx --sh [FILE]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-b` | `--sh` | none |  | output Bourne shell code to set LS_COLORS (also `--bourne-shell`) |
