---
title: "-S, --suffix"
description: "Override the usual backup suffix, '~', with SUFFIX."
---

An option of [installx](/docs/tools/installx).

## Usage

```bash
installx -S SUFFIX SOURCE... DEST
installx --suffix=SUFFIX SOURCE... DEST
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-S` | `--suffix` | `SUFFIX` |  | override the usual backup suffix, '~', with SUFFIX |

## Help in the terminal

```bash
gnux help installx --suffix
```
