---
title: "-o, --owner"
description: "Set ownership (super-user only) to OWNER."
---

An option of [installx](/docs/tools/installx).

## Usage

```bash
installx -o OWNER SOURCE... DEST
installx --owner=OWNER SOURCE... DEST
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-o` | `--owner` | `OWNER` |  | set ownership (super-user only) to OWNER |

## Help in the terminal

```bash
gnux help installx --owner
```
