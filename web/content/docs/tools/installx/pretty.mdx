An option of [installx](/docs/tools/installx).

## Usage

```bash
installx --pretty[=WHEN] SOURCE... DEST
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--pretty` | `WHEN` (optional) |  | the `gnux` terminal view WHEN: 'always' (the default when WHEN is omitted), 'auto' (the default: on a terminal only), or 'never'; GNUX_PRETTY sets the default |

## Help in the terminal

```bash
gnux help installx --pretty
```
