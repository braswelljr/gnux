---
title: "-s, --strip"
description: "Strip symbol tables (not supported: warns and installs unstripped)."
---

An option of [installx](/docs/tools/installx).

## Usage

```bash
installx -s SOURCE... DEST
installx --strip SOURCE... DEST
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-s` | `--strip` | none |  | strip symbol tables (not supported: warns and installs unstripped) |

## Help in the terminal

```bash
gnux help installx --strip
```
