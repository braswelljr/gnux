---
title: "-C, --compare"
description: "Compare content of source and destination files, and if no change to content, ownership, and permissions, do not modify the destination at all."
---

An option of [installx](/docs/tools/installx).

## Usage

```bash
installx -C SOURCE... DEST
installx --compare SOURCE... DEST
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-C` | `--compare` | none |  | compare content of source and destination files, and if no change to content, ownership, and permissions, do not modify the destination at all |

## Examples

### Leave unchanged files untouched

```bash tab="bash" tab-group="shell"
installx -C -m 644 docs/*.md /usr/share/doc/app/
```

```powershell tab="PowerShell" tab-group="shell"
installx -C -m 644 (Get-ChildItem docs\*.md -Name) C:\app\doc
```
