---
title: "--quiet"
description: "Same as --silent."
---

An option of [chownx](/docs/tools/chownx).

## Usage

```bash
chownx --quiet [OWNER][:[GROUP]] FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--quiet` | none |  | same as `--silent` |

## Help in the terminal

```bash
gnux help chownx --quiet
```
