---
title: "-R, --recursive"
description: "Operate on files and directories recursively."
---

An option of [chownx](/docs/tools/chownx).

## Usage

```bash
chownx -R [OWNER][:[GROUP]] FILE...
chownx --recursive [OWNER][:[GROUP]] FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-R` | `--recursive` | none |  | operate on files and directories recursively |

## Help in the terminal

```bash
gnux help chownx --recursive
```
