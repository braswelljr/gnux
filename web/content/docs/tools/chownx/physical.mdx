---
title: "-P, --physical"
description: "With -R, do not traverse any symbolic links (default)."
---

An option of [chownx](/docs/tools/chownx).

## Usage

```bash
chownx -P [OWNER][:[GROUP]] FILE...
chownx --physical [OWNER][:[GROUP]] FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-P` | `--physical` | none |  | with `-R`, do not traverse any symbolic links (default) |

## Help in the terminal

```bash
gnux help chownx --physical
```
