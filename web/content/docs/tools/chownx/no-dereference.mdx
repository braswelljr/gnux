---
title: "-h, --no-dereference"
description: "Affect symbolic links instead of any referenced file."
---

An option of [chownx](/docs/tools/chownx).

## Usage

```bash
chownx -h [OWNER][:[GROUP]] FILE...
chownx --no-dereference [OWNER][:[GROUP]] FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-h` | `--no-dereference` | none |  | affect symbolic links instead of any referenced file |

## Help in the terminal

```bash
gnux help chownx --no-dereference
```
