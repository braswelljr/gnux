An option of [cpx](/docs/tools/cpx).

## Usage

```bash
cpx -d SOURCE... DIRECTORY
cpx --no-dereference-links SOURCE... DIRECTORY
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-d` | `--no-dereference-links` | none |  | same as `--no-dereference --preserve`=links |

gnux help cpx --no-dereference-links
