title: "-i, --interactive"
description: "Prompt before overwrite."
---

An option of [cpx](/docs/tools/cpx).

## Usage

```bash
cpx -i SOURCE... DIRECTORY
cpx --interactive SOURCE... DIRECTORY
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-i` | `--interactive` | none |  | prompt before overwrite |

## Examples

Ask before overwriting an existing copy:

```bash
cpx -i config.yml config.yml.orig
```

```powershell
cpx -i config.yml config.yml.orig
```

## Help in the terminal

```bash
gnux help cpx --interactive
```
