---
title: "--strip-trailing-slashes"
description: "Remove any trailing slashes from each SOURCE argument."
---

An option of [cpx](/docs/tools/cpx).

## Usage

```bash
cpx --strip-trailing-slashes SOURCE... DIRECTORY
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--strip-trailing-slashes` | none |  | remove any trailing slashes from each SOURCE argument |

## Examples

Back up a tree without crossing into other mounted file systems:

```bash
cpx -ax --strip-trailing-slashes data/ /mnt/backup/data
```

```powershell
cpx -ax --strip-trailing-slashes data\ D:\backup\data
```
