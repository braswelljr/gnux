---
title: "-x, --one-file-system"
description: "Stay on this file system."
---

An option of [cpx](/docs/tools/cpx).

## Usage

```bash
cpx -x SOURCE... DIRECTORY
cpx --one-file-system SOURCE... DIRECTORY
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-x` | `--one-file-system` | none |  | stay on this file system |

## Examples

Back up a tree without crossing into other mounted file systems:

```bash
cpx -ax --strip-trailing-slashes data/ /mnt/backup/data
```

```powershell
cpx -ax --strip-trailing-slashes data\ D:\backup\data
```

## Help in the terminal
