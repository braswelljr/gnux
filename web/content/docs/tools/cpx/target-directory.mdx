---
title: "-t, --target-directory"
description: "Copy all SOURCE arguments into DIRECTORY."
---

An option of [cpx](/docs/tools/cpx).

## Usage

```bash
cpx -t string SOURCE... DIRECTORY
cpx --target-directory=string SOURCE... DIRECTORY
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-t` | `--target-directory` | `string` |  | copy all SOURCE arguments into DIRECTORY |

## Examples

### Copy into a directory named first, without overwriting anything

```bash tab="bash" tab-group="shell"
cpx -n -t ~/Documents report.pdf slides.pdf
```

```powershell tab="PowerShell" tab-group="shell"
cpx -n -t $HOME\Documents report.pdf slides.pdf
```
