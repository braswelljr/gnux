---
title: "-p, --preserve-default"
description: "Same as --preserve=mode,ownership,timestamps."
---

An option of [cpx](/docs/tools/cpx).

## Usage

```bash
cpx -p SOURCE... DIRECTORY
cpx --preserve-default SOURCE... DIRECTORY
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-p` | `--preserve-default` | none |  | same as `--preserve`=mode,ownership,timestamps |

## Examples

Keep the mode and timestamps of a script while copying it:

```bash
cpx -p deploy.sh bin/
```

```powershell
cpx -p deploy.sh bin
```

## Help in the terminal

```bash
gnux help cpx --preserve-default
```
