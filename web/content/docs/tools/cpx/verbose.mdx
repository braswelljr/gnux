---
title: "-v, --verbose"
description: "Explain what is being done."
---

An option of [cpx](/docs/tools/cpx).

## Usage

```bash
cpx -v SOURCE... DIRECTORY
cpx --verbose SOURCE... DIRECTORY
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-v` | `--verbose` | none |  | explain what is being done |

## Examples

Copy several files into a directory, reporting each one:

```bash
cpx -v a.txt b.txt backup/
```

```powershell
cpx -v a.txt b.txt backup
```

Copy every .conf file into a fresh directory with the `gnux shell`:

```bash
gnux shell -c 'mkdirx -p confbak && cpx -v *.conf confbak/'
```

```powershell
gnux shell -c 'mkdirx -p confbak && cpx -v *.conf confbak/'
```

## Help in the terminal

```bash
gnux help cpx --verbose
```
