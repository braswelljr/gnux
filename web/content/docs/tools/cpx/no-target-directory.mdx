---
title: "-T, --no-target-directory"
description: "Treat DEST as a normal file."
---

An option of [cpx](/docs/tools/cpx).

## Usage

```bash
cpx -T SOURCE... DIRECTORY
cpx --no-target-directory SOURCE... DIRECTORY
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-T` | `--no-target-directory` | none |  | treat DEST as a normal file |

## Examples

### Copy a template's contents into an existing directory, not inside it

```bash tab="bash" tab-group="shell"
cpx -rT template/ newproject/
```

```powershell tab="PowerShell" tab-group="shell"
cpx -rT template newproject
```

## Help in the terminal

```bash
gnux help cpx --no-target-directory
```
