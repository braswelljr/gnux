An option of [cpx](/docs/tools/cpx).

## Usage

```bash
cpx -u SOURCE... DIRECTORY
cpx --update[=string] SOURCE... DIRECTORY
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-u` | `--update` | `string` (optional) |  | control which existing files are updated: all, none, or older (the default for `-u`) |

## Examples

### Update a mirror, copying only files that are newer

```bash tab="bash" tab-group="shell"
cpx -ru src/. mirror/
```

```powershell tab="PowerShell" tab-group="shell"
cpx -ru src\. mirror
```

### Add missing default files without overwriting customized ones

```bash tab="bash" tab-group="shell"
cpx -r --update=none defaults/. config/
```

```powershell tab="PowerShell" tab-group="shell"
cpx -r --update=none defaults\. config
```
