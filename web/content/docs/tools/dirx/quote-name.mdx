---
title: "-Q, --quote-name"
description: "Enclose entry names in double quotes."
---

An option of [dirx](/docs/tools/dirx).

## Usage

```bash
dirx -Q [FILE]...
dirx --quote-name [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-Q` | `--quote-name` | none |  | enclose entry names in double quotes |

## Help in the terminal

```bash
gnux help dirx --quote-name
```
