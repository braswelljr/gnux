An option of [dirx](/docs/tools/dirx).

## Usage

```bash
dirx --color[=WHEN] [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--color` | `WHEN` (optional) | `never` | color the output WHEN: 'always' (the default when WHEN is omitted), 'auto', or 'never' |

## Help in the terminal

```bash
gnux help dirx --color
```
