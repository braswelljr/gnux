---
title: "--theme"
description: "Color the view with the built-in theme NAME (gnux themes shows them all); GNUX_THEME sets the default."
---

An option of [dirx](/docs/tools/dirx).

## Usage

```bash
dirx --theme=NAME [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--theme` | `NAME` |  | color the view with the built-in theme NAME (`gnux` themes shows them all); GNUX_THEME sets the default |

## Help in the terminal

```bash
gnux help dirx --theme
```
