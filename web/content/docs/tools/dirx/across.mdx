---
title: "-x, --across"
description: "List entries by lines instead of by columns."
---

An option of [dirx](/docs/tools/dirx).

## Usage

```bash
dirx -x [FILE]...
dirx --across [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-x` | `--across` | none |  | list entries by lines instead of by columns |

## Examples

### List entries across rather than down

```bash tab="bash" tab-group="shell"
dirx -x src
```

```powershell tab="PowerShell" tab-group="shell"
dirx -x src
```

## Help in the terminal

```bash
gnux help dirx --across
```
