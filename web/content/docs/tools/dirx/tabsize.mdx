---
title: "-T, --tabsize"
description: "Assume tab stops at each COLS instead of 8."
---

An option of [dirx](/docs/tools/dirx).

## Usage

```bash
dirx -T COLS [FILE]...
dirx --tabsize=COLS [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-T` | `--tabsize` | `COLS` |  | assume tab stops at each COLS instead of 8 |

## Help in the terminal

```bash
gnux help dirx --tabsize
```
