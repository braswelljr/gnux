An option of [dirx](/docs/tools/dirx).

## Usage

```bash
dirx -G [FILE]...
dirx --no-group [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-G` | `--no-group` | none |  | in a long listing, don't print group names |

## Help in the terminal

```bash
gnux help dirx --no-group
```
