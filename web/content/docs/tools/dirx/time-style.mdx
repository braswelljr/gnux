An option of [dirx](/docs/tools/dirx).

## Usage

```bash
dirx --time-style=TIME_STYLE [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--time-style` | `TIME_STYLE` |  | time/`date` format with `-l`, TIME_STYLE: full-iso, long-iso, iso, locale, or +FORMAT |

## Help in the terminal

```bash
gnux help dirx --time-style
```
