An option of [dirx](/docs/tools/dirx).

## Usage

```bash
dirx -b [FILE]...
dirx --escape [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-b` | `--escape` | none |  | print C-style escapes for nongraphic characters |

## Help in the terminal

```bash
gnux help dirx --escape
```
