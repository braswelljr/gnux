An option of [dirx](/docs/tools/dirx).

## Usage

```bash
dirx -t [FILE]...
dirx --sort-time [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-t` | `--sort-time` | none |  | sort by time, newest first; see `--time` |

## Examples

### Sort by modification time, newest first

```bash tab="bash" tab-group="shell"
dirx -t
```

```powershell tab="PowerShell" tab-group="shell"
dirx -t
```
