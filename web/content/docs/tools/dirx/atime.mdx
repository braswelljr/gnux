---
title: "-u, --atime"
description: "With -lt: sort by, and show, access time; with -l: show access time and sort by name; otherwise: sort by access time, newest first."
---

An option of [dirx](/docs/tools/dirx).

## Usage

```bash
dirx -u [FILE]...
dirx --atime [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-u` | `--atime` | none |  | with `-lt`: sort by, and show, access time; with `-l`: show access time and sort by name; otherwise: sort by access time, newest first |

## Help in the terminal

```bash
gnux help dirx --atime
```
