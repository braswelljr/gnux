An option of [dirx](/docs/tools/dirx).

## Usage

```bash
dirx -X [FILE]...

```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-X` | `--sort-extension` | none |  | sort alphabetically by entry extension |
