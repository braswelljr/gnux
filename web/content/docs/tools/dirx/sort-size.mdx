---
title: "-S, --sort-size"
description: "Sort by file size, largest first."
---

An option of [dirx](/docs/tools/dirx).

## Usage

```bash
dirx -S [FILE]...
dirx --sort-size [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-S` | `--sort-size` | none |  | sort by file size, largest first |

## Help in the terminal

```bash
gnux help dirx --sort-size
```
