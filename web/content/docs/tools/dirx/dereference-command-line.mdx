An option of [dirx](/docs/tools/dirx).

## Usage

```bash
dirx -H [FILE]...
dirx --dereference-command-line [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-H` | `--dereference-command-line` | none |  | follow symbolic links listed on the command line |

## Help in the terminal

```bash
gnux help dirx --dereference-command-line
```
