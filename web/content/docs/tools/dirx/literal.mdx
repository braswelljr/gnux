---
title: "-N, --literal"
description: "Print entry names without quoting."
---

An option of [dirx](/docs/tools/dirx).

## Usage

```bash
dirx -N [FILE]...
dirx --literal [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-N` | `--literal` | none |  | print entry names without quoting |

## Help in the terminal

```bash
gnux help dirx --literal
```
