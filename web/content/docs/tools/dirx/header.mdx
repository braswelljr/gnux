---
title: "--header"
description: "With -l, print a row naming each column."
---

An option of [dirx](/docs/tools/dirx).

## Usage

```bash
dirx --header [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--header` | none |  | with `-l`, print a row naming each column |

## Help in the terminal

```bash
gnux help dirx --header
```
