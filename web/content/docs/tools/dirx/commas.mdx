An option of [dirx](/docs/tools/dirx).

## Usage

```bash
dirx -m [FILE]...
dirx --commas [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-m` | `--commas` | none |  | fill width with a comma separated list of entries |

## Help in the terminal

```bash
gnux help dirx --commas
```
