---
title: "-r, --reverse"
description: "Reverse order while sorting."
---

An option of [dirx](/docs/tools/dirx).

## Usage

```bash
dirx -r [FILE]...
dirx --reverse [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-r` | `--reverse` | none |  | reverse order while sorting |

## Help in the terminal

```bash
gnux help dirx --reverse
```
