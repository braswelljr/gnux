An option of [dirx](/docs/tools/dirx).

## Usage

```bash
dirx -k [FILE]...
dirx --kibibytes [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-k` | `--kibibytes` | none |  | default to 1024-byte blocks for file system usage; used only with `-s` and per directory totals |

## Help in the terminal

```bash
gnux help dirx --kibibytes
```
