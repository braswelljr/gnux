---
title: "-w, --width"
description: "Set output width to COLS; 0 means no limit."
---

An option of [dirx](/docs/tools/dirx).

## Usage

```bash
dirx -w COLS [FILE]...
dirx --width=COLS [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-w` | `--width` | `COLS` |  | set output width to COLS; 0 means no limit |

## Examples

### Fit the columns in 40 characters

```bash tab="bash" tab-group="shell"
dirx -w 40 /etc
```

```powershell tab="PowerShell" tab-group="shell"
dirx -w 40 C:\Windows
```

## Help in the terminal

```bash
gnux help dirx --width
```
