---
title: "--level"
description: "With -R or --tree, go at most DEPTH levels deep."
---

An option of [dirx](/docs/tools/dirx).

## Usage

```bash
dirx --level=DEPTH [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--level` | `DEPTH` |  | with `-R` or `--tree`, go at most DEPTH levels deep |

## Help in the terminal

```bash
gnux help dirx --level
```
