---
title: "-l, --long"
description: "Use a long listing format."
---

An option of [dirx](/docs/tools/dirx).

## Usage

```bash
dirx -l [FILE]...
dirx --long [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-l` | `--long` | none |  | use a long listing format |

## Examples

### Switch to the long format, as vdirx does

```bash tab="bash" tab-group="shell"
dirx -l
```

```powershell tab="PowerShell" tab-group="shell"
dirx -l
```

## Help in the terminal

```bash
gnux help dirx --long
```
