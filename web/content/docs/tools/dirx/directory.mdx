---
title: "-d, --directory"
description: "List directories themselves, not their contents."
---

An option of [dirx](/docs/tools/dirx).

## Usage

```bash
dirx -d [FILE]...
dirx --directory [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-d` | `--directory` | none |  | list directories themselves, not their contents |

## Help in the terminal

```bash
gnux help dirx --directory
```
