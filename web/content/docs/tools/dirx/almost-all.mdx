An option of [dirx](/docs/tools/dirx).

## Usage

```bash
dirx -A [FILE]...
dirx --almost-all [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-A` | `--almost-all` | none |  | do not list implied . and .. |
