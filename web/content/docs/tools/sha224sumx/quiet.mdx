---
title: "--quiet"
description: "Don't print OK for each successfully verified file."
---

An option of [sha224sumx](/docs/tools/sha224sumx).

## Usage

```bash
sha224sumx --quiet [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--quiet` | none |  | don't print OK for each successfully verified file |

## Examples

### Verify quietly, showing only failures

```bash tab="bash" tab-group="shell"
sha224sumx -c --quiet sha224.sums
```

```powershell tab="PowerShell" tab-group="shell"
sha224sumx -c --quiet sha224.sums
```

## Help in the terminal

```bash
gnux help sha224sumx --quiet
```
