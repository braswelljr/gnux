title: "sha224sumx"
description: "Print or check SHA-224 (224-bit) checksums."
---

Mirrors GNU `sha224sum`. Run it as `sha224sumx`, or as `gnux sha224sumx`.

## Synopsis

```bash
sha224sumx [OPTION]... [FILE]...
```

## GNU reference

- [GNU coreutils manual: sha224sum invocation](https://www.gnu.org/software/coreutils/manual/html_node/sha2-utilities.html)
- [Source: src/cksum.c in coreutils/coreutils](https://github.com/coreutils/coreutils/blob/master/src/cksum.c)

## Description

`sha224sumx` prints or checks SHA-224 message digests (FIPS 180-4, 224 bits). For each FILE it prints one line: the digest in hexadecimal, a space, a mode mark (a space for text mode, '*' with `-b`), and the file name. With no FILE, or when FILE is -, it reads standard input. Files are always read as bytes, so `-b` and `-t` change only the mark; when both are given, `-t` wins. `--tag` prints BSD-style lines instead ('ALGORITHM (FILE) = DIGEST'). A file name containing a backslash, newline or carriage return is escaped and its line starts with a backslash, unless `-z` ends lines with NUL instead. `-c` reads such lines (in either style) from the FILEs and checks each listed file, printing 'FILE: OK' or 'FILE: FAILED' and a summary warning of mismatches, unreadable files and improperly formatted lines; `--quiet` drops the OK lines, `--status` prints nothing, `--ignore-missing` skips listed files that do not exist, `-w` warns about each improperly formatted line and `--strict` fails because of them. The exit status is 0 when everything was read (and, with `-c`, matched), 1 otherwise. On Windows a backslash in a file name is the path separator, so it is not escaped as GNU escapes it on Unix; a name with a newline is still escaped.

## Permissions

Needs read permission on each FILE (and, with `-c`, on the checksum lists and every file they name) and search permission on the directories leading to them. Nothing is ever modified.

## Use cases

- Verifying a download against the checksum its publisher lists.
- Recording digests of release artifacts so users can check them.
- Detecting whether files changed between two points in time.
- Finding duplicate files by comparing their digests.
- Checking a backup or a copy against the original.

## Flags

```text
  -b, --binary           read in binary mode
  -c, --check            read checksums from the FILEs and check them
      --help             display this help and exit
      --ignore-missing   don't fail or report status for missing files
      --quiet            don't print OK for each successfully verified file
      --status           don't output anything, status code shows success
      --strict           exit non-zero for improperly formatted checksum lines
      --tag              create a BSD-style checksum
  -t, --text             read in text mode (default)
      --version          output version information and exit
  -w, --warn             warn about improperly formatted checksum lines
  -z, --zero             end each output line with NUL, not newline, and disable file name escaping
```

## Examples

### You downloaded an installer: print its digest to compare with the one on the website

```bash tab="bash" tab-group="shell"
sha224sumx ubuntu-24.04-desktop-amd64.iso
```

```powershell tab="PowerShell" tab-group="shell"
sha224sumx ubuntu-24.04-desktop-amd64.iso
```

### Verify the download against the publisher's checksum file, which lists other files too

```bash tab="bash" tab-group="shell"
sha224sumx -c --ignore-missing sha224.sums
```

```powershell tab="PowerShell" tab-group="shell"
sha224sumx -c --ignore-missing sha224.sums
```

```text title="Output"
ubuntu-24.04-desktop-amd64.iso: OK
```

### Publish checksums next to your release archives

```bash tab="bash" tab-group="shell"
sha224sumx dist/*.tar.gz > dist/sha224.sums
```

```powershell tab="PowerShell" tab-group="shell"
sha224sumx (Get-ChildItem dist\*.zip -Name) > dist\sha224.sums
```

### Check that a backup copied to a USB drive still matches the original

```bash tab="bash" tab-group="shell"
sha224sumx photos.tar /media/usb/photos.tar
```

```powershell tab="PowerShell" tab-group="shell"
sha224sumx photos.tar E:\photos.tar
```

### Find duplicate photos in a folder: files with the same digest have the same content

```bash tab="bash" tab-group="shell"
sha224sumx *.jpg | sortx | uniqx -w 56 -D
```

```powershell tab="PowerShell" tab-group="shell"
sha224sumx (Get-ChildItem *.jpg -Name) | sortx | uniqx -w 56 -D
```

### In CI, fail the build when a vendored file was changed by hand

```bash tab="bash" tab-group="shell"
sha224sumx -c --status vendor.sha224sums || { echox 'vendored files changed' >&2; exit 1; }
```

```powershell tab="PowerShell" tab-group="shell"
sha224sumx -c --status vendor.sha224sums; if ($LASTEXITCODE -ne 0) { Write-Error 'vendored files changed'; exit 1 }
```

### Re-check a large archive set and show only what no longer matches

```bash tab="bash" tab-group="shell"
sha224sumx -c --quiet sha224.sums
```

```powershell tab="PowerShell" tab-group="shell"
sha224sumx -c --quiet sha224.sums
```

```text title="Output"
notes.txt: FAILED
sha224sumx: WARNING: 1 computed checksum did NOT match
```

### Hash a token from a variable, without the newline echo would add

```bash tab="bash" tab-group="shell"
printfx '%s' "$TOKEN" | sha224sumx
```

```powershell tab="PowerShell" tab-group="shell"
printfx '%s' $env:TOKEN | sha224sumx
```

### Write lines that name the algorithm, so a mixed list can be checked with cksumx -c

```bash tab="bash" tab-group="shell"
sha224sumx --tag release.tar.gz >> CHECKSUMS
```

```powershell tab="PowerShell" tab-group="shell"
sha224sumx --tag release.zip >> CHECKSUMS
```

### Refuse a checksum list with malformed lines instead of skipping them

```bash tab="bash" tab-group="shell"
sha224sumx -c --strict -w sha224.sums
```

```powershell tab="PowerShell" tab-group="shell"
sha224sumx -c --strict -w sha224.sums
```

### Match the '*' binary-mode lines produced by tools on Windows

```bash tab="bash" tab-group="shell"
sha224sumx -b setup.exe
```

```powershell tab="PowerShell" tab-group="shell"
sha224sumx -b setup.exe
```

### Record a digest next to the file in the portable gnux shell, the same on every OS

```bash tab="bash" tab-group="shell"
gnux shell -c 'sha224sumx file.iso > file.iso.sha224sum'
```

```powershell tab="PowerShell" tab-group="shell"
gnux shell -c 'sha224sumx file.iso > file.iso.sha224sum'
```

## Exit status

| Status | Meaning |
|--------|---------|
| 0 | success: every operand was processed |
| 1 | failure: an operand could not be processed (diagnosed on standard error), or a command-line mistake |
