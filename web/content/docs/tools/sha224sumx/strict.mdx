---
title: "--strict"
description: "Exit non-zero for improperly formatted checksum lines."
---

An option of [sha224sumx](/docs/tools/sha224sumx).

## Usage

```bash
sha224sumx --strict [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--strict` | none |  | exit non-zero for improperly formatted checksum lines |

## Examples

### Fail on malformed lines in the list

```bash tab="bash" tab-group="shell"
sha224sumx -c --strict -w sha224.sums
```

```powershell tab="PowerShell" tab-group="shell"
sha224sumx -c --strict -w sha224.sums
```

## Help in the terminal

```bash
gnux help sha224sumx --strict
```
