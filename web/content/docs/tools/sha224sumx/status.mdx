title: "--status"

---

An option of [sha224sumx](/docs/tools/sha224sumx).

## Usage

```bash
sha224sumx --status [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--status` | none |  | don't output anything, status code shows success |

## Examples

### In CI, fail the build when a vendored file was changed by hand

```bash tab="bash" tab-group="shell"
sha224sumx -c --status vendor.sha224sums || { echox 'vendored files changed' >&2; exit 1; }
```

```powershell tab="PowerShell" tab-group="shell"
sha224sumx -c --status vendor.sha224sums; if ($LASTEXITCODE -ne 0) { Write-Error 'vendored files changed'; exit 1 }
```
