An option of [base32x](/docs/tools/base32x).

## Usage

```bash
base32x -i [FILE]
base32x --ignore-garbage [FILE]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-i` | `--ignore-garbage` | none |  | when decoding, ignore non-alphabet characters |

## Examples

### Decode, skipping characters outside the alphabet

```bash tab="bash" tab-group="shell"
base32x -d -i messy.txt
```

```powershell tab="PowerShell" tab-group="shell"
base32x -d -i messy.txt
```
