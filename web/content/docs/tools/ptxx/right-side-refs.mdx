---
title: "-R, --right-side-refs"
description: "Put references at right, not counted in -w."
---

An option of [ptxx](/docs/tools/ptxx).

## Usage

```bash
ptxx -R [INPUT]...   (without -G)
ptxx -G [OPTION]... [INPUT [OUTPUT]]
ptxx --right-side-refs [INPUT]...   (without -G)
ptxx -G [OPTION]... [INPUT [OUTPUT]]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-R` | `--right-side-refs` | none |  | put references at right, not counted in `-w` |

## Help in the terminal

```bash
gnux help ptxx --right-side-refs
```
