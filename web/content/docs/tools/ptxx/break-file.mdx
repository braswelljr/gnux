---
title: "-b, --break-file"
description: "Word break characters in this FILE."
---

An option of [ptxx](/docs/tools/ptxx).

## Usage

```bash
ptxx -b FILE [INPUT]...   (without -G)
ptxx -G [OPTION]... [INPUT [OUTPUT]]
ptxx --break-file=FILE [INPUT]...   (without -G)
ptxx -G [OPTION]... [INPUT [OUTPUT]]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-b` | `--break-file` | `FILE` |  | word break characters in this FILE |

## Help in the terminal

```bash
gnux help ptxx --break-file
```
