---
title: "-g, --gap-size"
description: "Gap size in columns between output fields."
---

An option of [ptxx](/docs/tools/ptxx).

## Usage

```bash
ptxx -g string [INPUT]...   (without -G)
ptxx -G [OPTION]... [INPUT [OUTPUT]]
ptxx --gap-size=string [INPUT]...   (without -G)
ptxx -G [OPTION]... [INPUT [OUTPUT]]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-g` | `--gap-size` | `string` |  | gap size in columns between output fields |

## Help in the terminal

```bash
gnux help ptxx --gap-size
```
