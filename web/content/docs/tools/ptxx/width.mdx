---
title: "-w, --width"
description: "Output width in columns, reference excluded."
---

An option of [ptxx](/docs/tools/ptxx).

## Usage

```bash
ptxx -w string [INPUT]...   (without -G)
ptxx -G [OPTION]... [INPUT [OUTPUT]]
ptxx --width=string [INPUT]...   (without -G)
ptxx -G [OPTION]... [INPUT [OUTPUT]]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-w` | `--width` | `string` |  | output width in columns, reference excluded |

## Help in the terminal

```bash
gnux help ptxx --width
```
