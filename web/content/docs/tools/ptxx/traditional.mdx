---
title: "-G, --traditional"
description: "Behave more like System V 'ptx'."
---

An option of [ptxx](/docs/tools/ptxx).

## Usage

```bash
ptxx -G [INPUT]...   (without -G)
ptxx -G [OPTION]... [INPUT [OUTPUT]]
ptxx --traditional [INPUT]...   (without -G)
ptxx -G [OPTION]... [INPUT [OUTPUT]]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-G` | `--traditional` | none |  | behave more like System V '`ptx`' |

## Help in the terminal

```bash
gnux help ptxx --traditional
```
