---
title: "--format"
description: "Generate output as roff or TeX directives: FORMAT is roff or tex."
---

An option of [ptxx](/docs/tools/ptxx).

## Usage

```bash
ptxx --format=FORMAT [INPUT]...   (without -G)
ptxx -G [OPTION]... [INPUT [OUTPUT]]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--format` | `FORMAT` |  | generate output as roff or TeX directives: FORMAT is roff or tex |

## Help in the terminal

```bash
gnux help ptxx --format
```
