---

An option of [ptxx](/docs/tools/ptxx).

## Usage

```bash
ptxx -S string [INPUT]...   (without -G)
ptxx -G [OPTION]... [INPUT [OUTPUT]]
ptxx --sentence-regexp=string [INPUT]...   (without -G)
ptxx -G [OPTION]... [INPUT [OUTPUT]]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-S` | `--sentence-regexp` | `string` |  | for end of lines or end of sentences |

## Examples

### Treat each line as its own context, ignoring case when sorting

```bash tab="bash" tab-group="shell"
ptxx -f -S '\n' titles.txt
```

```powershell tab="PowerShell" tab-group="shell"
ptxx -f -S '\n' titles.txt
```
