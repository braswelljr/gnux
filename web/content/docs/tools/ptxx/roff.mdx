---
title: "-O, --roff"
description: "Generate output as roff directives (--format=roff)."
---

An option of [ptxx](/docs/tools/ptxx).

## Usage

```bash
ptxx -O [INPUT]...   (without -G)
ptxx -G [OPTION]... [INPUT [OUTPUT]]
ptxx --roff [INPUT]...   (without -G)
ptxx -G [OPTION]... [INPUT [OUTPUT]]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-O` | `--roff` | none |  | generate output as roff directives (`--format`=roff) |

## Help in the terminal

```bash
gnux help ptxx --roff
```
