title: "-r, --references"

An option of [ptxx](/docs/tools/ptxx).

## Usage

```bash
ptxx -r [INPUT]...   (without -G)
ptxx -G [OPTION]... [INPUT [OUTPUT]]
ptxx --references [INPUT]...   (without -G)
ptxx -G [OPTION]... [INPUT [OUTPUT]]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-r` | `--references` | none |  | first field of each line is a reference |

## Help in the terminal

```bash
gnux help ptxx --references
```
