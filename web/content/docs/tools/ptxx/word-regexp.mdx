---
title: "-W, --word-regexp"
description: "Use REGEXP to match each keyword."
---

An option of [ptxx](/docs/tools/ptxx).

## Usage

```bash
ptxx -W REGEXP [INPUT]...   (without -G)
ptxx -G [OPTION]... [INPUT [OUTPUT]]
ptxx --word-regexp=REGEXP [INPUT]...   (without -G)
ptxx -G [OPTION]... [INPUT [OUTPUT]]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-W` | `--word-regexp` | `REGEXP` |  | use REGEXP to match each keyword |

## Help in the terminal

```bash
gnux help ptxx --word-regexp
```
