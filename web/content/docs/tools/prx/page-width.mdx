title: "-W, --page-width"
description: "Set page width to PAGE_WIDTH (72) characters always, truncate lines, except -J option is set, no interference with -S or -s."
---

An option of [prx](/docs/tools/prx).

## Usage

```bash
prx -W PAGE_WIDTH [FILE]...
prx --page-width=PAGE_WIDTH [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-W` | `--page-width` | `PAGE_WIDTH` |  | set page width to PAGE_WIDTH (72) characters always, `truncate` lines, except `-J` option is set, no interference with `-S` or `-s` |

## Help in the terminal

```bash
gnux help prx --page-width
```
