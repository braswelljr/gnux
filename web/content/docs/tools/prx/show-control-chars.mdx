---
title: "-c, --show-control-chars"
description: "Use hat notation (^G) and octal backslash notation."
---

An option of [prx](/docs/tools/prx).

## Usage

```bash
prx -c [FILE]...
prx --show-control-chars [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-c` | `--show-control-chars` | none |  | use hat notation (^G) and octal backslash notation |

## Help in the terminal

```bash
gnux help prx --show-control-chars
```
