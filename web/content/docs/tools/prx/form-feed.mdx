An option of [prx](/docs/tools/prx).

## Usage

```bash
prx -f [FILE]...
prx --form-feed [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-f` | `--form-feed` | none |  | use form feeds instead of newlines to separate pages (also `-F`) |

## Examples

### Use short pages and a form feed between them

```bash tab="bash" tab-group="shell"
prx -l 40 -f notes.txt
```

```powershell tab="PowerShell" tab-group="shell"
prx -l 40 -f notes.txt
```

## Help in the terminal

```bash
gnux help prx --form-feed
```
