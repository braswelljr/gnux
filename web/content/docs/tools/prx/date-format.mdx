---
title: "-D, --date-format"
description: "Use FORMAT for the header date."
---

An option of [prx](/docs/tools/prx).

## Usage

```bash
prx -D FORMAT [FILE]...
prx --date-format=FORMAT [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-D` | `--date-format` | `FORMAT` |  | use FORMAT for the header `date` |

## Help in the terminal

```bash
gnux help prx --date-format
```
