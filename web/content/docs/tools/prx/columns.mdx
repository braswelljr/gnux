---
title: "--columns"
description: "Output COLUMN columns and print columns down, unless -a is used; also -COLUMN."
---

An option of [prx](/docs/tools/prx).

## Usage

```bash
prx --columns=COLUMN [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--columns` | `COLUMN` |  | output COLUMN columns and print columns down, unless `-a` is used; also `-COLUMN` |

## Help in the terminal

```bash
gnux help prx --columns
```
