---
title: "-w, --width"
description: "Set page width to PAGE_WIDTH (72) characters for multiple text-column output only, -s[char] turns off (72)."
---

An option of [prx](/docs/tools/prx).

## Usage

```bash
prx -w PAGE_WIDTH [FILE]...
prx --width=PAGE_WIDTH [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-w` | `--width` | `PAGE_WIDTH` |  | set page width to PAGE_WIDTH (72) characters for multiple text-column output only, `-s`[char] turns off (72) |

## Help in the terminal

```bash
gnux help prx --width
```
