An option of [prx](/docs/tools/prx).

## Usage

```bash
prx --pages=FIRST_PAGE[:LAST_PAGE] [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--pages` | `FIRST_PAGE[:LAST_PAGE]` |  | begin [stop] printing with page FIRST_PAGE[:LAST_PAGE]; also +FIRST_PAGE[:LAST_PAGE] |

## Help in the terminal

```bash
gnux help prx --pages
```
