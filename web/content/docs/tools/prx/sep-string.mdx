---
title: "-S, --sep-string"
description: "Separate columns by STRING; without -S, a blank with -J and a space otherwise; written -S[STRING]."
---

An option of [prx](/docs/tools/prx).

## Usage

```bash
prx -S STRING [FILE]...
prx --sep-string=STRING [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-S` | `--sep-string` | `STRING` |  | separate columns by STRING; without `-S`, a blank with `-J` and a space otherwise; written `-S`[STRING] |

## Help in the terminal

```bash
gnux help prx --sep-string
```
