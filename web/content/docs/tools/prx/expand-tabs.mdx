---
title: "-e, --expand-tabs"
description: "Expand input CHARs (TABs) to tab `WIDTH` (8); written -e[CHAR[WIDTH]]."
---

An option of [prx](/docs/tools/prx).

## Usage

```bash
prx -e CHAR [FILE]...
prx --expand-tabs=CHAR [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-e` | `--expand-tabs` | `CHAR` |  | `expand` input CHARs (TABs) to tab `WIDTH` (8); written `-e`[CHAR[WIDTH]] |

## Help in the terminal

```bash
gnux help prx --expand-tabs
```
