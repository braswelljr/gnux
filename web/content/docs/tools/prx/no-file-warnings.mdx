An option of [prx](/docs/tools/prx).

## Usage

```bash
prx -r [FILE]...
prx --no-file-warnings [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-r` | `--no-file-warnings` | none |  | omit warning when a file cannot be opened |
