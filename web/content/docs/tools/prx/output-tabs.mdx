---
title: "-i, --output-tabs"
description: "Replace spaces with CHARs (TABs) to tab `WIDTH` (8); written -i[CHAR[WIDTH]]."
---

An option of [prx](/docs/tools/prx).

## Usage

```bash
prx -i CHAR [FILE]...
prx --output-tabs=CHAR [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-i` | `--output-tabs` | `CHAR` |  | replace spaces with CHARs (TABs) to tab `WIDTH` (8); written `-i`[CHAR[WIDTH]] |

## Help in the terminal

```bash
gnux help prx --output-tabs
```
