An option of [prx](/docs/tools/prx).

## Usage

```bash
prx -v [FILE]...
prx --show-nonprinting [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-v` | `--show-nonprinting` | none |  | use octal backslash notation |

## Help in the terminal

```bash
gnux help prx --show-nonprinting
```
