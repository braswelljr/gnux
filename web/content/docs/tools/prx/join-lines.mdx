An option of [prx](/docs/tools/prx).

## Usage

```bash
prx -J [FILE]...
prx --join-lines [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-J` | `--join-lines` | none |  | merge full lines, turns off `-W` line truncation, no column alignment, `--sep-string`[=STRING] sets separators |
