---
title: "-T, --omit-pagination"
description: "Omit page headers and trailers, eliminate any pagination by form feeds set in input files."
---

An option of [prx](/docs/tools/prx).

## Usage

```bash
prx -T [FILE]...
prx --omit-pagination [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-T` | `--omit-pagination` | none |  | omit page headers and trailers, eliminate any pagination by form feeds set in input files |

## Help in the terminal

```bash
gnux help prx --omit-pagination
```
