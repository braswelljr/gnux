---
title: "-o, --indent"
description: "Offset each line with MARGIN (zero) spaces."
---

An option of [prx](/docs/tools/prx).

## Usage

```bash
prx -o MARGIN [FILE]...
prx --indent=MARGIN [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-o` | `--indent` | `MARGIN` |  | offset each line with MARGIN (zero) spaces |

## Help in the terminal

```bash
gnux help prx --indent
```
