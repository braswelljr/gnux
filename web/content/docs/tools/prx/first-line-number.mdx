---
title: "-N, --first-line-number"
description: "Start counting with NUMBER at 1st line of first page printed."
---

An option of [prx](/docs/tools/prx).

## Usage

```bash
prx -N NUMBER [FILE]...
prx --first-line-number=NUMBER [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-N` | `--first-line-number` | `NUMBER` |  | start counting with NUMBER at 1st line of first page printed |

## Help in the terminal

```bash
gnux help prx --first-line-number
```
