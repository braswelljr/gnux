---
title: "--strict"
description: "Exit non-zero for improperly formatted checksum lines."
---

An option of [sha512sumx](/docs/tools/sha512sumx).

## Usage

```bash
sha512sumx --strict [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--strict` | none |  | exit non-zero for improperly formatted checksum lines |

## Examples

### Fail on malformed lines in the list

```bash tab="bash" tab-group="shell"
sha512sumx -c --strict -w sha512.sums
```

```powershell tab="PowerShell" tab-group="shell"
sha512sumx -c --strict -w sha512.sums
```

## Help in the terminal

```bash
gnux help sha512sumx --strict
```
