---
title: "-n, --digits"
description: "Use specified number of digits instead of 2."
---

An option of [csplitx](/docs/tools/csplitx).

## Usage

```bash
csplitx -n digits FILE PATTERN...
csplitx --digits=digits FILE PATTERN...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-n` | `--digits` | `digits` |  | use specified number of digits instead of 2 |

## Help in the terminal

```bash
gnux help csplitx --digits
```
