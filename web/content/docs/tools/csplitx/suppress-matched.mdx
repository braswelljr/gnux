---
title: "--suppress-matched"
description: "Suppress the lines matching PATTERN."
---

An option of [csplitx](/docs/tools/csplitx).

## Usage

```bash
csplitx --suppress-matched FILE PATTERN...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--suppress-matched` | none |  | suppress the lines matching PATTERN |

## Examples

### Split a multi-document Kubernetes YAML into one manifest per file, dropping the '---' lines

```bash tab="bash" tab-group="shell"
csplitx -z --suppress-matched -f manifest- -b '%02d.yaml' all.yaml '/^---$/' '{*}'
```

```powershell tab="PowerShell" tab-group="shell"
csplitx -z --suppress-matched -f manifest- -b '%02d.yaml' all.yaml '/^---$/' '{*}'
```
