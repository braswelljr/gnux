---
title: "--quiet"
description: "Same as --silent."
---

An option of [chmodx](/docs/tools/chmodx).

## Usage

```bash
chmodx --quiet MODE[,MODE]... FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--quiet` | none |  | same as `--silent` |

## Help in the terminal

```bash
gnux help chmodx --quiet
```
