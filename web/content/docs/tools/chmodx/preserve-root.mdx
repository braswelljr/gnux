---
title: "--preserve-root"
description: "Fail to operate recursively on '/' (the default)."
---

An option of [chmodx](/docs/tools/chmodx).

## Usage

```bash
chmodx --preserve-root MODE[,MODE]... FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--preserve-root` | none |  | fail to operate recursively on '/' (the default) |

## Help in the terminal

```bash
gnux help chmodx --preserve-root
```
