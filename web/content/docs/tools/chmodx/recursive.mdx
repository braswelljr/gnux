---
title: "-R, --recursive"
description: "Change files and directories recursively."
---

An option of [chmodx](/docs/tools/chmodx).

## Usage

```bash
chmodx -R MODE[,MODE]... FILE...
chmodx --recursive MODE[,MODE]... FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-R` | `--recursive` | none |  | change files and directories recursively |

## Examples

### Let your team edit everything in a project directory

```bash tab="bash" tab-group="shell"
chmodx -R g+w project/
```

```powershell tab="PowerShell" tab-group="shell"
chmodx -R g+w project\
```

### Make a website folder browsable without making every file executable

```bash tab="bash" tab-group="shell"
chmodx -R a+X public/
```

```powershell tab="PowerShell" tab-group="shell"
chmodx -R a+X public\
```

### Fix permissions on your docs and see every file processed

```bash tab="bash" tab-group="shell"
chmodx -v -R u+rw docs/
```

```powershell tab="PowerShell" tab-group="shell"
chmodx -v -R u+rw docs\
```
