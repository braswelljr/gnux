---
title: "-f, --silent"
description: "Suppress most error messages."
---

An option of [chmodx](/docs/tools/chmodx).

## Usage

```bash
chmodx -f MODE[,MODE]... FILE...
chmodx --silent MODE[,MODE]... FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-f` | `--silent` | none |  | suppress most error messages |

## Help in the terminal

```bash
gnux help chmodx --silent
```
