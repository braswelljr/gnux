---
title: "-L, --dereference-all"
description: "With -R, follow every symbolic link to a directory."
---

An option of [chmodx](/docs/tools/chmodx).

## Usage

```bash
chmodx -L MODE[,MODE]... FILE...
chmodx --dereference-all MODE[,MODE]... FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-L` | `--dereference-all` | none |  | with `-R`, follow every symbolic `link` to a directory |

## Help in the terminal

```bash
gnux help chmodx --dereference-all
```
