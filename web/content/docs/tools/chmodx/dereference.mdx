---
title: "--dereference"
description: "Affect the referent of each symbolic link, rather than the symbolic link itself."
---

An option of [chmodx](/docs/tools/chmodx).

## Usage

```bash
chmodx --dereference MODE[,MODE]... FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--dereference` | none |  | affect the referent of each symbolic `link`, rather than the symbolic `link` itself |

## Help in the terminal

```bash
gnux help chmodx --dereference
```
