---
title: "-P, --physical"
description: "With -R, do not follow any symbolic links."
---

An option of [chmodx](/docs/tools/chmodx).

## Usage

```bash
chmodx -P MODE[,MODE]... FILE...
chmodx --physical MODE[,MODE]... FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-P` | `--physical` | none |  | with `-R`, do not follow any symbolic links |

## Help in the terminal

```bash
gnux help chmodx --physical
```
