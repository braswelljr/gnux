---
title: "-c, --changes"
description: "Like verbose but report only when a change is made."
---

An option of [chmodx](/docs/tools/chmodx).

## Usage

```bash
chmodx -c MODE[,MODE]... FILE...
chmodx --changes MODE[,MODE]... FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-c` | `--changes` | none |  | like verbose but report only when a change is made |

## Examples

### Report only the files that changed

```bash tab="bash" tab-group="shell"
chmodx -c 644 *.txt
```

```powershell tab="PowerShell" tab-group="shell"
chmodx -c 644 (Get-ChildItem *.txt -Name)
```

## Help in the terminal

```bash
gnux help chmodx --changes
```
