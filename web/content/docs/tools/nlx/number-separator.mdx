An option of [nlx](/docs/tools/nlx).

## Usage

```bash
nlx -s STRING [FILE]...
nlx --number-separator=STRING [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-s` | `--number-separator` | `STRING` |  | add STRING after (possible) line number (default TAB) |

## Examples

### Turn a list of steps into a numbered checklist

```bash tab="bash" tab-group="shell"
nlx -w 2 -s '. ' steps.txt
```

```powershell tab="PowerShell" tab-group="shell"
nlx -w 2 -s '. ' steps.txt
```

```text title="Output"
 1. Back up the database
 2. Stop the service
 3. Run the migration
```

### Give records fixed-width, zero-padded IDs

```bash tab="bash" tab-group="shell"
nlx -n rz -w 5 -s , names.txt > names.csv
```

```powershell tab="PowerShell" tab-group="shell"
nlx -n rz -w 5 -s , names.txt > names.csv
```

```text title="Output"
00001,Ada
00002,Grace
00003,Linus
```

### Number lines left-aligned with no padding before the text

```bash tab="bash" tab-group="shell"
nlx -n ln -w 1 -s ' ' todo.txt
```

```powershell tab="PowerShell" tab-group="shell"
nlx -n ln -w 1 -s ' ' todo.txt
```
