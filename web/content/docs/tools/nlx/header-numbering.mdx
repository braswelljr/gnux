An option of [nlx](/docs/tools/nlx).

## Usage

```bash
nlx -h STYLE [FILE]...
nlx --header-numbering=STYLE [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-h` | `--header-numbering` | `STYLE` |  | use STYLE for numbering header lines (default n) |

```bash
gnux help nlx --header-numbering
```
