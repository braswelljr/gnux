---
title: "-l, --length"
description: "Digest length in bits; must not exceed the maximum for the blake2 algorithm and must be a multiple of 8."
---

An option of [cksumx](/docs/tools/cksumx).

## Usage

```bash
cksumx -l bits [FILE]...
cksumx --length=bits [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-l` | `--length` | `bits` |  | digest length in bits; must not exceed the maximum for the blake2 algorithm and must be a multiple of 8 |

## Examples

### Print a 256-bit BLAKE2b digest

```bash tab="bash" tab-group="shell"
cksumx -a blake2b -l 256 file.iso
```

```powershell tab="PowerShell" tab-group="shell"
cksumx -a blake2b -l 256 file.iso
```
