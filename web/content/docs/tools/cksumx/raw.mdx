---
title: "--raw"
description: "Emit a raw binary digest, not hexadecimal."
---

An option of [cksumx](/docs/tools/cksumx).

## Usage

```bash
cksumx --raw [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--raw` | none |  | emit a raw binary digest, not hexadecimal |

## Examples

### Write the raw binary digest of one file

```bash tab="bash" tab-group="shell"
cksumx -a sha256 --raw file.iso > file.sha256.bin
```

```powershell tab="PowerShell" tab-group="shell"
cksumx -a sha256 --raw file.iso > file.sha256.bin
```
