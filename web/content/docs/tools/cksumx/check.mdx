---
title: "-c, --check"
description: "Read checksums from the FILEs and check them."
---

An option of [cksumx](/docs/tools/cksumx).

## Usage

```bash
cksumx -c [FILE]...
cksumx --check [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-c` | `--check` | none |  | read checksums from the FILEs and check them |

## Examples

### Save tagged digests and check them later

```bash tab="bash" tab-group="shell"
cksumx -a sha256 *.iso > SUMS && cksumx -c SUMS
```

```powershell tab="PowerShell" tab-group="shell"
cksumx -a sha256 (Get-ChildItem *.iso -Name) > SUMS; cksumx -c SUMS
```

### Check silently and branch on the result

```bash tab="bash" tab-group="shell"
cksumx -c --status SUMS && echox verified
```

```powershell tab="PowerShell" tab-group="shell"
cksumx -c --status SUMS; if ($LASTEXITCODE -eq 0) { 'verified' }
```
