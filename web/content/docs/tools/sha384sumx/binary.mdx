title: "-b, --binary"
description: "Read in binary mode."
---

An option of [sha384sumx](/docs/tools/sha384sumx).

## Usage

```bash
sha384sumx -b [FILE]...
sha384sumx --binary [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-b` | `--binary` | none |  | read in binary mode |

## Examples

### Mark the files as read in binary mode

```bash tab="bash" tab-group="shell"
sha384sumx -b file.iso
```

```powershell tab="PowerShell" tab-group="shell"
sha384sumx -b file.iso
```

## Help in the terminal

```bash
gnux help sha384sumx --binary
```
