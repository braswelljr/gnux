---
title: "--status"
description: "Don't output anything, status code shows success."
---

An option of [sha384sumx](/docs/tools/sha384sumx).

## Usage

```bash
sha384sumx --status [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--status` | none |  | don't output anything, status code shows success |

## Examples

### Verify silently and branch on the result

```bash tab="bash" tab-group="shell"
sha384sumx -c --status sha384.sums && echox verified
```

```powershell tab="PowerShell" tab-group="shell"
sha384sumx -c --status sha384.sums; if ($LASTEXITCODE -eq 0) { 'verified' }
```

## Help in the terminal

```bash
gnux help sha384sumx --status
```
