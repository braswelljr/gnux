---
title: "--no-symlinks"
description: "Don't expand symlinks (same as --strip)."
---

An option of [realpathx](/docs/tools/realpathx).

## Usage

```bash
realpathx --no-symlinks FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--no-symlinks` | none |  | don't `expand` symlinks (same as `--strip`) |

## Examples

### Same thing, spelled out

```bash tab="bash" tab-group="shell"
realpathx --no-symlinks bin/tool
```

```powershell tab="PowerShell" tab-group="shell"
realpathx --no-symlinks bin\tool
```

## Help in the terminal

```bash
gnux help realpathx --no-symlinks
```
