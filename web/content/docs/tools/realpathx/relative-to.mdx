---
title: "--relative-to"
description: "Print the resolved path relative to DIR."
---

An option of [realpathx](/docs/tools/realpathx).

## Usage

```bash
realpathx --relative-to=DIR FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--relative-to` | `DIR` |  | print the resolved path relative to DIR |

## Examples

Print a path relative to another directory:

```bash
realpathx --relative-to=/usr/lib /usr/bin/sort
```

```powershell
realpathx --relative-to=C:\Windows C:\Windows\System32\sort.exe
```

## Help in the terminal

```bash
gnux help realpathx --relative-to
```
