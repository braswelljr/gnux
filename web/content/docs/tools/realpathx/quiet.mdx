---
title: "-q, --quiet"
description: "Suppress most error messages."
---

An option of [realpathx](/docs/tools/realpathx).

## Usage

```bash
realpathx -q FILE...
realpathx --quiet FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-q` | `--quiet` | none |  | suppress most error messages |

## Examples

Test for existence quietly and branch on the exit status:

```bash
realpathx -q -e config.yaml >/dev/null || echox 'config.yaml is missing'
```

```powershell
realpathx -q -e config.yaml > $null; if ($LASTEXITCODE -ne 0) { echox 'config.yaml is missing' }
```

## Help in the terminal

```bash
gnux help realpathx --quiet
```
