---
title: "--relative-base"
description: "Print absolute paths unless paths below DIR."
---

An option of [realpathx](/docs/tools/realpathx).

## Usage

```bash
realpathx --relative-base=DIR FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--relative-base` | `DIR` |  | print absolute paths unless paths below DIR |

## Examples

Make names under the project relative, but leave outside ones absolute:

```bash
realpathx --relative-base=. lib/util.go /etc/hosts
```

```powershell
realpathx --relative-base=. lib\util.go $env:WINDIR\System32\drivers\etc\hosts
```

## Help in the terminal

```bash
gnux help realpathx --relative-base
```
