---
title: "-m, --canonicalize-missing"
description: "No path components need exist or be a directory."
---

An option of [realpathx](/docs/tools/realpathx).

## Usage

```bash
realpathx -m FILE...
realpathx --canonicalize-missing FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-m` | `--canonicalize-missing` | none |  | no path components need exist or be a directory |

## Examples

Normalize a path that does not exist yet:

```bash
realpathx -m build/out/../report.txt
```

```powershell
realpathx -m build\out\..\report.txt
```

## Help in the terminal

```bash
gnux help realpathx --canonicalize-missing
```
