---
title: "--process-slot-var"
description: "Set environment variable VAR in child processes (not supported)."
---

An option of [xargsx](/docs/tools/xargsx).

## Usage

```bash
xargsx --process-slot-var=VAR [COMMAND [INITIAL-ARGUMENT]...]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--process-slot-var` | `VAR` |  | set environment variable VAR in child processes (not supported) |

## Help in the terminal

```bash
gnux help xargsx --process-slot-var
```
