An option of [xargsx](/docs/tools/xargsx).

## Usage

```bash
xargsx -0 [COMMAND [INITIAL-ARGUMENT]...]
xargsx --null [COMMAND [INITIAL-ARGUMENT]...]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-0` | `--null` | none |  | items are separated by a NUL, not whitespace; disables quote and backslash processing and logical EOF processing |

## Examples

### Remove the files a search found, whatever characters their names hold

```bash tab="bash" tab-group="shell"
findx . -name '*.tmp' -print0 | xargsx -0 rmx -f
```

```powershell tab="PowerShell" tab-group="shell"
findx . -name '*.tmp' -print0 | xargsx -0 rmx -f
```

### Do nothing at all when the search finds no file

```bash tab="bash" tab-group="shell"
findx . -name '*.orig' -print0 | xargsx -0 -r rmx
```

```powershell tab="PowerShell" tab-group="shell"
findx . -name '*.orig' -print0 | xargsx -0 -r rmx
```

### Checksum many files four commands at a time

```bash tab="bash" tab-group="shell"
findx . -type f -print0 | xargsx -0 -n 50 -P 4 sha256sumx
```

```powershell tab="PowerShell" tab-group="shell"
findx . -type f -print0 | xargsx -0 -n 50 -P 4 sha256sumx
```
