An option of [xargsx](/docs/tools/xargsx).

## Usage

```bash
xargsx -l [COMMAND [INITIAL-ARGUMENT]...]
xargsx --max-lines[=MAX-LINES] [COMMAND [INITIAL-ARGUMENT]...]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-l` | `--max-lines` | `MAX-LINES` (optional) |  | similar to `-L` but defaults to at most one non-blank input line if MAX-LINES is not specified |

## Help in the terminal

```bash
gnux help xargsx --max-lines
```
