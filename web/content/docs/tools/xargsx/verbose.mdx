---
title: "-t, --verbose"
description: "Print commands before executing them."
---

An option of [xargsx](/docs/tools/xargsx).

## Usage

```bash
xargsx -t [COMMAND [INITIAL-ARGUMENT]...]
xargsx --verbose [COMMAND [INITIAL-ARGUMENT]...]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-t` | `--verbose` | none |  | print commands before executing them |

## Examples

### Print each command line before it runs

```bash tab="bash" tab-group="shell"
seqx 4 | xargsx -t -n 2 echox
```

```powershell tab="PowerShell" tab-group="shell"
seqx 4 | xargsx -t -n 2 echox
```

## Help in the terminal

```bash
gnux help xargsx --verbose
```
