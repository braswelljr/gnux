---
title: "-L, --max-input-lines"
description: "Use at most MAX-LINES non-blank input lines per command line."
---

An option of [xargsx](/docs/tools/xargsx).

## Usage

```bash
xargsx -L MAX-LINES [COMMAND [INITIAL-ARGUMENT]...]
xargsx --max-input-lines=MAX-LINES [COMMAND [INITIAL-ARGUMENT]...]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-L` | `--max-input-lines` | `MAX-LINES` |  | use at most MAX-LINES non-blank input lines per command line |

## Examples

### Use one input line per command, as -L counts them

```bash tab="bash" tab-group="shell"
printfx 'a b\nc d\n' | xargsx -L 1 echox line:
```

```powershell tab="PowerShell" tab-group="shell"
printfx 'a b\nc d\n' | xargsx -L 1 echox line:
```

## Help in the terminal

```bash
gnux help xargsx --max-input-lines
```
