---
title: "-L, --logical"
description: "Use PWD from the environment, even if it contains symlinks."
---

An option of [pwdx](/docs/tools/pwdx).

## Usage

```bash
pwdx -L
pwdx --logical
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-L` | `--logical` | none |  | use PWD from the environment, even if it contains symlinks |

## Examples

Keep symlinks as the shell sees them:

```bash
pwdx -L
```

```powershell
pwdx -L
```

## Help in the terminal

```bash
gnux help pwdx --logical
```
