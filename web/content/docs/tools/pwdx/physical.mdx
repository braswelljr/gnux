---
title: "-P, --physical"
description: "Resolve all symlinks (default)."
---

An option of [pwdx](/docs/tools/pwdx).

## Usage

```bash
pwdx -P
pwdx --physical
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-P` | `--physical` | none |  | resolve all symlinks (default) |

## Examples

Resolve every symlink explicitly:

```bash
cd link && pwdx -P
```

```powershell
Set-Location link; pwdx -P
```

## Help in the terminal

```bash
gnux help pwdx --physical
```
