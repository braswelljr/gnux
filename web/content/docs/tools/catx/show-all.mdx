An option of [catx](/docs/tools/catx).

## Usage

```bash
catx -A [FILE]...
catx --show-all [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-A` | `--show-all` | none |  | equivalent to `-vET` |

## Examples

Reveal tabs, line ends and control characters:

```bash
catx -A Makefile
```

```powershell
catx -A Makefile
```

## Help in the terminal

```bash
gnux help catx --show-all
```
