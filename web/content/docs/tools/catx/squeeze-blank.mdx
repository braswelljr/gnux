---
title: "-s, --squeeze-blank"
description: "Suppress repeated empty output lines."
---

An option of [catx](/docs/tools/catx).

## Usage

```bash
catx -s [FILE]...
catx --squeeze-blank [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-s` | `--squeeze-blank` | none |  | suppress repeated empty output lines |

## Examples

Squeeze runs of blank lines into one, then number the result:

```bash
catx -sn draft.txt
```

```powershell
catx -sn draft.txt
```

## Help in the terminal

```bash
gnux help catx --squeeze-blank
```
