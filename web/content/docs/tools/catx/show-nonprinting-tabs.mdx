An option of [catx](/docs/tools/catx).

## Usage

```bash
catx -t [FILE]...
catx --show-nonprinting-tabs [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-t` | `--show-nonprinting-tabs` | none |  | equivalent to `-vT` |

## Examples

Show tabs and nonprinting bytes, but not line ends:

```bash
catx -t data.tsv
```

```powershell
catx -t data.tsv
```

## Help in the terminal

```bash
gnux help catx --show-nonprinting-tabs
```
