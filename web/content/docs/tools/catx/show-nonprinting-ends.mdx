An option of [catx](/docs/tools/catx).

## Usage

```bash
catx -e [FILE]...
catx --show-nonprinting-ends [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-e` | `--show-nonprinting-ends` | none |  | equivalent to `-vE` |

## Examples

Find trailing spaces and Windows line endings (shown as ^M$):

```bash
catx -e config.ini
```

```powershell
catx -e config.ini
```

## Help in the terminal

```bash
gnux help catx --show-nonprinting-ends
```
