An option of [catx](/docs/tools/catx).

## Usage

```bash
catx -u [FILE]...
catx --unbuffered [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-u` | `--unbuffered` | none |  | (ignored) |

## Examples

### Put standard input between two files (-u is accepted and ignored)

```bash tab="bash" tab-group="shell"
echox '---' | catx -u header.txt - footer.txt
```

```powershell tab="PowerShell" tab-group="shell"
'---' | catx -u header.txt - footer.txt
```
