---
title: "-r, --regex"
description: "Interpret the separator as a regular expression."
---

An option of [tacx](/docs/tools/tacx).

## Usage

```bash
tacx -r [FILE]...
tacx --regex [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-r` | `--regex` | none |  | interpret the separator as a regular expression |

## Examples

### Split records on a regular expression

```bash tab="bash" tab-group="shell"
tacx -r -s '[0-9]+' data.txt
```

```powershell tab="PowerShell" tab-group="shell"
tacx -r -s '[0-9]+' data.txt
```
