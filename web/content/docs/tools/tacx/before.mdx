---
title: "-b, --before"
description: "Attach the separator before instead of after."
---

An option of [tacx](/docs/tools/tacx).

## Usage

```bash
tacx -b [FILE]...
tacx --before [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-b` | `--before` | none |  | attach the separator before instead of after |

## Examples

### Attach each separator to the following record

```bash tab="bash" tab-group="shell"
tacx -b -s '---' notes.txt
```

```powershell tab="PowerShell" tab-group="shell"
tacx -b -s '---' notes.txt
```

## Help in the terminal

```bash
gnux help tacx --before
```
