---
title: "gnux"
description: "The GNU core utilities in one cross-platform binary, a Go library, and a portable shell."
---

`gnux` brings the interface of the GNU core utilities to every platform: one binary of GNU-compatible tools, written in Go. Every tool is named after its GNU counterpart with an x appended - `rm` is `rmx`, `cp` is `cpx`, `ls` is `lsx` - and mirrors its flags, semantics, diagnostics and exit statuses, on Linux, macOS and Windows alike. It can be used three ways: as commands, as a Go library, and through `gnux shell`, a portable script interpreter built on the tools. `gnux` is an independent project, not affiliated with or endorsed by the GNU Project or the FSF; it complements GNU coreutils rather than replacing them.

## Three ways to use it

- **Commands** - each tool is a command of its own, and a subcommand of the one binary. See the [guide](/docs/v1.0/guide).
- **Go library** - every tool's engine is an importable package. See [Go library](/docs/v1.0/library).
- **Portable shell** - scripts that run the same on every platform. See [gnux shell](/docs/v1.0/shell).

```bash
rmx -rf build/                  # a command of its own
gnux rmx -rf build/             # a subcommand
gnux shell -c 'rmx -rf build/'  # a line of a portable script
```
