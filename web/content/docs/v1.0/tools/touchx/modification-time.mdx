---
title: "-m, --modification-time"
description: "Change only the modification time."
---

An option of [touchx](/docs/v1.0/tools/touchx).

## Usage

```bash
touchx -m FILE...
touchx --modification-time FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-m` | `--modification-time` | none |  | change only the modification time |

## Examples

### Set only the modification time to a specific date

```bash tab="bash" tab-group="shell"
touchx -m -d '2024-01-02 15:04:05' report.pdf
```

```powershell tab="PowerShell" tab-group="shell"
touchx -m -d '2024-01-02 15:04:05' report.pdf
```

### Copy just the modification time, and only to files that already exist

```bash tab="bash" tab-group="shell"
touchx -c -m -r original.jpg edited.jpg report.pdf
```

```powershell tab="PowerShell" tab-group="shell"
touchx -c -m -r original.jpg edited.jpg report.pdf
```
