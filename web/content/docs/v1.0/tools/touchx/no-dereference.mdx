---
title: "-h, --no-dereference"
description: "Affect each symbolic link instead of any referenced file."
---

An option of [touchx](/docs/v1.0/tools/touchx).

## Usage

```bash
touchx -h FILE...
touchx --no-dereference FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-h` | `--no-dereference` | none |  | affect each symbolic `link` instead of any referenced file |

## Examples

### Change the times of a symbolic link itself, not its target (Linux only)

```bash tab="bash" tab-group="shell"
touchx -h -d 2024-01-01 link.txt
```

```powershell tab="PowerShell" tab-group="shell"
touchx -h -d 2024-01-01 link.txt
```
