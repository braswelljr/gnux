---
title: "-r, --reference"
description: "Use this FILE's times instead of current time."
---

An option of [touchx](/docs/v1.0/tools/touchx).

## Usage

```bash
touchx -r FILE FILE...
touchx --reference=FILE FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-r` | `--reference` | `FILE` |  | use this FILE's times instead of current time |

## Examples

### Give one file the timestamps of another

```bash tab="bash" tab-group="shell"
touchx -r original.jpg edited.jpg
```

```powershell tab="PowerShell" tab-group="shell"
touchx -r original.jpg edited.jpg
```

### Copy just the modification time, and only to files that already exist

```bash tab="bash" tab-group="shell"
touchx -c -m -r original.jpg edited.jpg report.pdf
```

```powershell tab="PowerShell" tab-group="shell"
touchx -c -m -r original.jpg edited.jpg report.pdf
```
