An option of [trx](/docs/v1.0/tools/trx).

## Usage

```bash
trx -C STRING1 [STRING2]
trx --complement-upper STRING1 [STRING2]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-C` | `--complement-upper` | none |  | equivalent to `-c` |
