---
title: "-s, --squeeze-repeats"
description: "Replace each sequence of a repeated character that is listed in the last specified SET, with a single occurrence of that character."
---

An option of [trx](/docs/v1.0/tools/trx).

## Usage

```bash
trx -s STRING1 [STRING2]
trx --squeeze-repeats STRING1 [STRING2]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-s` | `--squeeze-repeats` | none |  | replace each sequence of a repeated character that is listed in the last specified SET, with a single occurrence of that character |

## Examples

### Squeeze runs of spaces into one

```bash tab="bash" tab-group="shell"
echox 'a    b     c' | trx -s ' '
```

```powershell tab="PowerShell" tab-group="shell"
'a    b     c' | trx -s ' '
```

### Put each word on a line of its own

```bash tab="bash" tab-group="shell"
catx essay.txt | trx -cs '[:alnum:]' '\n'
```

```powershell tab="PowerShell" tab-group="shell"
catx essay.txt | trx -cs '[:alnum:]' '\n'
```

### Delete digits and squeeze the spaces left behind

```bash tab="bash" tab-group="shell"
echox 'a 1 2 b' | trx -ds '[:digit:]' ' '
```

```powershell tab="PowerShell" tab-group="shell"
'a 1 2 b' | trx -ds '[:digit:]' ' '
```
