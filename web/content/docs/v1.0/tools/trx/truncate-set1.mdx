An option of [trx](/docs/v1.0/tools/trx).

## Usage

```bash
trx -t STRING1 [STRING2]
trx --truncate-set1 STRING1 [STRING2]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-t` | `--truncate-set1` | none |  | first `truncate` SET1 to length of SET2 |

## Examples

### Map a set onto a shorter one without padding it (-t)

```bash tab="bash" tab-group="shell"
echox abcde | trx -t a-e xy
```

```powershell tab="PowerShell" tab-group="shell"
'abcde' | trx -t a-e xy
```
