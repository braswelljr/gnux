---
title: "-D, --dereference-args"
description: "Dereference only symlinks that are listed on the command line."
---

An option of [dux](/docs/v1.0/tools/dux).

## Usage

```bash
dux -D [FILE]...
dux --dereference-args [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-D` | `--dereference-args` | none |  | dereference only symlinks that are listed on the command line |

## Help in the terminal

```bash
gnux help dux --dereference-args
```
