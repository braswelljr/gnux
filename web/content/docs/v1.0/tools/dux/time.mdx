title: "--time"
description: "Show time of the last modification of any file in the directory, or any of its subdirectories; with WORD: atime, access, use, ctime or status."
---

An option of [dux](/docs/v1.0/tools/dux).

## Usage

```bash
dux --time[=WORD] [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--time` | `WORD` (optional) |  | show time of the last modification of any file in the directory, or any of its subdirectories; with WORD: atime, access, use, ctime or status |

## Examples

### See which log directories changed most recently

```bash tab="bash" tab-group="shell"
dux -sh --time /var/log/*
```

```powershell tab="PowerShell" tab-group="shell"
dux -sh --time (Get-ChildItem C:\logs -Directory).FullName
```

```text title="Output"
1.3M	2026-10-12 09:41	/var/log/apt
96M	2026-10-12 10:02	/var/log/journal
```
