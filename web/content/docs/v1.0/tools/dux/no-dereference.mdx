title: "-P, --no-dereference"

---

An option of [dux](/docs/v1.0/tools/dux).

## Usage

```bash
dux -P [FILE]...
dux --no-dereference [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-P` | `--no-dereference` | none |  | don't follow any symbolic links (this is the default) |

## Help in the terminal

```bash
gnux help dux --no-dereference
```
