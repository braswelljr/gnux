---
title: "-i, --input-range"
description: "Treat each number LO-HI as an input line."
---

An option of [shufx](/docs/v1.0/tools/shufx).

## Usage

```bash
shufx -i LO-HI [FILE]
shufx --input-range=LO-HI [FILE]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-i` | `--input-range` | `LO-HI` |  | treat each number LO-HI as an input line |

## Examples

### Shuffle the numbers 1 to 10

```bash tab="bash" tab-group="shell"
shufx -i 1-10
```

```powershell tab="PowerShell" tab-group="shell"
shufx -i 1-10
```

### Roll a die five times (numbers may repeat)

```bash tab="bash" tab-group="shell"
shufx -i 1-6 -r -n 5
```

```powershell tab="PowerShell" tab-group="shell"
shufx -i 1-6 -r -n 5
```
