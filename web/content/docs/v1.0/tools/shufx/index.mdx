Mirrors GNU `shuf`. Run it as `shufx`, or as `gnux shufx`.

## Synopsis

```bash
shufx [OPTION]... [FILE]
```

## GNU reference

- [GNU coreutils manual: shuf invocation](https://www.gnu.org/software/coreutils/manual/html_node/shuf-invocation.html)
- [Source: src/shuf.c in coreutils/coreutils](https://github.com/coreutils/coreutils/blob/master/src/shuf.c)

## Description

`shufx` writes a random permutation of its input lines to standard output. The input is the lines of FILE, or of standard input when FILE is absent or -; with `-e`, each ARG operand is an input line instead (`shufx -e` [OPTION]... [ARG]...); with `-i` LO-HI, the numbers LO through HI are (`shufx -i` LO-HI [OPTION]...). `-n` COUNT writes at most COUNT lines (given more than once, the smallest COUNT wins, as in GNU `shuf`). `-r` draws with replacement, so lines may repeat, and with no `-n` it writes forever until its reader goes away. `-o` FILE writes to FILE instead of standard output; it is opened only after the input has been read, so FILE may also be the input. `--random-source`=FILE takes the random bytes from FILE, so the same FILE always gives the same order; without it the order comes from a generator seeded by the operating system's random source. `-z` uses NUL rather than newline as the line delimiter. Differences from GNU `shuf`: the permutation drawn from a given `--random-source` differs from the one GNU `shuf` draws from the same bytes, though it is just as reproducible.

## Permissions

Needs read permission on FILE and on the `--random-source` file, and search permission on the directories leading to them. With `-o`, needs write permission on the output file, or on its directory when it does not exist yet.

## Use cases

- Putting the lines of a file in random order.
- Picking a random sample of N lines with `-n`.
- Choosing one item at random from a list of operands with `-e -n` 1.
- Generating random numbers in a range with `-i`, with or without repeats.
- Shuffling a playlist, a deck or a `test` order.
- Getting a reproducible shuffle in tests with `--random-source`.
- Producing an endless stream of random choices with `-r`.
- Splitting a data set into random training and `test` portions.

## Flags

```text
  -e, --echo                 treat each ARG as an input line
  -n, --head-count COUNT     output at most COUNT lines
      --help                 display this help and exit
  -i, --input-range LO-HI    treat each number LO-HI as an input line
  -o, --output FILE          write result to FILE instead of standard output
      --random-source FILE   get random bytes from FILE
  -r, --repeat               output lines can be repeated
      --version              output version information and exit
  -z, --zero-terminated      line delimiter is NUL, not newline
```

## Examples

### Shuffle the lines of a file

```bash tab="bash" tab-group="shell"
shufx names.txt
```

```powershell tab="PowerShell" tab-group="shell"
shufx names.txt
```

### Pick three random lines

```bash tab="bash" tab-group="shell"
shufx -n 3 names.txt
```

```powershell tab="PowerShell" tab-group="shell"
shufx -n 3 names.txt
```

### Pick one of several words

```bash tab="bash" tab-group="shell"
shufx -e -n 1 red green blue
```

```powershell tab="PowerShell" tab-group="shell"
shufx -e -n 1 red green blue
```

### Shuffle the numbers 1 to 10

```bash tab="bash" tab-group="shell"
shufx -i 1-10
```

```powershell tab="PowerShell" tab-group="shell"
shufx -i 1-10
```

### Roll a die five times (numbers may repeat)

```bash tab="bash" tab-group="shell"
shufx -i 1-6 -r -n 5
```

```powershell tab="PowerShell" tab-group="shell"
shufx -i 1-6 -r -n 5
```

### Shuffle standard input

```bash tab="bash" tab-group="shell"
seqx 5 | shufx
```

```powershell tab="PowerShell" tab-group="shell"
1..5 | shufx
```

### Shuffle a file in place

```bash tab="bash" tab-group="shell"
shufx -o deck.txt deck.txt
```

```powershell tab="PowerShell" tab-group="shell"
shufx -o deck.txt deck.txt
```

### A reproducible order for tests

```bash tab="bash" tab-group="shell"
shufx --random-source=seed.bin cases.txt
```

```powershell tab="PowerShell" tab-group="shell"
shufx --random-source=seed.bin cases.txt
```

### Pick a random file from a NUL-separated list

```bash tab="bash" tab-group="shell"
find . -type f -print0 | shufx -z -n 1
```

```powershell tab="PowerShell" tab-group="shell"
lsx -1 | shufx -n 1
```

### An endless stream of coin flips, cut short by headx

```bash tab="bash" tab-group="shell"
shufx -r -e heads tails | headx -n 4
```

```powershell tab="PowerShell" tab-group="shell"
shufx -r -e heads tails | headx -n 4
```

### Sample 100 lines for a quick look at a large log

```bash tab="bash" tab-group="shell"
shufx -n 100 access.log > sample.log
```

```powershell tab="PowerShell" tab-group="shell"
shufx -n 100 access.log > sample.log
```

### Shuffle in the portable gnux shell

```bash tab="bash" tab-group="shell"
gnux shell -c 'lsx -1 | shufx -n 2'
```

```powershell tab="PowerShell" tab-group="shell"
gnux shell -c 'lsx -1 | shufx -n 2'
```

## Options

Each option has a page of its own, with its usage and examples.

- [-e, --echo](/docs/v1.0/tools/shufx/echo): Treat each ARG as an input line.
- [-n, --head-count](/docs/v1.0/tools/shufx/head-count): Output at most COUNT lines.
- [-i, --input-range](/docs/v1.0/tools/shufx/input-range): Treat each number LO-HI as an input line.
- [-o, --output](/docs/v1.0/tools/shufx/output): Write result to FILE instead of standard output.
- [--random-source](/docs/v1.0/tools/shufx/random-source): Get random bytes from FILE.
- [-r, --repeat](/docs/v1.0/tools/shufx/repeat): Output lines can be repeated.
- [-z, --zero-terminated](/docs/v1.0/tools/shufx/zero-terminated): Line delimiter is NUL, not newline.

## Exit status

| Status | Meaning |
|--------|---------|
| 0 | success: every operand was processed |
| 1 | failure: an operand could not be processed (diagnosed on standard error), or a command-line mistake |

```bash
shufx --help                # options, first examples, exit status
gnux help shufx             # this page: the full manual
gnux help shufx --OPTION    # one option in depth, with its examples
```
