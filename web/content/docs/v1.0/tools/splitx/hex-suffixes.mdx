An option of [splitx](/docs/v1.0/tools/splitx).

## Usage

```bash
splitx -x [FILE [PREFIX]]
splitx --hex-suffixes[=FROM] [FILE [PREFIX]]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-x` | `--hex-suffixes` | `FROM` (optional) |  | use hex suffixes starting at 0, not alphabetic; `--hex-suffixes`=FROM starts at FROM |

## Help in the terminal

```bash
gnux help splitx --hex-suffixes
```
