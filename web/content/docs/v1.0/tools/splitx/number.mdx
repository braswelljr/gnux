An option of [splitx](/docs/v1.0/tools/splitx).

## Usage

```bash
splitx -n CHUNKS [FILE [PREFIX]]
splitx --number=CHUNKS [FILE [PREFIX]]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-n` | `--number` | `CHUNKS` |  | generate CHUNKS output files: N, K/N, l/N, l/K/N, r/N or r/K/N |

## Examples

### Split a log into 4 roughly equal parts for 4 parallel workers, without cutting a line in half

```bash tab="bash" tab-group="shell"
splitx -n l/4 access.log chunk-
```

```powershell tab="PowerShell" tab-group="shell"
splitx -n l/4 access.log chunk-
```

### Deal a list of URLs out to 3 crawlers in turn

```bash tab="bash" tab-group="shell"
splitx -n r/3 urls.txt crawler-
```

```powershell tab="PowerShell" tab-group="shell"
splitx -n r/3 urls.txt crawler-
```

### Look at just the third quarter of a huge file without writing any pieces

```bash tab="bash" tab-group="shell"
splitx -n l/3/4 huge.log | headx
```

```powershell tab="PowerShell" tab-group="shell"
splitx -n l/3/4 huge.log | headx
```
