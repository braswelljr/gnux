---
title: "-C, --line-bytes"
description: "Put at most SIZE bytes of records per output file."
---

An option of [splitx](/docs/v1.0/tools/splitx).

## Usage

```bash
splitx -C SIZE [FILE [PREFIX]]
splitx --line-bytes=SIZE [FILE [PREFIX]]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-C` | `--line-bytes` | `SIZE` |  | put at most SIZE bytes of records per output file |

## Examples

### Send a log in email-sized pieces of at most 5 MB, keeping lines whole

```bash tab="bash" tab-group="shell"
splitx -C 5M app.log app.log.
```

```powershell tab="PowerShell" tab-group="shell"
splitx -C 5M app.log app.log.
```
