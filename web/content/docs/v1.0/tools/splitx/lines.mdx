---
title: "-l, --lines"
description: "Put NUMBER lines/records per output file."
---

An option of [splitx](/docs/v1.0/tools/splitx).

## Usage

```bash
splitx -l NUMBER [FILE [PREFIX]]
splitx --lines=NUMBER [FILE [PREFIX]]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-l` | `--lines` | `NUMBER` |  | put NUMBER lines/records per output file |

## Examples

### Break a million-row CSV into files of 100,000 rows for an import tool that chokes on big files

```bash tab="bash" tab-group="shell"
tailx -n +2 users.csv | splitx -l 100000 -d --additional-suffix=.csv - users-
```

```powershell tab="PowerShell" tab-group="shell"
tailx -n +2 users.csv | splitx -l 100000 -d --additional-suffix=.csv - users-
```

```text title="Output"
(creates users-00.csv ... users-09.csv)
```

### Number the pieces from 1 instead of 0

```bash tab="bash" tab-group="shell"
splitx -l 500 --numeric-suffixes=1 -a 3 list.txt list-
```

```powershell tab="PowerShell" tab-group="shell"
splitx -l 500 --numeric-suffixes=1 -a 3 list.txt list-
```

```text title="Output"
(creates list-001, list-002, ...)
```

### See each file as it is created

```bash tab="bash" tab-group="shell"
splitx --verbose -l 2 names.txt
```

```powershell tab="PowerShell" tab-group="shell"
splitx --verbose -l 2 names.txt
```

```text title="Output"
creating file 'xaa'
creating file 'xab'
```

### Split NUL-separated records, such as the output of find -print0

```bash tab="bash" tab-group="shell"
find . -type f -print0 | splitx -t '\0' -l 1000 - batch-
```

```powershell tab="PowerShell" tab-group="shell"
splitx -t '\0' -l 1000 files.lst batch-
```
