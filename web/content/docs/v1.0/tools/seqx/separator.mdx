---
title: "-s, --separator"
description: "Use STRING to separate numbers."
---

An option of [seqx](/docs/v1.0/tools/seqx).

## Usage

```bash
seqx -s STRING [FIRST [INCREMENT]] LAST
seqx --separator=STRING [FIRST [INCREMENT]] LAST
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-s` | `--separator` | `STRING` | `\n` | use STRING to separate numbers |

## Examples

### Separate the numbers with commas on one line

```bash tab="bash" tab-group="shell"
seqx -s , 1 10
```

```powershell tab="PowerShell" tab-group="shell"
seqx -s , 1 10
```

### Sum the numbers 1 to 100 with another program

```bash tab="bash" tab-group="shell"
seqx -s + 1 100 | bc
```

```powershell tab="PowerShell" tab-group="shell"
(seqx 1 100 | Measure-Object -Sum).Sum
```
