---
title: "-p, --no-renumber"
description: "Do not reset line numbers for each section."
---

An option of [nlx](/docs/v1.0/tools/nlx).

## Usage

```bash
nlx -p [FILE]...
nlx --no-renumber [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-p` | `--no-renumber` | none |  | do not reset line numbers for each section |

## Help in the terminal

```bash
gnux help nlx --no-renumber
```
