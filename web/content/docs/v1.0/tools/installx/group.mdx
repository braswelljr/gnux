---
title: "-g, --group"
description: "Set group ownership, instead of process' current group, to GROUP."
---

An option of [installx](/docs/v1.0/tools/installx).

## Usage

```bash
installx -g GROUP SOURCE... DEST
installx --group=GROUP SOURCE... DEST
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-g` | `--group` | `GROUP` |  | set group ownership, instead of process' current group, to GROUP |

## Help in the terminal

```bash
gnux help installx --group
```
