---
title: "-u, --unique"
description: "Only print unique lines."
---

An option of [uniqx](/docs/v1.0/tools/uniqx).

## Usage

```bash
uniqx -u [INPUT [OUTPUT]]
uniqx --unique [INPUT [OUTPUT]]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-u` | `--unique` | none |  | only print unique lines |

## Examples

### Print only the lines that are not repeated

```bash tab="bash" tab-group="shell"
uniqx -u sorted.txt
```

```powershell tab="PowerShell" tab-group="shell"
uniqx -u sorted.txt
```

## Help in the terminal

```bash
gnux help uniqx --unique
```
