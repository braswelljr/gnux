---
title: "-w, --check-chars"
description: "Compare no more than N characters in lines."
---

An option of [uniqx](/docs/v1.0/tools/uniqx).

## Usage

```bash
uniqx -w N [INPUT [OUTPUT]]
uniqx --check-chars=N [INPUT [OUTPUT]]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-w` | `--check-chars` | `N` |  | compare no more than N characters in lines |

## Examples

### Treat lines that share their first 8 characters as equal

```bash tab="bash" tab-group="shell"
uniqx -w 8 commits.txt
```

```powershell tab="PowerShell" tab-group="shell"
uniqx -w 8 commits.txt
```
