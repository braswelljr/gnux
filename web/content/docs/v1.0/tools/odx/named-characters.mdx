An option of [odx](/docs/v1.0/tools/odx).

## Usage

```bash
odx -a [FILE]...
odx --named-characters[=string] [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-a` | `--named-characters` | `string` (optional) |  | same as `-t` a, select named characters, ignoring high-order bit |

gnux help odx --named-characters
