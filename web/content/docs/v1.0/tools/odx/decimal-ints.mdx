An option of [odx](/docs/v1.0/tools/odx).

## Usage

```bash
odx -i [FILE]...
odx --decimal-ints[=string] [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-i` | `--decimal-ints` | `string` (optional) |  | same as `-t` dI, select decimal ints |
