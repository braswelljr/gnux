---
title: "-t, --separator"
description: "Use CHAR as input and output field separator."
---

An option of [joinx](/docs/v1.0/tools/joinx).

## Usage

```bash
joinx -t CHAR FILE1 FILE2
joinx --separator=CHAR FILE1 FILE2
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-t` | `--separator` | `CHAR` |  | use CHAR as input and output field separator |

## Examples

### Attach each order to its customer from two CSV exports

```bash tab="bash" tab-group="shell"
joinx -t, users.csv orders.csv
```

```powershell tab="PowerShell" tab-group="shell"
joinx -t, users.csv orders.csv
```

### Join two CSV exports that each start with a header row

```bash tab="bash" tab-group="shell"
joinx --header -t, users.csv orders.csv
```

```powershell tab="PowerShell" tab-group="shell"
joinx --header -t, users.csv orders.csv
```
