An option of [joinx](/docs/v1.0/tools/joinx).

## Usage

```bash
joinx -j stringArray FILE1 FILE2
joinx --join-field=stringArray FILE1 FILE2
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-j` | `--join-field` | `stringArray` |  | equivalent to '-1 FIELD -2 FIELD' |

## Help in the terminal

```bash
gnux help joinx --join-field
```
