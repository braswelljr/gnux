---
title: "-z, --zero-terminated"
description: "Line delimiter is NUL, not newline."
---

An option of [joinx](/docs/v1.0/tools/joinx).

## Usage

```bash
joinx -z FILE1 FILE2
joinx --zero-terminated FILE1 FILE2
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-z` | `--zero-terminated` | none |  | line delimiter is NUL, not newline |

## Help in the terminal

```bash
gnux help joinx --zero-terminated
```
