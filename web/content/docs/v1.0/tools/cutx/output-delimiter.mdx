---
title: "--output-delimiter"
description: "Use STRING as the output delimiter; the default is to use the input delimiter."
---

An option of [cutx](/docs/v1.0/tools/cutx).

## Usage

```bash
cutx --output-delimiter=STRING OPTION... [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--output-delimiter` | `STRING` |  | use STRING as the output delimiter; the default is to use the input delimiter |

## Examples

### Convert a CSV file to TAB-separated output

```bash tab="bash" tab-group="shell"
cutx -d , -f 1- --output-delimiter=$'\t' people.csv
```

```powershell tab="PowerShell" tab-group="shell"
cutx -d , -f 1- --output-delimiter="`t" people.csv
```

### Join the selected columns with a custom separator

```bash tab="bash" tab-group="shell"
cutx -d : -f 1,3 --output-delimiter=' -> ' passwd.txt
```

```powershell tab="PowerShell" tab-group="shell"
cutx -d : -f 1,3 --output-delimiter=' -> ' passwd.txt
```
