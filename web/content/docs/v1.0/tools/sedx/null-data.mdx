---
title: "-z, --null-data"
description: "Separate lines by NUL characters."
---

An option of [sedx](/docs/v1.0/tools/sedx).

## Usage

```bash
sedx -z {script-only-if-no-other-script} [input-file]...
sedx --null-data {script-only-if-no-other-script} [input-file]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-z` | `--null-data` | none |  | separate lines by NUL characters |

## Help in the terminal

```bash
gnux help sedx --null-data
```
