title: "-i, --in-place"
description: "Edit files in place; -iSUFFIX or --in-place=SUFFIX also keeps each original under that suffix."
---

An option of [sedx](/docs/v1.0/tools/sedx).

## Usage

```bash
sedx -i {script-only-if-no-other-script} [input-file]...
sedx --in-place {script-only-if-no-other-script} [input-file]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-i` | `--in-place` | none |  | edit files in place; `-iSUFFIX` or `--in-place`=SUFFIX also keeps each original under that suffix |

## Examples

### Point a config file at a new host, keeping the original as config.ini.bak

```bash tab="bash" tab-group="shell"
sedx -i.bak 's/^host = .*/host = db2.internal/' config.ini
```

```powershell tab="PowerShell" tab-group="shell"
sedx '-i.bak' 's/^host = .*/host = db2.internal/' config.ini
```

### Add a line after the one that matches, in every YAML file of a directory

```bash tab="bash" tab-group="shell"
sedx -i '/^dependencies:/a\  - gnux' *.yaml
```

```powershell tab="PowerShell" tab-group="shell"
sedx -i '/^dependencies:/a\  - gnux' (Get-ChildItem *.yaml).Name
```

### Remove trailing white space from every source file, in place

```bash tab="bash" tab-group="shell"
sedx -i 's/[[:space:]]*$//' main.go util.go
```

```powershell tab="PowerShell" tab-group="shell"
sedx -i 's/[[:space:]]*$//' main.go util.go
```
