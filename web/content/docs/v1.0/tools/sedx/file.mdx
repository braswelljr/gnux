---

An option of [sedx](/docs/v1.0/tools/sedx).

## Usage

```bash
sedx -f SCRIPT-FILE {script-only-if-no-other-script} [input-file]...
sedx --file=SCRIPT-FILE {script-only-if-no-other-script} [input-file]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-f` | `--file` | `SCRIPT-FILE` |  | add the contents of SCRIPT-FILE to the commands to be executed |

## Examples

### Run an edit script kept in a file

```bash tab="bash" tab-group="shell"
sedx -f cleanup.sed report.txt > report.clean.txt
```

```powershell tab="PowerShell" tab-group="shell"
sedx -f cleanup.sed report.txt > report.clean.txt
```
