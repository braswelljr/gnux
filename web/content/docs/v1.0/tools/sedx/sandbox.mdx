---
title: "--sandbox"
description: "Operate in sandbox mode (refuse the r, R, w and W commands)."
---

An option of [sedx](/docs/v1.0/tools/sedx).

## Usage

```bash
sedx --sandbox {script-only-if-no-other-script} [input-file]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--sandbox` | none |  | operate in sandbox mode (refuse the r, R, w and W commands) |

## Help in the terminal

```bash
gnux help sedx --sandbox
```
