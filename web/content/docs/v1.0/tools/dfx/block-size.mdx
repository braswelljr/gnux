---
title: "-B, --block-size"
description: "Scale sizes by SIZE before printing them; e.g., '-BM' prints sizes in units of 1,048,576 bytes."
---

An option of [dfx](/docs/v1.0/tools/dfx).

## Usage

```bash
dfx -B SIZE [FILE]...
dfx --block-size=SIZE [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-B` | `--block-size` | `SIZE` |  | scale sizes by SIZE before printing them; e.g., '`-BM`' prints sizes in units of 1,048,576 bytes |

## Examples

### Print just the available space, in megabytes, for a script

```bash tab="bash" tab-group="shell"
dfx -BM --output=avail /data | tailx -n 1
```

```powershell tab="PowerShell" tab-group="shell"
dfx -BM --output=avail D:\ | tailx -n 1
```

```text title="Output"
  48213M
```
