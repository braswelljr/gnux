---
title: "-0, --null"
description: "End each output line with NUL, not newline."
---

An option of [printenvx](/docs/v1.0/tools/printenvx).

## Usage

```bash
printenvx -0 [VARIABLE]...
printenvx --null [VARIABLE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-0` | `--null` | none |  | end each output line with NUL, not newline |

## Examples

### Print the environment NUL-separated

```bash tab="bash" tab-group="shell"
printenvx -0 | trx '\0' '\n' | wcx -l
```

```powershell tab="PowerShell" tab-group="shell"
printenvx -0 | trx '\0' '\n' | wcx -l
```

## Help in the terminal

```bash
gnux help printenvx --null
```
