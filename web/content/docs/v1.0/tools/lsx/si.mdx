---
title: "--si"
description: "Likewise, but use powers of 1000 not 1024."
---

An option of [lsx](/docs/v1.0/tools/lsx).

## Usage

```bash
lsx --si [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--si` | none |  | likewise, but use powers of 1000 not 1024 |

## Examples

### Largest files first, with sizes in powers of 1000

```bash tab="bash" tab-group="shell"
lsx -lS --si downloads/
```

```powershell tab="PowerShell" tab-group="shell"
lsx -lS --si downloads
```

## Help in the terminal

```bash
gnux help lsx --si
```
