---
title: "-F, --classify"
description: "Append indicator (one of */=@|) to entries."
---

An option of [lsx](/docs/v1.0/tools/lsx).

## Usage

```bash
lsx -F [FILE]...
lsx --classify [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-F` | `--classify` | none |  | append indicator (one of */=@\|) to entries |

## Examples

### Recursively list a tree, marking directories and executables

```bash tab="bash" tab-group="shell"
lsx -RF src/
```

```powershell tab="PowerShell" tab-group="shell"
lsx -RF src
```

gnux help lsx --classify
