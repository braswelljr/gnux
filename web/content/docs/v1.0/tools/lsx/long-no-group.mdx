title: "-o, --long-no-group"
description: "Like -l, but do not list group information."
---

An option of [lsx](/docs/v1.0/tools/lsx).

## Usage

```bash
lsx -o [FILE]...
lsx --long-no-group [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-o` | `--long-no-group` | none |  | like `-l`, but do not list group information |

## Examples

### Long format with numeric user and group IDs, or without the owner or group columns

```bash tab="bash" tab-group="shell"
lsx -n data/ && lsx -g data/ && lsx -o data/ && lsx -lG data/
```

```powershell tab="PowerShell" tab-group="shell"
lsx -n data; lsx -g data; lsx -o data; lsx -lG data
```

## Help in the terminal

```bash
gnux help lsx --long-no-group
```
