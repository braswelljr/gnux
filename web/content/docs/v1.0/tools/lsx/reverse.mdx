---
title: "-r, --reverse"
description: "Reverse order while sorting."
---

An option of [lsx](/docs/v1.0/tools/lsx).

## Usage

```bash
lsx -r [FILE]...
lsx --reverse [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-r` | `--reverse` | none |  | reverse order while sorting |

## Examples

### Smallest files first (reverse the size sort)

```bash tab="bash" tab-group="shell"
lsx -lShr downloads/
```

```powershell tab="PowerShell" tab-group="shell"
lsx -lShr downloads
```

## Help in the terminal

```bash
gnux help lsx --reverse
```
