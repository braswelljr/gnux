---
title: "-g, --long-no-owner"
description: "Like -l, but do not list owner."
---

An option of [lsx](/docs/v1.0/tools/lsx).

## Usage

```bash
lsx -g [FILE]...
lsx --long-no-owner [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-g` | `--long-no-owner` | none |  | like `-l`, but do not list owner |

## Examples

### Long format with numeric user and group IDs, or without the owner or group columns

```bash tab="bash" tab-group="shell"
lsx -n data/ && lsx -g data/ && lsx -o data/ && lsx -lG data/
```

```powershell tab="PowerShell" tab-group="shell"
lsx -n data; lsx -g data; lsx -o data; lsx -lG data
```

## Help in the terminal

```bash
gnux help lsx --long-no-owner
```
