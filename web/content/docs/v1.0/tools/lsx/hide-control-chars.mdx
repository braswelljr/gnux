An option of [lsx](/docs/v1.0/tools/lsx).

## Usage

```bash
lsx -q [FILE]...
lsx --hide-control-chars [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-q` | `--hide-control-chars` | none |  | print ? instead of nongraphic characters |

## Examples

### Quote names, or escape control characters, to spot odd file names

```bash tab="bash" tab-group="shell"
lsx -Q && lsx -b && lsx -q
```

```powershell tab="PowerShell" tab-group="shell"
lsx -Q; lsx -b; lsx -q
```

## Help in the terminal

```bash
gnux help lsx --hide-control-chars
```
