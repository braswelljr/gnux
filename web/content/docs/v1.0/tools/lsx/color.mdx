---
title: "--color"
description: "Color the output WHEN: 'always' (the default when WHEN is omitted), 'auto', or 'never'."
---

An option of [lsx](/docs/v1.0/tools/lsx).

## Usage

```bash
lsx --color[=WHEN] [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--color` | `WHEN` (optional) | `never` | color the output WHEN: 'always' (the default when WHEN is omitted), 'auto', or 'never' |

## Examples

### Color by file type and mark types (but not executables) when writing to a terminal

```bash tab="bash" tab-group="shell"
lsx --color=auto --file-type -C -T 4
```

```powershell tab="PowerShell" tab-group="shell"
lsx --color=auto --file-type -C -T 4
```

## Help in the terminal

```bash
gnux help lsx --color
```
