---
title: "-c, --ctime"
description: "With -lt: sort by, and show, ctime (time of last change of file status information); with -l: show ctime and sort by name; otherwise: sort by ctime, newest first."
---

An option of [lsx](/docs/v1.0/tools/lsx).

## Usage

```bash
lsx -c [FILE]...
lsx --ctime [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-c` | `--ctime` | none |  | with `-lt`: sort by, and show, ctime (time of last change of file status information); with `-l`: show ctime and sort by name; otherwise: sort by ctime, newest first |

## Help in the terminal

```bash
gnux help lsx --ctime
```
