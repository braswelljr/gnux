An option of [whox](/docs/v1.0/tools/whox).

## Usage

```bash
whox -r [ FILE | ARG1 ARG2 ]
whox --runlevel [ FILE | ARG1 ARG2 ]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-r` | `--runlevel` | none |  | print current runlevel |

## Help in the terminal

```bash
gnux help whox --runlevel
```
