---
title: "-d, --dead"
description: "Print dead processes."
---

An option of [whox](/docs/v1.0/tools/whox).

## Usage

```bash
whox -d [ FILE | ARG1 ARG2 ]
whox --dead [ FILE | ARG1 ARG2 ]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-d` | `--dead` | none |  | print dead processes |

## Help in the terminal

```bash
gnux help whox --dead
```
