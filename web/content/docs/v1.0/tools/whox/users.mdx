---
title: "-u, --users"
description: "List users logged in."
---

An option of [whox](/docs/v1.0/tools/whox).

## Usage

```bash
whox -u [ FILE | ARG1 ARG2 ]
whox --users [ FILE | ARG1 ARG2 ]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-u` | `--users` | none |  | list users logged in |

## Examples

### See how long each session has been idle, with headings

```bash tab="bash" tab-group="shell"
whox -uH
```

```powershell tab="PowerShell" tab-group="shell"
whox -uH
```

```text title="Output"
NAME     LINE         TIME         IDLE          PID COMMENT
alice    pts/0        Oct 12 09:30 01:30        1234 (10.0.0.5)
bob      pts/1        Oct 12 13:02   .          1300 (laptop.lan)
```
