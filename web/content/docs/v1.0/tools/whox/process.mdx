title: "-p, --process"

An option of [whox](/docs/v1.0/tools/whox).

## Usage

```bash
whox -p [ FILE | ARG1 ARG2 ]
whox --process [ FILE | ARG1 ARG2 ]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-p` | `--process` | none |  | print active processes spawned by init |

## Help in the terminal

```bash
gnux help whox --process
```
