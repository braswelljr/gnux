---
title: "-2, --suppress-file2"
description: "Suppress column 2 (lines unique to FILE2)."
---

An option of [commx](/docs/v1.0/tools/commx).

## Usage

```bash
commx -2 FILE1 FILE2
commx --suppress-file2 FILE1 FILE2
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-2` | `--suppress-file2` | none |  | suppress column 2 (lines unique to FILE2) |

## Help in the terminal

```bash
gnux help commx --suppress-file2
```
