---
title: "--nocheck-order"
description: "Do not check that the input is correctly sorted."
---

An option of [commx](/docs/v1.0/tools/commx).

## Usage

```bash
commx --nocheck-order FILE1 FILE2
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--nocheck-order` | none |  | do not check that the input is correctly sorted |

## Examples

### Skip the order check

```bash tab="bash" tab-group="shell"
commx --nocheck-order old.txt new.txt
```

```powershell tab="PowerShell" tab-group="shell"
commx --nocheck-order old.txt new.txt
```
