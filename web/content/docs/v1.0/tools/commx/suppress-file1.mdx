---
title: "-1, --suppress-file1"
description: "Suppress column 1 (lines unique to FILE1)."
---

An option of [commx](/docs/v1.0/tools/commx).

## Usage

```bash
commx -1 FILE1 FILE2
commx --suppress-file1 FILE1 FILE2
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-1` | `--suppress-file1` | none |  | suppress column 1 (lines unique to FILE1) |

## Help in the terminal

```bash
gnux help commx --suppress-file1
```
