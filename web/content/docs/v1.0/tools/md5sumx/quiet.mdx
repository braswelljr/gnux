---
title: "--quiet"
description: "Don't print OK for each successfully verified file."
---

An option of [md5sumx](/docs/v1.0/tools/md5sumx).

## Usage

```bash
md5sumx --quiet [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--quiet` | none |  | don't print OK for each successfully verified file |

## Examples

### Re-check a large archive set and show only what no longer matches

```bash tab="bash" tab-group="shell"
md5sumx -c --quiet md5.sums
```

```powershell tab="PowerShell" tab-group="shell"
md5sumx -c --quiet md5.sums
```

```text title="Output"
notes.txt: FAILED
md5sumx: WARNING: 1 computed checksum did NOT match
```

## Help in the terminal

```bash
gnux help md5sumx --quiet
```
