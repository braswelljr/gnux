---
title: "--strict"
description: "Exit non-zero for improperly formatted checksum lines."
---

An option of [md5sumx](/docs/v1.0/tools/md5sumx).

## Usage

```bash
md5sumx --strict [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--strict` | none |  | exit non-zero for improperly formatted checksum lines |

## Examples

### Refuse a checksum list with malformed lines instead of skipping them

```bash tab="bash" tab-group="shell"
md5sumx -c --strict -w md5.sums
```

```powershell tab="PowerShell" tab-group="shell"
md5sumx -c --strict -w md5.sums
```

## Help in the terminal

```bash
gnux help md5sumx --strict
```
