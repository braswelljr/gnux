---
title: "-P, --max-procs"
description: "Run at most MAX-PROCS processes at a time."
---

An option of [xargsx](/docs/v1.0/tools/xargsx).

## Usage

```bash
xargsx -P MAX-PROCS [COMMAND [INITIAL-ARGUMENT]...]
xargsx --max-procs=MAX-PROCS [COMMAND [INITIAL-ARGUMENT]...]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-P` | `--max-procs` | `MAX-PROCS` |  | run at most MAX-PROCS processes at a time |

## Examples

### Checksum many files four commands at a time

```bash tab="bash" tab-group="shell"
findx . -type f -print0 | xargsx -0 -n 50 -P 4 sha256sumx
```

```powershell tab="PowerShell" tab-group="shell"
findx . -type f -print0 | xargsx -0 -n 50 -P 4 sha256sumx
```
