---
title: "-n, --max-args"
description: "Use at most MAX-ARGS arguments per command line."
---

An option of [xargsx](/docs/v1.0/tools/xargsx).

## Usage

```bash
xargsx -n MAX-ARGS [COMMAND [INITIAL-ARGUMENT]...]
xargsx --max-args=MAX-ARGS [COMMAND [INITIAL-ARGUMENT]...]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-n` | `--max-args` | `MAX-ARGS` |  | use at most MAX-ARGS arguments per command line |

## Examples

### Pass two items to each command

```bash tab="bash" tab-group="shell"
seqx 6 | xargsx -n 2 echox
```

```powershell tab="PowerShell" tab-group="shell"
seqx 6 | xargsx -n 2 echox
```

### Print each command line before it runs

```bash tab="bash" tab-group="shell"
seqx 4 | xargsx -t -n 2 echox
```

```powershell tab="PowerShell" tab-group="shell"
seqx 4 | xargsx -t -n 2 echox
```

### Ask before each removal (the answer is read from the terminal)

```bash tab="bash" tab-group="shell"
lsx | xargsx -p -n 1 rmx
```

```powershell tab="PowerShell" tab-group="shell"
lsx | xargsx -p -n 1 rmx
```

### Checksum many files four commands at a time

```bash tab="bash" tab-group="shell"
findx . -type f -print0 | xargsx -0 -n 50 -P 4 sha256sumx
```

```powershell tab="PowerShell" tab-group="shell"
findx . -type f -print0 | xargsx -0 -n 50 -P 4 sha256sumx
```

## Help in the terminal

```bash
gnux help xargsx --max-args
```
