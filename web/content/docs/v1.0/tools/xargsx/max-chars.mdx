---
title: "-s, --max-chars"
description: "Limit length of command line to MAX-CHARS."
---

An option of [xargsx](/docs/v1.0/tools/xargsx).

## Usage

```bash
xargsx -s MAX-CHARS [COMMAND [INITIAL-ARGUMENT]...]
xargsx --max-chars=MAX-CHARS [COMMAND [INITIAL-ARGUMENT]...]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-s` | `--max-chars` | `MAX-CHARS` |  | limit length of command line to MAX-CHARS |

## Examples

### Keep every command line within 20 bytes

```bash tab="bash" tab-group="shell"
seqx 10 | xargsx -s 20 echox
```

```powershell tab="PowerShell" tab-group="shell"
seqx 10 | xargsx -s 20 echox
```

## Help in the terminal

```bash
gnux help xargsx --max-chars
```
