---
title: "-e, --eof"
description: "Equivalent to -E END if END is specified; otherwise, there is no end-of-file string."
---

An option of [xargsx](/docs/v1.0/tools/xargsx).

## Usage

```bash
xargsx -e [COMMAND [INITIAL-ARGUMENT]...]
xargsx --eof[=END] [COMMAND [INITIAL-ARGUMENT]...]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-e` | `--eof` | `END` (optional) |  | equivalent to `-E` END if END is specified; otherwise, there is no end-of-file string |

## Help in the terminal

```bash
gnux help xargsx --eof
```
