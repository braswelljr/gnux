---
title: "-p, --interactive"
description: "Prompt before running commands."
---

An option of [xargsx](/docs/v1.0/tools/xargsx).

## Usage

```bash
xargsx -p [COMMAND [INITIAL-ARGUMENT]...]
xargsx --interactive [COMMAND [INITIAL-ARGUMENT]...]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-p` | `--interactive` | none |  | prompt before running commands |

## Examples

### Ask before each removal (the answer is read from the terminal)

```bash tab="bash" tab-group="shell"
lsx | xargsx -p -n 1 rmx
```

```powershell tab="PowerShell" tab-group="shell"
lsx | xargsx -p -n 1 rmx
```

## Help in the terminal

```bash
gnux help xargsx --interactive
```
