---
title: "--show-limits"
description: "Show limits on command-line length."
---

An option of [xargsx](/docs/v1.0/tools/xargsx).

## Usage

```bash
xargsx --show-limits [COMMAND [INITIAL-ARGUMENT]...]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--show-limits` | none |  | show limits on command-line length |

## Examples

### Show the size limits in effect without running anything

```bash tab="bash" tab-group="shell"
xargsx --show-limits -r < /dev/null
```

```powershell tab="PowerShell" tab-group="shell"
'' | xargsx --show-limits -r
```

## Help in the terminal

```bash
gnux help xargsx --show-limits
```
