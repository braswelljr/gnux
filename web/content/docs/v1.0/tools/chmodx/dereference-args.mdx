title: "-H, --dereference-args"
description: "With -R, follow symbolic links given on the command line (the default)."

An option of [chmodx](/docs/v1.0/tools/chmodx).

## Usage

```bash
chmodx -H MODE[,MODE]... FILE...
chmodx --dereference-args MODE[,MODE]... FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-H` | `--dereference-args` | none |  | with `-R`, follow symbolic links given on the command line (the default) |

## Help in the terminal

```bash
gnux help chmodx --dereference-args
```
