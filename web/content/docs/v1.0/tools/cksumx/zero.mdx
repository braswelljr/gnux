title: "-z, --zero"

An option of [cksumx](/docs/v1.0/tools/cksumx).

## Usage

```bash
cksumx -z [FILE]...
cksumx --zero [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-z` | `--zero` | none |  | end each output line with NUL, not newline, and disable file name escaping |

## Help in the terminal

```bash
gnux help cksumx --zero
```
