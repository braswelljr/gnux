---
title: "--ignore-missing"
description: "Don't fail or report status for missing files."
---

An option of [cksumx](/docs/v1.0/tools/cksumx).

## Usage

```bash
cksumx --ignore-missing [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--ignore-missing` | none |  | don't fail or report status for missing files |

## Help in the terminal

```bash
gnux help cksumx --ignore-missing
```
