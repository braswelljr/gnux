---
title: "-z, --zero-terminated"
description: "Line delimiter is NUL, not newline."
---

An option of [pastex](/docs/v1.0/tools/pastex).

## Usage

```bash
pastex -z [FILE]...
pastex --zero-terminated [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-z` | `--zero-terminated` | none |  | line delimiter is NUL, not newline |

## Examples

### Paste NUL-terminated records

```bash tab="bash" tab-group="shell"
pastex -z keys.bin values.bin
```

```powershell tab="PowerShell" tab-group="shell"
pastex -z keys.bin values.bin
```

## Help in the terminal

```bash
gnux help pastex --zero-terminated
```
