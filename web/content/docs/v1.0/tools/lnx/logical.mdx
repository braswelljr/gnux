---
title: "-L, --logical"
description: "Dereference TARGETs that are symbolic links."
---

An option of [lnx](/docs/v1.0/tools/lnx).

## Usage

```bash
lnx -L TARGET... [LINK_NAME|DIRECTORY]
lnx --logical TARGET... [LINK_NAME|DIRECTORY]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-L` | `--logical` | none |  | dereference TARGETs that are symbolic links |

## Examples

### Hard-link the file a symlink points to, instead of the symlink itself

```bash tab="bash" tab-group="shell"
lnx -L current.log saved.log
```

```powershell tab="PowerShell" tab-group="shell"
lnx -L current.log saved.log
```
