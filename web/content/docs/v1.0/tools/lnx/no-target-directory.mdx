---
title: "-T, --no-target-directory"
description: "Treat LINK_NAME as a normal file always."
---

An option of [lnx](/docs/v1.0/tools/lnx).

## Usage

```bash
lnx -T TARGET... [LINK_NAME|DIRECTORY]
lnx --no-target-directory TARGET... [LINK_NAME|DIRECTORY]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-T` | `--no-target-directory` | none |  | treat LINK_NAME as a normal file always |

## Examples

### Treat the link name as a plain file, never as a directory to link into

```bash tab="bash" tab-group="shell"
lnx -sT releases/v3 current-release
```

```powershell tab="PowerShell" tab-group="shell"
lnx -sT releases\v3 current-release
```
