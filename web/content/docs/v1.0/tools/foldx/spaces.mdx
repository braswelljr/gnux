---
title: "-s, --spaces"
description: "Break at spaces."
---

An option of [foldx](/docs/v1.0/tools/foldx).

## Usage

```bash
foldx -s [FILE]...
foldx --spaces [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-s` | `--spaces` | none |  | break at spaces |

## Examples

### Wrap a commit message body at 72 columns without breaking words

```bash tab="bash" tab-group="shell"
foldx -s -w 72 essay.txt
```

```powershell tab="PowerShell" tab-group="shell"
foldx -s -w 72 essay.txt
```

### Save a wrapped copy of a draft for an email client that does not wrap

```bash tab="bash" tab-group="shell"
foldx -s -w 72 draft.txt > wrapped.txt
```

```powershell tab="PowerShell" tab-group="shell"
foldx -s -w 72 draft.txt > wrapped.txt
```
