---
title: "-s, --separator"
description: "Use STRING as the separator instead of newline."
---

An option of [tacx](/docs/v1.0/tools/tacx).

## Usage

```bash
tacx -s STRING [FILE]...
tacx --separator=STRING [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-s` | `--separator` | `STRING` |  | use STRING as the separator instead of newline |

## Examples

### Reverse items in a comma-separated list

```bash tab="bash" tab-group="shell"
printfx 'a,b,c,' | tacx -s ,
```

```powershell tab="PowerShell" tab-group="shell"
printfx 'a,b,c,' | tacx -s ,
```

### Reverse sections of a file that each start with a '---' line

```bash tab="bash" tab-group="shell"
tacx -b -s '---' notes.txt
```

```powershell tab="PowerShell" tab-group="shell"
tacx -b -s '---' notes.txt
```

### Reverse records separated by numbers of any length

```bash tab="bash" tab-group="shell"
tacx -r -s '[0-9]+' data.txt
```

```powershell tab="PowerShell" tab-group="shell"
tacx -r -s '[0-9]+' data.txt
```
