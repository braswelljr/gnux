---
title: "-L, --logical"
description: "Resolve '..' components before symlinks."
---

An option of [realpathx](/docs/v1.0/tools/realpathx).

## Usage

```bash
realpathx -L FILE...
realpathx --logical FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-L` | `--logical` | none |  | resolve '..' components before symlinks |

## Examples

### Read '..' after a link logically (-L) rather than physically (-P, the default)

```bash tab="bash" tab-group="shell"
realpathx -L src/tools/.. && realpathx -P src/tools/..
```

```powershell tab="PowerShell" tab-group="shell"
realpathx -L src\tools\..; realpathx -P src\tools\..
```

## Help in the terminal

gnux help realpathx --logical
