---
title: "-e, --canonicalize-existing"
description: "All components of the path must exist."
---

An option of [realpathx](/docs/v1.0/tools/realpathx).

## Usage

```bash
realpathx -e FILE...
realpathx --canonicalize-existing FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-e` | `--canonicalize-existing` | none |  | all components of the path must exist |

## Examples

### Require the file to exist

```bash tab="bash" tab-group="shell"
realpathx -e /usr/bin/python3
```

```powershell tab="PowerShell" tab-group="shell"
realpathx -e $env:WINDIR\System32\cmd.exe
```

### Test for existence quietly and branch on the exit status

```bash tab="bash" tab-group="shell"
realpathx -q -e config.yaml >/dev/null || echox 'config.yaml is missing'
```

```powershell tab="PowerShell" tab-group="shell"
realpathx -q -e config.yaml > $null; if ($LASTEXITCODE -ne 0) { echox 'config.yaml is missing' }
```
