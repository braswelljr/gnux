---
title: "-r, --real"
description: "Print the real ID instead of the effective ID, with -u,-g,-G."
---

An option of [idx](/docs/v1.0/tools/idx).

## Usage

```bash
idx -r [USER]...
idx --real [USER]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-r` | `--real` | none |  | print the real ID instead of the effective ID, with `-u`,`-g`,`-G` |

## Examples

### Print the real user ID rather than the effective one

```bash tab="bash" tab-group="shell"
idx -ru
```

```powershell tab="PowerShell" tab-group="shell"
idx -ru
```

## Help in the terminal

```bash
gnux help idx --real
```
