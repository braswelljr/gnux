---
title: "--files0-from"
description: "Read input from the files specified by NUL-terminated names in file F; if F is - then read names from standard input."
---

An option of [wcx](/docs/v1.0/tools/wcx).

## Usage

```bash
wcx --files0-from=F [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--files0-from` | `F` |  | read input from the files specified by NUL-terminated names in file F; if F is - then read names from standard input |

## Examples

### Read the list of files to count from a NUL-separated file

```bash tab="bash" tab-group="shell"
wcx -l --files0-from=sources.lst
```

```powershell tab="PowerShell" tab-group="shell"
wcx -l --files0-from=sources.lst
```

### Print only the grand total for a list of files found elsewhere

```bash tab="bash" tab-group="shell"
find . -name '*.go' -print0 | wcx -l --files0-from=- --total=only
```

```powershell tab="PowerShell" tab-group="shell"
wcx -l --total=only (Get-ChildItem -Recurse *.go).FullName
```
