---
title: "-c, --bytes"
description: "Print the byte counts."
---

An option of [wcx](/docs/v1.0/tools/wcx).

## Usage

```bash
wcx -c [FILE]...
wcx --bytes [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-c` | `--bytes` | none |  | print the byte counts |

## Examples

### Print the size of a file in bytes

```bash tab="bash" tab-group="shell"
wcx -c image.png
```

```powershell tab="PowerShell" tab-group="shell"
wcx -c image.png
```
