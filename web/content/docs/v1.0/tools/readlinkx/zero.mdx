---
title: "-z, --zero"
description: "End each output line with NUL, not newline."
---

An option of [readlinkx](/docs/v1.0/tools/readlinkx).

## Usage

```bash
readlinkx -z FILE...
readlinkx --zero FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-z` | `--zero` | none |  | end each output line with NUL, not newline |

## Examples

### Resolve several links at once, NUL-separated

```bash tab="bash" tab-group="shell"
readlinkx -z -f a b c | trx '\0' '\n'
```

```powershell tab="PowerShell" tab-group="shell"
readlinkx -z -f a b c | trx '\0' '\n'
```

## Help in the terminal

```bash
gnux help readlinkx --zero
```
