---
title: "-v, --verbose"
description: "Report error messages."
---

An option of [readlinkx](/docs/v1.0/tools/readlinkx).

## Usage

```bash
readlinkx -v FILE...
readlinkx --verbose FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-v` | `--verbose` | none |  | report error messages |

## Examples

### Explain why a name cannot be resolved

```bash tab="bash" tab-group="shell"
readlinkx -v -e missing/file
```

```powershell tab="PowerShell" tab-group="shell"
readlinkx -v -e missing/file
```

## Help in the terminal

```bash
gnux help readlinkx --verbose
```
