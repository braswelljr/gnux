---
title: "-s, --silent"
description: "Suppress most error messages (on by default)."
---

An option of [readlinkx](/docs/v1.0/tools/readlinkx).

## Usage

```bash
readlinkx -s FILE...
readlinkx --silent FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-s` | `--silent` | none |  | suppress most error messages (on by default) |

## Help in the terminal

```bash
gnux help readlinkx --silent
```
