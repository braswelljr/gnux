---
title: "-n, --no-newline"

An option of [readlinkx](/docs/v1.0/tools/readlinkx).

## Usage

```bash
readlinkx -n FILE...
readlinkx --no-newline FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-n` | `--no-newline` | none |  | do not output the trailing delimiter |

## Help in the terminal

```bash
gnux help readlinkx --no-newline
```
