---
title: "--ignore-fail-on-non-empty"
description: "Ignore each failure that is solely because a directory is non-empty."
---

An option of [rmdirx](/docs/v1.0/tools/rmdirx).

## Usage

```bash
rmdirx --ignore-fail-on-non-empty DIRECTORY...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--ignore-fail-on-non-empty` | none |  | ignore each failure that is solely because a directory is non-empty |

## Examples

### Clean up whatever is empty without failing on the rest

```bash tab="bash" tab-group="shell"
rmdirx --ignore-fail-on-non-empty cache logs tmp
```

```powershell tab="PowerShell" tab-group="shell"
rmdirx --ignore-fail-on-non-empty cache logs tmp
```

### Prune parents as far as they are empty, stopping quietly at the first that is not

```bash tab="bash" tab-group="shell"
rmdirx -p --ignore-fail-on-non-empty keep/sub
```

```powershell tab="PowerShell" tab-group="shell"
rmdirx -p --ignore-fail-on-non-empty keep\sub
```
