---
title: "-H, --dereference-args"
description: "With -R, follow symbolic links to directories given on the command line."
---

An option of [chgrpx](/docs/v1.0/tools/chgrpx).

## Usage

```bash
chgrpx -H GROUP FILE...
chgrpx --dereference-args GROUP FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-H` | `--dereference-args` | none |  | with `-R`, follow symbolic links to directories given on the command line |

## Help in the terminal

```bash
gnux help chgrpx --dereference-args
```
