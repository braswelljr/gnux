---
title: "--preserve-root"
description: "Fail to operate recursively on '/' (the default)."
---

An option of [chgrpx](/docs/v1.0/tools/chgrpx).

## Usage

```bash
chgrpx --preserve-root GROUP FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--preserve-root` | none |  | fail to operate recursively on '/' (the default) |

## Help in the terminal

```bash
gnux help chgrpx --preserve-root
```
