---
title: "--reference"
description: "Use RFILE's group rather than specifying a GROUP value."
---

An option of [chgrpx](/docs/v1.0/tools/chgrpx).

## Usage

```bash
chgrpx --reference=RFILE GROUP FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--reference` | `RFILE` |  | use RFILE's group rather than specifying a GROUP value |

## Examples

### Copy the group of another file

```bash tab="bash" tab-group="shell"
chgrpx --reference=template.conf new.conf
```

```powershell tab="PowerShell" tab-group="shell"
chgrpx --reference=template.conf new.conf
```

## Help in the terminal

```bash
gnux help chgrpx --reference
```
