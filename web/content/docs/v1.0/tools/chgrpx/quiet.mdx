---
title: "--quiet"
description: "Same as --silent."
---

An option of [chgrpx](/docs/v1.0/tools/chgrpx).

## Usage

```bash
chgrpx --quiet GROUP FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--quiet` | none |  | same as `--silent` |

## Help in the terminal

```bash
gnux help chgrpx --quiet
```
