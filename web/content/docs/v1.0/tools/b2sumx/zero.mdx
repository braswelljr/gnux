title: "-z, --zero"

An option of [b2sumx](/docs/v1.0/tools/b2sumx).

## Usage

```bash
b2sumx -z [FILE]...
b2sumx --zero [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-z` | `--zero` | none |  | end each output line with NUL, not newline, and disable file name escaping |

## Help in the terminal

```bash
gnux help b2sumx --zero
```
