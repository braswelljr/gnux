---
title: "-c, --check"
description: "Read checksums from the FILEs and check them."
---

An option of [sha224sumx](/docs/v1.0/tools/sha224sumx).

## Usage

```bash
sha224sumx -c [FILE]...
sha224sumx --check [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-c` | `--check` | none |  | read checksums from the FILEs and check them |

## Examples

### Verify the download against the publisher's checksum file, which lists other files too

```bash tab="bash" tab-group="shell"
sha224sumx -c --ignore-missing sha224.sums
```

```powershell tab="PowerShell" tab-group="shell"
sha224sumx -c --ignore-missing sha224.sums
```

```text title="Output"
ubuntu-24.04-desktop-amd64.iso: OK
```

### In CI, fail the build when a vendored file was changed by hand

```bash tab="bash" tab-group="shell"
sha224sumx -c --status vendor.sha224sums || { echox 'vendored files changed' >&2; exit 1; }
```

```powershell tab="PowerShell" tab-group="shell"
sha224sumx -c --status vendor.sha224sums; if ($LASTEXITCODE -ne 0) { Write-Error 'vendored files changed'; exit 1 }
```

### Re-check a large archive set and show only what no longer matches

```bash tab="bash" tab-group="shell"
sha224sumx -c --quiet sha224.sums
```

```powershell tab="PowerShell" tab-group="shell"
sha224sumx -c --quiet sha224.sums
```

```text title="Output"
notes.txt: FAILED
sha224sumx: WARNING: 1 computed checksum did NOT match
```

### Refuse a checksum list with malformed lines instead of skipping them

```bash tab="bash" tab-group="shell"
sha224sumx -c --strict -w sha224.sums
```

```powershell tab="PowerShell" tab-group="shell"
sha224sumx -c --strict -w sha224.sums
```
