---
title: "-m, --machine"
description: "Print the machine hardware name."
---

An option of [unamex](/docs/v1.0/tools/unamex).

## Usage

```bash
unamex -m
unamex --machine
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-m` | `--machine` | none |  | print the machine hardware name |

## Examples

### Print the machine architecture

```bash tab="bash" tab-group="shell"
unamex -m
```

```powershell tab="PowerShell" tab-group="shell"
unamex -m
```

## Help in the terminal

```bash
gnux help unamex --machine
```
