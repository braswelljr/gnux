An option of [unamex](/docs/v1.0/tools/unamex).

## Usage

```bash
unamex -v
unamex --kernel-version
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-v` | `--kernel-version` | none |  | print the kernel version |

## Help in the terminal

```bash
gnux help unamex --kernel-version
```
