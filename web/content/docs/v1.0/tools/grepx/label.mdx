An option of [grepx](/docs/v1.0/tools/grepx).

## Usage

```bash
grepx --label=LABEL PATTERNS [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--label` | `LABEL` |  | use LABEL as the file name of standard input |

## Help in the terminal

```bash
gnux help grepx --label
```
