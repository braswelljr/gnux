An option of [grepx](/docs/v1.0/tools/grepx).

## Usage

```bash
grepx -z PATTERNS [FILE]...
grepx --null-data PATTERNS [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-z` | `--null-data` | none |  | a data line ends in a NUL byte, not a newline |

```bash
gnux help grepx --null-data
```
