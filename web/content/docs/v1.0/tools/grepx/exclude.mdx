---
title: "--exclude"
description: "Skip files that match GLOB."
---

An option of [grepx](/docs/v1.0/tools/grepx).

## Usage

```bash
grepx --exclude=GLOB PATTERNS [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--exclude` | `GLOB` |  | skip files that match GLOB |

## Help in the terminal

```bash
gnux help grepx --exclude
```
