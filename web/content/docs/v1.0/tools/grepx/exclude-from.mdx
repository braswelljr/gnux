---
title: "--exclude-from"
description: "Skip files that match any file pattern from FILE."
---

An option of [grepx](/docs/v1.0/tools/grepx).

## Usage

```bash
grepx --exclude-from=FILE PATTERNS [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--exclude-from` | `FILE` |  | skip files that match any file pattern from FILE |

## Help in the terminal

```bash
gnux help grepx --exclude-from
```
