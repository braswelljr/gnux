An option of [grepx](/docs/v1.0/tools/grepx).

## Usage

```bash
grepx -d ACTION PATTERNS [FILE]...
grepx --directories=ACTION PATTERNS [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-d` | `--directories` | `ACTION` |  | how to handle directories; ACTION is read (the default), recurse or skip |

## Help in the terminal

```bash
gnux help grepx --directories
```
