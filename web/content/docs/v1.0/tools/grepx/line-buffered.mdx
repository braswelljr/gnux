---
title: "--line-buffered"
description: "Flush the output on every line."
---

An option of [grepx](/docs/v1.0/tools/grepx).

## Usage

```bash
grepx --line-buffered PATTERNS [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--line-buffered` | none |  | flush the output on every line |

## Help in the terminal

```bash
gnux help grepx --line-buffered
```
