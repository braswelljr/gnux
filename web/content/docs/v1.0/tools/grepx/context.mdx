---
title: "-C, --context"
description: "Print NUM lines of output context; -NUM is the same."
---

An option of [grepx](/docs/v1.0/tools/grepx).

## Usage

```bash
grepx -C NUM PATTERNS [FILE]...
grepx --context=NUM PATTERNS [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-C` | `--context` | `NUM` |  | print NUM lines of output context; `-NUM` is the same |

## Examples

### Ignore case and show two lines of context around each match

```bash tab="bash" tab-group="shell"
grepx -i -C 2 'timeout' server.log
```

```powershell tab="PowerShell" tab-group="shell"
grepx -i -C 2 'timeout' server.log
```
