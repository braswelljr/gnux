---
title: "-i, --ignore-case"
description: "Ignore case distinctions in patterns and data."
---

An option of [grepx](/docs/v1.0/tools/grepx).

## Usage

```bash
grepx -i PATTERNS [FILE]...
grepx --ignore-case PATTERNS [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-i` | `--ignore-case` | none |  | ignore case distinctions in patterns and data |

## Examples

### Ignore case and show two lines of context around each match

```bash tab="bash" tab-group="shell"
grepx -i -C 2 'timeout' server.log
```

```powershell tab="PowerShell" tab-group="shell"
grepx -i -C 2 'timeout' server.log
```

### Filter another tool's output in a pipeline

```bash tab="bash" tab-group="shell"
lsx -l | grepx -i '\.log$'
```

```powershell tab="PowerShell" tab-group="shell"
lsx -l | grepx -i '\.log$'
```
