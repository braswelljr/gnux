---
title: "-l, --files-with-matches"
description: "Print only the names of FILEs with selected lines."
---

An option of [grepx](/docs/v1.0/tools/grepx).

## Usage

```bash
grepx -l PATTERNS [FILE]...
grepx --files-with-matches PATTERNS [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-l` | `--files-with-matches` | none |  | print only the names of FILEs with selected lines |

## Examples

### List the files under the current directory that contain a string

```bash tab="bash" tab-group="shell"
grepx -rl 'deprecated' .
```

```powershell tab="PowerShell" tab-group="shell"
grepx -rl 'deprecated' .
```

## Help in the terminal

```bash
gnux help grepx --files-with-matches
```
