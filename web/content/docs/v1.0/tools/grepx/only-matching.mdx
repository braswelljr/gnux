---
title: "-o, --only-matching"
description: "Print only the matched (non-empty) parts of lines, one to a line."
---

An option of [grepx](/docs/v1.0/tools/grepx).

## Usage

```bash
grepx -o PATTERNS [FILE]...
grepx --only-matching PATTERNS [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-o` | `--only-matching` | none |  | print only the matched (non-empty) parts of lines, one to a line |

## Examples

### Print only the matched parts, here every IPv4-looking address

```bash tab="bash" tab-group="shell"
grepx -oE '[0-9]+\.[0-9]+\.[0-9]+\.[0-9]+' access.log
```

```powershell tab="PowerShell" tab-group="shell"
grepx -oE '[0-9]+\.[0-9]+\.[0-9]+\.[0-9]+' access.log
```
