---
title: "-h, --no-filename"
description: "Suppress the file name prefix on output."
---

An option of [grepx](/docs/v1.0/tools/grepx).

## Usage

```bash
grepx -h PATTERNS [FILE]...
grepx --no-filename PATTERNS [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-h` | `--no-filename` | none |  | suppress the file name prefix on output |

## Help in the terminal

```bash
gnux help grepx --no-filename
```
