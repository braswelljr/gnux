---
title: "--no-group-separator"
description: "Do not print a separator between groups of matches with context."
---

An option of [grepx](/docs/v1.0/tools/grepx).

## Usage

```bash
grepx --no-group-separator PATTERNS [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--no-group-separator` | none |  | do not print a separator between groups of matches with context |

## Help in the terminal

```bash
gnux help grepx --no-group-separator
```
