title: "--binary-files"

An option of [grepx](/docs/v1.0/tools/grepx).

## Usage

```bash
grepx --binary-files=TYPE PATTERNS [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--binary-files` | `TYPE` |  | assume that binary files are TYPE: binary (the default), text or without-match; `-I` is `--binary-files`=without-match |

## Help in the terminal

```bash
gnux help grepx --binary-files
```
