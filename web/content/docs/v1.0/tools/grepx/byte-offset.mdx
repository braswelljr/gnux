---
title: "-b, --byte-offset"
description: "Print the byte offset with output lines."
---

An option of [grepx](/docs/v1.0/tools/grepx).

## Usage

```bash
grepx -b PATTERNS [FILE]...
grepx --byte-offset PATTERNS [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-b` | `--byte-offset` | none |  | print the byte offset with output lines |

## Help in the terminal

```bash
gnux help grepx --byte-offset
```
