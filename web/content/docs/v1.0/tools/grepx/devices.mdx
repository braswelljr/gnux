An option of [grepx](/docs/v1.0/tools/grepx).

## Usage

```bash
grepx -D ACTION PATTERNS [FILE]...
grepx --devices=ACTION PATTERNS [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-D` | `--devices` | `ACTION` |  | how to handle devices, FIFOs and sockets; ACTION is read or skip |

## Help in the terminal

```bash
gnux help grepx --devices
```
