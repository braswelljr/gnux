---
title: "-R, --rfc-email"
description: "Output date and time in RFC 5322 format."
---

An option of [datex](/docs/v1.0/tools/datex).

## Usage

```bash
datex -R [+FORMAT]
datex --rfc-email [+FORMAT]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-R` | `--rfc-email` | none |  | output `date` and time in RFC 5322 format |

## Help in the terminal

```bash
gnux help datex --rfc-email
```
