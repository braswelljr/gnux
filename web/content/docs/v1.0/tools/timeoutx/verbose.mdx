---
title: "-v, --verbose"
description: "Diagnose to stderr any signal sent upon timeout."
---

An option of [timeoutx](/docs/v1.0/tools/timeoutx).

## Usage

```bash
timeoutx -v [OPTION] DURATION COMMAND [ARG]...
timeoutx --verbose [OPTION] DURATION COMMAND [ARG]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-v` | `--verbose` | none |  | diagnose to stderr any signal sent upon `timeout` |

## Examples

### Report the signals as they are sent

```bash tab="bash" tab-group="shell"
timeoutx -v 2s sleepx 60
```

```powershell tab="PowerShell" tab-group="shell"
timeoutx -v 2s sleepx 60
```

## Help in the terminal

```bash
gnux help timeoutx --verbose
```
