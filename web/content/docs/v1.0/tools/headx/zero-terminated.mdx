---
title: "-z, --zero-terminated"
description: "Line delimiter is NUL, not newline."
---

An option of [headx](/docs/v1.0/tools/headx).

## Usage

```bash
headx -z [FILE]...
headx --zero-terminated [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-z` | `--zero-terminated` | none |  | line delimiter is NUL, not newline |

## Examples

### Take the first two entries of a NUL-separated list

```bash tab="bash" tab-group="shell"
find . -name '*.txt' -print0 | headx -z -n 2 | xargs -0 wcx -l
```

```powershell tab="PowerShell" tab-group="shell"
headx -z -n 2 names.lst
```

## Help in the terminal

```bash
gnux help headx --zero-terminated
```
