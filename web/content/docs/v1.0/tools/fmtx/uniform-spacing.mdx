An option of [fmtx](/docs/v1.0/tools/fmtx).

## Usage

```bash
fmtx [-WIDTH] -u [FILE]...
fmtx [-WIDTH] --uniform-spacing [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-u` | `--uniform-spacing` | none |  | one space between words, two after sentences |

## Examples

### Normalize spacing in a document pasted from several sources

```bash tab="bash" tab-group="shell"
fmtx -u draft.txt
```

```powershell tab="PowerShell" tab-group="shell"
fmtx -u draft.txt
```

## Help in the terminal

```bash
gnux help fmtx --uniform-spacing
```
