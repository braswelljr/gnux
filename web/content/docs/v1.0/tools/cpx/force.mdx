---
title: "-f, --force"
description: "If an existing destination file cannot be opened, remove it and try again."
---

An option of [cpx](/docs/v1.0/tools/cpx).

## Usage

```bash
cpx -f SOURCE... DIRECTORY
cpx --force SOURCE... DIRECTORY
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-f` | `--force` | none |  | if an existing destination file cannot be opened, remove it and try again |

## Examples

### Replace a read-only destination file

```bash tab="bash" tab-group="shell"
cpx -f new.conf readonly.conf
```

```powershell tab="PowerShell" tab-group="shell"
cpx -f new.conf readonly.conf
```

gnux help cpx --force
