---
title: "-P, --no-dereference"
description: "Never follow symbolic links in SOURCE."
---

An option of [cpx](/docs/v1.0/tools/cpx).

## Usage

```bash
cpx -P SOURCE... DIRECTORY
cpx --no-dereference SOURCE... DIRECTORY
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-P` | `--no-dereference` | none |  | never follow symbolic links in SOURCE |

## Examples

### Copy a symbolic link as a link, rather than the file it points to

```bash tab="bash" tab-group="shell"
cpx -P current.yml saved-link.yml
```

```powershell tab="PowerShell" tab-group="shell"
cpx -P current.yml saved-link.yml
```
