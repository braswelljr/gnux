---
title: "--preserve"
description: "Preserve the listed attributes: mode, ownership, timestamps, links, all."
---

An option of [cpx](/docs/v1.0/tools/cpx).

## Usage

```bash
cpx --preserve[=string] SOURCE... DIRECTORY
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--preserve` | `string` (optional) |  | preserve the listed attributes: mode, ownership, timestamps, links, all |

## Examples

### Preserve only the timestamps, or archive without carrying over ownership

```bash tab="bash" tab-group="shell"
cpx --preserve=timestamps photo.jpg archive/ && cpx -a --no-preserve=ownership project/ copy/
```

```powershell tab="PowerShell" tab-group="shell"
cpx --preserve=timestamps photo.jpg archive; cpx -a --no-preserve=ownership project copy
```
