---
title: "-a, --argv0"
description: "Pass ARG as the zeroth argument of COMMAND."
---

An option of [envx](/docs/v1.0/tools/envx).

## Usage

```bash
envx -a ARG [-] [NAME=VALUE]... [COMMAND [ARG]...]
envx --argv0=ARG [-] [NAME=VALUE]... [COMMAND [ARG]...]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-a` | `--argv0` | `ARG` |  | pass ARG as the zeroth argument of COMMAND |

## Examples

### Run the gnux binary as rmx by setting its zeroth argument

```bash tab="bash" tab-group="shell"
envx -a rmx gnux -v old.log
```

```powershell tab="PowerShell" tab-group="shell"
envx -a rmx gnux -v old.log
```

## Help in the terminal

```bash
gnux help envx --argv0
```
