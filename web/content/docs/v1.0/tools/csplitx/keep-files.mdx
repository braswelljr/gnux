---
title: "-k, --keep-files"
description: "Do not remove output files on errors."
---

An option of [csplitx](/docs/v1.0/tools/csplitx).

## Usage

```bash
csplitx -k FILE PATTERN...
csplitx --keep-files FILE PATTERN...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-k` | `--keep-files` | none |  | do not remove output files on errors |

## Examples

### Keep the pieces even if a later pattern fails

```bash tab="bash" tab-group="shell"
csplitx -k data.txt 100 200 5000
```

```powershell tab="PowerShell" tab-group="shell"
csplitx -k data.txt 100 200 5000
```

```text title="Output"
2890
2900
csplitx: '5000': line number out of range
```
