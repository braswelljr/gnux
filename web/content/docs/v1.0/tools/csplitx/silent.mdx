---
title: "-q, --silent"
description: "Same as --quiet."
---

An option of [csplitx](/docs/v1.0/tools/csplitx).

## Usage

```bash
csplitx -q FILE PATTERN...
csplitx --silent FILE PATTERN...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-q` | `--silent` | none |  | same as `--quiet` |

## Help in the terminal

```bash
gnux help csplitx --silent
```
