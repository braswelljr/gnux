---
title: "--preserve-root"
description: "Fail to operate recursively on '/' (the default)."
---

An option of [chownx](/docs/v1.0/tools/chownx).

## Usage

```bash
chownx --preserve-root [OWNER][:[GROUP]] FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--preserve-root` | none |  | fail to operate recursively on '/' (the default) |

## Help in the terminal

```bash
gnux help chownx --preserve-root
```
