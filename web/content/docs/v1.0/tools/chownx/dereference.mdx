---
title: "--dereference"
description: "Affect the referent of each symbolic link (this is the default), rather than the symbolic link itself."
---

An option of [chownx](/docs/v1.0/tools/chownx).

## Usage

```bash
chownx --dereference [OWNER][:[GROUP]] FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--dereference` | none |  | affect the referent of each symbolic `link` (this is the default), rather than the symbolic `link` itself |

## Help in the terminal

```bash
gnux help chownx --dereference
```
