---
title: "--reference"
description: "Use RFILE's ownership rather than specifying values."
---

An option of [chownx](/docs/v1.0/tools/chownx).

## Usage

```bash
chownx --reference=RFILE [OWNER][:[GROUP]] FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--reference` | `RFILE` |  | use RFILE's ownership rather than specifying values |

## Help in the terminal

```bash
gnux help chownx --reference
```
