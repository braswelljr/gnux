---
title: "-f, --file-system"
description: "Display file system status instead of file status."
---

An option of [statx](/docs/v1.0/tools/statx).

## Usage

```bash
statx -f FILE...
statx --file-system FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-f` | `--file-system` | none |  | display file system status instead of file status |

## Examples

### Check the file system type and free space under a directory

```bash tab="bash" tab-group="shell"
statx -f /var/lib/docker
```

```powershell tab="PowerShell" tab-group="shell"
statx -f C:\
```

## Help in the terminal

```bash
gnux help statx --file-system
```
