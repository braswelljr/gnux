---
title: "--quiet"
description: "Same as --silent."
---

An option of [ttyx](/docs/v1.0/tools/ttyx).

## Usage

```bash
ttyx --quiet
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--quiet` | none |  | same as `--silent` |

## Help in the terminal

```bash
gnux help ttyx --quiet
```
