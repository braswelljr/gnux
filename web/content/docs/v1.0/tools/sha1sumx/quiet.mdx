---
title: "--quiet"
description: "Don't print OK for each successfully verified file."
---

An option of [sha1sumx](/docs/v1.0/tools/sha1sumx).

## Usage

```bash
sha1sumx --quiet [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--quiet` | none |  | don't print OK for each successfully verified file |

## Examples

### Re-check a large archive set and show only what no longer matches

```bash tab="bash" tab-group="shell"
sha1sumx -c --quiet sha1.sums
```

```powershell tab="PowerShell" tab-group="shell"
sha1sumx -c --quiet sha1.sums
```

```text title="Output"
notes.txt: FAILED
sha1sumx: WARNING: 1 computed checksum did NOT match
```

## Help in the terminal

```bash
gnux help sha1sumx --quiet
```
