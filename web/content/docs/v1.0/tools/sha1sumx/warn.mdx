---
title: "-w, --warn"
description: "Warn about improperly formatted checksum lines."
---

An option of [sha1sumx](/docs/v1.0/tools/sha1sumx).

## Usage

```bash
sha1sumx -w [FILE]...
sha1sumx --warn [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-w` | `--warn` | none |  | warn about improperly formatted checksum lines |

## Examples

### Refuse a checksum list with malformed lines instead of skipping them

```bash tab="bash" tab-group="shell"
sha1sumx -c --strict -w sha1.sums
```

```powershell tab="PowerShell" tab-group="shell"
sha1sumx -c --strict -w sha1.sums
```

## Help in the terminal

```bash
gnux help sha1sumx --warn
```
