---
title: "-a, --access-time"
description: "Change only the access time."
---

An option of [touchx](/docs/v1.1/tools/touchx).

## Usage

```bash
touchx -a FILE...
touchx --access-time FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-a` | `--access-time` | none |  | change only the access time |

## Examples

### Set only the access time to now

```bash tab="bash" tab-group="shell"
touchx -a app.log
```

```powershell tab="PowerShell" tab-group="shell"
touchx -a app.log
```

### Backdate only the access time with a stamp

```bash tab="bash" tab-group="shell"
touchx -a -t 202001010000 app.log
```

```powershell tab="PowerShell" tab-group="shell"
touchx -a -t 202001010000 app.log
```
