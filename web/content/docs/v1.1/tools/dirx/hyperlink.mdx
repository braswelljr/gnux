An option of [dirx](/docs/v1.1/tools/dirx).

## Usage

```bash
dirx --hyperlink[=WHEN] [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--hyperlink` | `WHEN` (optional) |  | hyperlink file names WHEN: 'always' (the default when WHEN is omitted), 'auto', or 'never' |

## Help in the terminal

```bash
gnux help dirx --hyperlink
```
