An option of [dirx](/docs/v1.1/tools/dirx).

## Usage

```bash
dirx -i [FILE]...
dirx --inode [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-i` | `--inode` | none |  | print the index number of each file |

## Help in the terminal

```bash
gnux help dirx --inode
```
