An option of [dirx](/docs/v1.1/tools/dirx).

## Usage

```bash
dirx --hide=PATTERN [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--hide` | `PATTERN` |  | do not list implied entries matching shell PATTERN (overridden by `-a` or `-A`) |

## Help in the terminal

```bash
gnux help dirx --hide
```
