An option of [dirx](/docs/v1.1/tools/dirx).

## Usage

```bash
dirx -B [FILE]...
dirx --ignore-backups [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-B` | `--ignore-backups` | none |  | do not list implied entries ending with ~ |
