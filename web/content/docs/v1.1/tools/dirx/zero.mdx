---
title: "--zero"
description: "End each output line with NUL, not newline."
---

An option of [dirx](/docs/v1.1/tools/dirx).

## Usage

```bash
dirx --zero [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--zero` | none |  | end each output line with NUL, not newline |

## Help in the terminal

```bash
gnux help dirx --zero
```
