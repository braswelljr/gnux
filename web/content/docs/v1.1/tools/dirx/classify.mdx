title: "-F, --classify"

An option of [dirx](/docs/v1.1/tools/dirx).

## Usage

```bash
dirx -F [FILE]...
dirx --classify [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-F` | `--classify` | none |  | append indicator (one of */=@\|) to entries |

## Examples

### Mark directories and executables

```bash tab="bash" tab-group="shell"
dirx -F
```

```powershell tab="PowerShell" tab-group="shell"
dirx -F
```

## Help in the terminal

gnux help dirx --classify
