---
title: "--block-size"
description: "With -l, scale sizes by SIZE when printing them; e.g., '--block-size=M'."
---

An option of [dirx](/docs/v1.1/tools/dirx).

## Usage

```bash
dirx --block-size=SIZE [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--block-size` | `SIZE` |  | with `-l`, scale sizes by SIZE when printing them; e.g., '`--block-size`=M' |

## Help in the terminal

```bash
gnux help dirx --block-size
```
