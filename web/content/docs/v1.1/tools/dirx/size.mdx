---
title: "-s, --size"
description: "Print the allocated size of each file, in blocks."
---

An option of [dirx](/docs/v1.1/tools/dirx).

## Usage

```bash
dirx -s [FILE]...
dirx --size [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-s` | `--size` | none |  | print the allocated size of each file, in blocks |

## Examples

### Show sizes in blocks next to each name

```bash tab="bash" tab-group="shell"
dirx -sh
```

```powershell tab="PowerShell" tab-group="shell"
dirx -sh
```

## Help in the terminal

```bash
gnux help dirx --size
```
