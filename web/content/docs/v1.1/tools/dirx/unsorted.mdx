---
title: "-U, --unsorted"
description: "Do not sort; list entries in directory order."
---

An option of [dirx](/docs/v1.1/tools/dirx).

## Usage

```bash
dirx -U [FILE]...
dirx --unsorted [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-U` | `--unsorted` | none |  | do not sort; list entries in directory order |

## Help in the terminal

```bash
gnux help dirx --unsorted
```
