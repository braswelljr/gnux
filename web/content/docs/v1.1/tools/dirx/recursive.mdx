---
title: "-R, --recursive"
description: "List subdirectories recursively."
---

An option of [dirx](/docs/v1.1/tools/dirx).

## Usage

```bash
dirx -R [FILE]...
dirx --recursive [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-R` | `--recursive` | none |  | list subdirectories recursively |

## Help in the terminal

```bash
gnux help dirx --recursive
```
