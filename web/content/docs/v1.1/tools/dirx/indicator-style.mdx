---
title: "--indicator-style"
description: "Append indicator with style WORD to entry names: none (default), slash (-p), file-type (--file-type), classify (-F)."
---

An option of [dirx](/docs/v1.1/tools/dirx).

## Usage

```bash
dirx --indicator-style=WORD [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--indicator-style` | `WORD` |  | append indicator with style WORD to entry names: none (default), slash (`-p`), file-type (`--file-type`), classify (`-F`) |

## Help in the terminal

```bash
gnux help dirx --indicator-style
```
