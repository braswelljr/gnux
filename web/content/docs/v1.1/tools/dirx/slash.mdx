An option of [dirx](/docs/v1.1/tools/dirx).

```bash
dirx -p [FILE]...
dirx --slash [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-p` | `--slash` | none |  | append / indicator to directories |
