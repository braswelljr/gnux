---
title: "-w, --equal-width"
description: "Equalize width by padding with leading zeroes."
---

An option of [seqx](/docs/v1.1/tools/seqx).

## Usage

```bash
seqx -w [FIRST [INCREMENT]] LAST
seqx --equal-width [FIRST [INCREMENT]] LAST
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-w` | `--equal-width` | none |  | equalize width by padding with leading zeroes |

## Examples

### Pad the numbers with zeros to equal width

```bash tab="bash" tab-group="shell"
seqx -w 8 12
```

```powershell tab="PowerShell" tab-group="shell"
seqx -w 8 12
```
