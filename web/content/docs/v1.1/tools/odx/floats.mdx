---
title: "-f, --floats"
description: "Same as -t fF, select floats."
---

An option of [odx](/docs/v1.1/tools/odx).

## Usage

```bash
odx -f [FILE]...
odx --floats[=string] [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-f` | `--floats` | `string` (optional) |  | same as `-t` fF, select floats |

## Help in the terminal

```bash
gnux help odx --floats
```
