An option of [odx](/docs/v1.1/tools/odx).

## Usage

```bash
odx -x [FILE]...
odx --hex-2-bytes[=string] [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-x` | `--hex-2-bytes` | `string` (optional) |  | same as `-t` x2, select hexadecimal 2-byte units |

gnux help odx --hex-2-bytes
