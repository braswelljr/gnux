An option of [odx](/docs/v1.1/tools/odx).

## Usage

```bash
odx -A RADIX [FILE]...
odx --address-radix=RADIX [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-A` | `--address-radix` | `RADIX` | `o` | output format for file offsets; RADIX is one of [doxn], for Decimal, Octal, Hex or None |

## Examples

### A hexdump with offsets in hex and the text alongside

```bash tab="bash" tab-group="shell"
odx -A x -t x1z image.png
```

```powershell tab="PowerShell" tab-group="shell"
odx -A x -t x1z image.png
```

### Read the first four bytes (a magic number)

```bash tab="bash" tab-group="shell"
odx -A n -t x1 -N 4 image.png
```

```powershell tab="PowerShell" tab-group="shell"
odx -A n -t x1 -N 4 image.png
```
