An option of [odx](/docs/v1.1/tools/odx).

## Usage

```bash
odx -l [FILE]...
odx --decimal-longs[=string] [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-l` | `--decimal-longs` | `string` (optional) |  | same as `-t` dL, select decimal longs |

## Help in the terminal

```bash
gnux help odx --decimal-longs
```
