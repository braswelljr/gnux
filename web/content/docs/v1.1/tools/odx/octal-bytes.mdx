An option of [odx](/docs/v1.1/tools/odx).

## Usage

```bash
odx -b [FILE]...
odx --octal-bytes[=string] [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-b` | `--octal-bytes` | `string` (optional) |  | same as `-t` o1, select octal bytes |
