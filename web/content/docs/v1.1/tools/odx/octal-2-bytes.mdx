```bash
odx -o [FILE]...
odx --octal-2-bytes[=string] [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-o` | `--octal-2-bytes` | `string` (optional) |  | same as `-t` o2, select octal 2-byte units |
