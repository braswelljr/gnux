---
title: "-H, --dereference-command-line"
description: "Follow symbolic links listed on the command line."
---

An option of [vdirx](/docs/v1.1/tools/vdirx).

## Usage

```bash
vdirx -H [FILE]...
vdirx --dereference-command-line [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-H` | `--dereference-command-line` | none |  | follow symbolic links listed on the command line |

## Help in the terminal

```bash
gnux help vdirx --dereference-command-line
```
