An option of [vdirx](/docs/v1.1/tools/vdirx).

## Usage

```bash
vdirx -G [FILE]...
vdirx --no-group [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-G` | `--no-group` | none |  | in a long listing, don't print group names |
