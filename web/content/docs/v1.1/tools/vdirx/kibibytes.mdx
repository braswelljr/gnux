An option of [vdirx](/docs/v1.1/tools/vdirx).

## Usage

```bash
vdirx -k [FILE]...
vdirx --kibibytes [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-k` | `--kibibytes` | none |  | default to 1024-byte blocks for file system usage; used only with `-s` and per directory totals |

## Help in the terminal

```bash
gnux help vdirx --kibibytes
```
