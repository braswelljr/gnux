An option of [vdirx](/docs/v1.1/tools/vdirx).

## Usage

```bash
vdirx -a [FILE]...
vdirx --all [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-a` | `--all` | none |  | do not ignore entries starting with . |

## Examples

### Include hidden entries

```bash tab="bash" tab-group="shell"
vdirx -a
```

```powershell tab="PowerShell" tab-group="shell"
vdirx -a
```

## Help in the terminal

```bash
gnux help vdirx --all
```
