---
title: "--color"
description: "Color the output WHEN: 'always' (the default when WHEN is omitted), 'auto', or 'never'."
---

An option of [vdirx](/docs/v1.1/tools/vdirx).

## Usage

```bash
vdirx --color[=WHEN] [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--color` | `WHEN` (optional) |  | color the output WHEN: 'always' (the default when WHEN is omitted), 'auto', or 'never' |

## Help in the terminal

```bash
gnux help vdirx --color
```
