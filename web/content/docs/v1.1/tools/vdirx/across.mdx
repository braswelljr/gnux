---
title: "-x, --across"
description: "List entries by lines instead of by columns."
---

An option of [vdirx](/docs/v1.1/tools/vdirx).

## Usage

```bash
vdirx -x [FILE]...
vdirx --across [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-x` | `--across` | none |  | list entries by lines instead of by columns |

## Help in the terminal

```bash
gnux help vdirx --across
```
