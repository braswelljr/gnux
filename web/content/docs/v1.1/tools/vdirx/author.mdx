---
title: "--author"
description: "With -l, print the author of each file."
---

An option of [vdirx](/docs/v1.1/tools/vdirx).

## Usage

```bash
vdirx --author [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--author` | none |  | with `-l`, print the author of each file |

## Help in the terminal

```bash
gnux help vdirx --author
```
