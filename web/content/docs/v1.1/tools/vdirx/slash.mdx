An option of [vdirx](/docs/v1.1/tools/vdirx).

## Usage

```bash
vdirx -p [FILE]...
vdirx --slash [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-p` | `--slash` | none |  | append / indicator to directories |
