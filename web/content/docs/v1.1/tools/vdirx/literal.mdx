---
title: "-N, --literal"
description: "Print entry names without quoting."
---

An option of [vdirx](/docs/v1.1/tools/vdirx).

## Usage

```bash
vdirx -N [FILE]...
vdirx --literal [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-N` | `--literal` | none |  | print entry names without quoting |

## Help in the terminal

```bash
gnux help vdirx --literal
```
