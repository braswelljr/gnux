An option of [vdirx](/docs/v1.1/tools/vdirx).

## Usage

```bash
vdirx -b [FILE]...
vdirx --escape [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-b` | `--escape` | none |  | print C-style escapes for nongraphic characters |

## Help in the terminal

```bash
gnux help vdirx --escape
```
