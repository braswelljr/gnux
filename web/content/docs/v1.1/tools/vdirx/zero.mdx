---
title: "--zero"
description: "End each output line with NUL, not newline."
---

An option of [vdirx](/docs/v1.1/tools/vdirx).

## Usage

```bash
vdirx --zero [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--zero` | none |  | end each output line with NUL, not newline |

## Help in the terminal

```bash
gnux help vdirx --zero
```
