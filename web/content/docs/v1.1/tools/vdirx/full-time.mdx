An option of [vdirx](/docs/v1.1/tools/vdirx).

## Usage

```bash
vdirx --full-time [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--full-time` | none |  | like `-l --time-style`=full-iso |

## Examples

### Show full timestamps

```bash tab="bash" tab-group="shell"
vdirx --full-time
```

```powershell tab="PowerShell" tab-group="shell"
vdirx --full-time
```
