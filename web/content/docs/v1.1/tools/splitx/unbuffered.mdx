An option of [splitx](/docs/v1.1/tools/splitx).

## Usage

```bash
splitx -u [FILE [PREFIX]]
splitx --unbuffered [FILE [PREFIX]]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-u` | `--unbuffered` | none |  | immediately copy input to output with '`-n` r/...' (always the case here) |

## Help in the terminal

```bash
gnux help splitx --unbuffered
```
