An option of [splitx](/docs/v1.1/tools/splitx).

## Usage

```bash
splitx -t SEP [FILE [PREFIX]]
splitx --separator=SEP [FILE [PREFIX]]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-t` | `--separator` | `SEP` |  | use SEP instead of newline as the record separator; '\0' (zero) specifies the NUL character |

## Examples

### Split NUL-separated records, such as the output of find -print0

```bash tab="bash" tab-group="shell"
find . -type f -print0 | splitx -t '\0' -l 1000 - batch-
```

```powershell tab="PowerShell" tab-group="shell"
splitx -t '\0' -l 1000 files.lst batch-
```
