---
title: "--verbose"
description: "Print a diagnostic just before each output file is opened."
---

An option of [splitx](/docs/v1.1/tools/splitx).

## Usage

```bash
splitx --verbose [FILE [PREFIX]]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--verbose` | none |  | print a diagnostic just before each output file is opened |

## Examples

### See each file as it is created

```bash tab="bash" tab-group="shell"
splitx --verbose -l 2 names.txt
```

```powershell tab="PowerShell" tab-group="shell"
splitx --verbose -l 2 names.txt
```

```text title="Output"
creating file 'xaa'
creating file 'xab'
```

## Help in the terminal

```bash
gnux help splitx --verbose
```
