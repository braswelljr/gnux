---
title: "-c, --crown-margin"
description: "Preserve indentation of first two lines."
---

An option of [fmtx](/docs/v1.1/tools/fmtx).

## Usage

```bash
fmtx [-WIDTH] -c [FILE]...
fmtx [-WIDTH] --crown-margin [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-c` | `--crown-margin` | none |  | preserve indentation of first two lines |

## Examples

### Reflow a letter that indents its first line

```bash tab="bash" tab-group="shell"
fmtx -c letter.txt
```

```powershell tab="PowerShell" tab-group="shell"
fmtx -c letter.txt
```

## Help in the terminal

```bash
gnux help fmtx --crown-margin
```
