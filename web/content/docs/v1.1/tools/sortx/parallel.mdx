An option of [sortx](/docs/v1.1/tools/sortx).

## Usage

```bash
sortx --parallel=N [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--parallel` | `N` | `0` | accepted for compatibility and ignored (N concurrent sorts) |

## Help in the terminal

```bash
gnux help sortx --parallel
```
