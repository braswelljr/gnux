title: "--random-source"
description: "Get random bytes from FILE."
---

An option of [sortx](/docs/v1.1/tools/sortx).

## Usage

```bash
sortx --random-source=FILE [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--random-source` | `FILE` |  | get random bytes from FILE |

## Examples

### Run the test files in a shuffled order that a seed file makes repeatable

```bash tab="bash" tab-group="shell"
lsx tests/*.sh | sortx -R --random-source=ci-seed.bin
```

```powershell tab="PowerShell" tab-group="shell"
lsx tests | sortx -R --random-source=ci-seed.bin
```
