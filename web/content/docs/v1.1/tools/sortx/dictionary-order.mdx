An option of [sortx](/docs/v1.1/tools/sortx).

## Usage

```bash
sortx -d [FILE]...
sortx --dictionary-order [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-d` | `--dictionary-order` | none |  | consider only blanks and alphanumeric characters |

## Help in the terminal

gnux help sortx --dictionary-order
