An option of [sortx](/docs/v1.1/tools/sortx).

## Usage

```bash
sortx -i [FILE]...
sortx --ignore-nonprinting [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-i` | `--ignore-nonprinting` | none |  | consider only printable characters |
