---
title: "--status"
description: "Don't output anything, status code shows success."
---

An option of [cksumx](/docs/v1.1/tools/cksumx).

## Usage

```bash
cksumx --status [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--status` | none |  | don't output anything, status code shows success |

## Examples

### Check silently and branch on the result

```bash tab="bash" tab-group="shell"
cksumx -c --status SUMS && echox verified
```

```powershell tab="PowerShell" tab-group="shell"
cksumx -c --status SUMS; if ($LASTEXITCODE -eq 0) { 'verified' }
```

## Help in the terminal

```bash
gnux help cksumx --status
```
