---
title: "--base64"
description: "Emit base64-encoded digests, not hexadecimal."
---

An option of [cksumx](/docs/v1.1/tools/cksumx).

## Usage

```bash
cksumx --base64 [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--base64` | none |  | emit `base64``-encoded` digests, not hexadecimal |

## Examples

### Print a digest in base64 (as SRI hashes use)

```bash tab="bash" tab-group="shell"
cksumx -a sha384 --base64 app.js
```

```powershell tab="PowerShell" tab-group="shell"
cksumx -a sha384 --base64 app.js
```

gnux help cksumx --base64
