---
title: "--retry"
description: "Keep trying to open a file if it is inaccessible."
---

An option of [tailx](/docs/v1.1/tools/tailx).

## Usage

```bash
tailx --retry [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--retry` | none |  | keep trying to open a file if it is inaccessible |

## Examples

### Follow by name and wait for a file that does not exist yet

```bash tab="bash" tab-group="shell"
tailx --follow=name --retry service.log
```

```powershell tab="PowerShell" tab-group="shell"
tailx --follow=name --retry service.log
```

## Help in the terminal

```bash
gnux help tailx --retry
```
