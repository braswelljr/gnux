---
title: "-c, --bytes"
description: "Output the last NUM bytes; or use -c +NUM to output starting with byte NUM of each file."
---

An option of [tailx](/docs/v1.1/tools/tailx).

## Usage

```bash
tailx -c [+]NUM [FILE]...
tailx --bytes=[+]NUM [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-c` | `--bytes` | `[+]NUM` |  | output the last NUM bytes; or use `-c` +NUM to output starting with byte NUM of each file |

## Examples

### Print the last 100 bytes of a file

```bash tab="bash" tab-group="shell"
tailx -c 100 app.log
```

```powershell tab="PowerShell" tab-group="shell"
tailx -c 100 app.log
```

### Drop a 3-byte UTF-8 byte-order mark by starting at byte 4

```bash tab="bash" tab-group="shell"
tailx -c +4 with-bom.txt > clean.txt
```

```powershell tab="PowerShell" tab-group="shell"
gnux shell -c 'tailx -c +4 with-bom.txt > clean.txt'
```

## Help in the terminal

gnux help tailx --bytes
