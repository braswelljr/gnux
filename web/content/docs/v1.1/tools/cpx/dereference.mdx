---
title: "-L, --dereference"
description: "Always follow symbolic links in SOURCE."
---

An option of [cpx](/docs/v1.1/tools/cpx).

## Usage

```bash
cpx -L SOURCE... DIRECTORY
cpx --dereference SOURCE... DIRECTORY
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-L` | `--dereference` | none |  | always follow symbolic links in SOURCE |

## Examples

### Copy a tree, replacing every symbolic link with the file it points to

```bash tab="bash" tab-group="shell"
cpx -rL vendor/ vendor-flat/
```

```powershell tab="PowerShell" tab-group="shell"
cpx -rL vendor vendor-flat
```
