---
title: "-H, --dereference-args"
description: "Follow command-line symbolic links in SOURCE."
---

An option of [cpx](/docs/v1.1/tools/cpx).

## Usage

```bash
cpx -H SOURCE... DIRECTORY
cpx --dereference-args SOURCE... DIRECTORY
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-H` | `--dereference-args` | none |  | follow command-line symbolic links in SOURCE |

## Examples

### Copy through a symlinked directory named on the command line only

```bash tab="bash" tab-group="shell"
cpx -rH latest snapshot
```

```powershell tab="PowerShell" tab-group="shell"
cpx -rH latest snapshot
```

## Help in the terminal

```bash
gnux help cpx --dereference-args
```
