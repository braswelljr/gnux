---
title: "--parents"
description: "Use the full source file name under DIRECTORY."
---

An option of [cpx](/docs/v1.1/tools/cpx).

## Usage

```bash
cpx --parents SOURCE... DIRECTORY
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--parents` | none |  | use the full source file name under DIRECTORY |

## Examples

### Recreate the source paths under a backup directory

```bash tab="bash" tab-group="shell"
cpx --parents src/app/main.go src/lib/util.go backup/
```

```powershell tab="PowerShell" tab-group="shell"
cpx --parents src/app/main.go src/lib/util.go backup
```
