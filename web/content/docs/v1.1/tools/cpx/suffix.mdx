---
title: "-S, --suffix"
description: "Override the usual backup suffix, '~', with SUFFIX."
---

An option of [cpx](/docs/v1.1/tools/cpx).

## Usage

```bash
cpx -S SUFFIX SOURCE... DIRECTORY
cpx --suffix=SUFFIX SOURCE... DIRECTORY
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-S` | `--suffix` | `SUFFIX` |  | override the usual backup suffix, '~', with SUFFIX |

## Help in the terminal

```bash
gnux help cpx --suffix
```
