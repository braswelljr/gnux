---
title: "--no-preserve"
description: "Don't preserve the listed attributes."
---

An option of [cpx](/docs/v1.1/tools/cpx).

## Usage

```bash
cpx --no-preserve=string SOURCE... DIRECTORY
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--no-preserve` | `string` |  | don't preserve the listed attributes |

## Examples

### Preserve only the timestamps, or archive without carrying over ownership

```bash tab="bash" tab-group="shell"
cpx --preserve=timestamps photo.jpg archive/ && cpx -a --no-preserve=ownership project/ copy/
```

```powershell tab="PowerShell" tab-group="shell"
cpx --preserve=timestamps photo.jpg archive; cpx -a --no-preserve=ownership project copy
```
