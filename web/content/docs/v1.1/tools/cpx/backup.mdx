An option of [cpx](/docs/v1.1/tools/cpx).

## Usage

```bash
cpx --backup[=CONTROL] SOURCE... DIRECTORY
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--backup` | `CONTROL` (optional) |  | make a backup of each existing destination file; CONTROL is none (off), simple (never), existing (nil) or numbered (t) |

## Examples

### Keep every earlier version of a deployed file as app.conf.~1~, app.conf.~2~, ...

```bash tab="bash" tab-group="shell"
cpx --backup=numbered build/app.conf /etc/app/app.conf
```

```powershell tab="PowerShell" tab-group="shell"
cpx --backup=numbered build\app.conf C:\app\app.conf
```
