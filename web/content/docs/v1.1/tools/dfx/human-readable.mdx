---
title: "-h, --human-readable"
description: "Print sizes in powers of 1024 (e.g., 1023M)."
---

An option of [dfx](/docs/v1.1/tools/dfx).

## Usage

```bash
dfx -h [FILE]...
dfx --human-readable [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-h` | `--human-readable` | none |  | print sizes in powers of 1024 (e.g., 1023M) |

## Examples

### See at a glance how full every disk is

```bash tab="bash" tab-group="shell"
dfx -h
```

```powershell tab="PowerShell" tab-group="shell"
dfx -h
```

```text title="Output"
Filesystem      Size  Used Avail Use% Mounted on
/dev/nvme0n1p2  469G  301G  145G  68% /
/dev/nvme0n1p1  511M  6.1M  505M   2% /boot/efi
/dev/sda1       1.8T  1.6T  163G  91% /mnt/backup
```

### Before a 20 GB download, check the free space where it will land

```bash tab="bash" tab-group="shell"
dfx -h ~/Downloads
```

```powershell tab="PowerShell" tab-group="shell"
dfx -h $HOME\Downloads
```

```text title="Output"
Filesystem      Size  Used Avail Use% Mounted on
/dev/nvme0n1p2  469G  301G  145G  68% /
```

### Show only real local disks, with their file system types

```bash tab="bash" tab-group="shell"
dfx -hlT
```

```powershell tab="PowerShell" tab-group="shell"
dfx -hlT
```

```text title="Output"
Filesystem     Type  Size  Used Avail Use% Mounted on
/dev/nvme0n1p2 ext4  469G  301G  145G  68% /
```

### Total the space across all local disks

```bash tab="bash" tab-group="shell"
dfx -hl --total
```

```powershell tab="PowerShell" tab-group="shell"
dfx -hl --total
```

### Check only the network shares

```bash tab="bash" tab-group="shell"
dfx -h -t nfs -t cifs
```

```powershell tab="PowerShell" tab-group="shell"
dfx -h
```

### Leave temporary file systems out of the report

```bash tab="bash" tab-group="shell"
dfx -h -x tmpfs -x devtmpfs
```

```powershell tab="PowerShell" tab-group="shell"
dfx -h
```
