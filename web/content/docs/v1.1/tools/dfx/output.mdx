An option of [dfx](/docs/v1.1/tools/dfx).

## Usage

```bash
dfx --output[=FIELD_LIST] [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--output` | `FIELD_LIST` (optional) |  | use the output format defined by FIELD_LIST, or print all fields if FIELD_LIST is omitted |

## Examples

### Print just the available space, in megabytes, for a script

```bash tab="bash" tab-group="shell"
dfx -BM --output=avail /data | tailx -n 1
```

```powershell tab="PowerShell" tab-group="shell"
dfx -BM --output=avail D:\ | tailx -n 1
```

```text title="Output"
  48213M
```

### See which device and file system type a directory is on

```bash tab="bash" tab-group="shell"
dfx --output=source,fstype,target /var/lib/docker
```

```powershell tab="PowerShell" tab-group="shell"
dfx --output=source,fstype,target C:\Users
```

```text title="Output"
Filesystem     Type Mounted on
/dev/nvme0n1p2 ext4 /
```
