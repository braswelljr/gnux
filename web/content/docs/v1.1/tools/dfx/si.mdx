---
title: "-H, --si"
description: "Print sizes in powers of 1000 (e.g., 1.1G)."
---

An option of [dfx](/docs/v1.1/tools/dfx).

## Usage

```bash
dfx -H [FILE]...
dfx --si [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-H` | `--si` | none |  | print sizes in powers of 1000 (e.g., 1.1G) |

## Help in the terminal

```bash
gnux help dfx --si
```
