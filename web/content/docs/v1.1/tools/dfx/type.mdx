---
title: "-t, --type"
description: "Limit listing to file systems of type TYPE."
---

An option of [dfx](/docs/v1.1/tools/dfx).

## Usage

```bash
dfx -t TYPE [FILE]...
dfx --type=TYPE [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-t` | `--type` | `TYPE` |  | limit listing to file systems of type TYPE |

## Examples

### Check only the network shares

```bash tab="bash" tab-group="shell"
dfx -h -t nfs -t cifs
```

```powershell tab="PowerShell" tab-group="shell"
dfx -h
```

## Help in the terminal

```bash
gnux help dfx --type
```
