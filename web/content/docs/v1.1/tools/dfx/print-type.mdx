---
title: "-T, --print-type"
description: "Print file system type."
---

An option of [dfx](/docs/v1.1/tools/dfx).

## Usage

```bash
dfx -T [FILE]...
dfx --print-type [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-T` | `--print-type` | none |  | print file system type |

## Examples

### Show only real local disks, with their file system types

```bash tab="bash" tab-group="shell"
dfx -hlT
```

```powershell tab="PowerShell" tab-group="shell"
dfx -hlT
```

```text title="Output"
Filesystem     Type  Size  Used Avail Use% Mounted on
/dev/nvme0n1p2 ext4  469G  301G  145G  68% /
```

## Help in the terminal

```bash
gnux help dfx --print-type
```
