---
title: "-G, --no-group"
description: "In a long listing, don't print group names."
---

An option of [lsx](/docs/v1.1/tools/lsx).

## Usage

```bash
lsx -G [FILE]...
lsx --no-group [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-G` | `--no-group` | none |  | in a long listing, don't print group names |

## Examples

### Long format with numeric user and group IDs, or without the owner or group columns

```bash tab="bash" tab-group="shell"
lsx -n data/ && lsx -g data/ && lsx -o data/ && lsx -lG data/
```

```powershell tab="PowerShell" tab-group="shell"
lsx -n data; lsx -g data; lsx -o data; lsx -lG data
```

## Help in the terminal

```bash
gnux help lsx --no-group
```
