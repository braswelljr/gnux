---
title: "-i, --inode"
description: "Print the index number of each file."
---

An option of [lsx](/docs/v1.1/tools/lsx).

## Usage

```bash
lsx -i [FILE]...
lsx --inode [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-i` | `--inode` | none |  | print the index number of each file |

## Examples

### Show inode numbers and allocated blocks, with directories marked by a slash

```bash tab="bash" tab-group="shell"
lsx -isp
```

```powershell tab="PowerShell" tab-group="shell"
lsx -isp
```

## Help in the terminal

```bash
gnux help lsx --inode
```
