---
title: "-X, --sort-extension"
description: "Sort alphabetically by entry extension."
---

An option of [lsx](/docs/v1.1/tools/lsx).

## Usage

```bash
lsx -X [FILE]...
lsx --sort-extension [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-X` | `--sort-extension` | none |  | sort alphabetically by entry extension |

## Examples

### Group files by extension, as a comma-separated list

```bash tab="bash" tab-group="shell"
lsx -X -m assets/
```

```powershell tab="PowerShell" tab-group="shell"
lsx -X -m assets
```

## Help in the terminal

```bash
gnux help lsx --sort-extension
```
