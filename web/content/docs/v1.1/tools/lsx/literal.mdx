---
title: "-N, --literal"
description: "Print entry names without quoting."
---

An option of [lsx](/docs/v1.1/tools/lsx).

## Usage

```bash
lsx -N [FILE]...
lsx --literal [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-N` | `--literal` | none |  | print entry names without quoting |

## Help in the terminal

```bash
gnux help lsx --literal
```
