---
title: "-d, --directory"
description: "List directories themselves, not their contents."
---

An option of [lsx](/docs/v1.1/tools/lsx).

## Usage

```bash
lsx -d [FILE]...
lsx --directory [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-d` | `--directory` | none |  | list directories themselves, not their contents |

## Examples

### List a directory itself rather than its contents, with ISO timestamps

```bash tab="bash" tab-group="shell"
lsx -ld --time-style=long-iso ~/projects
```

```powershell tab="PowerShell" tab-group="shell"
lsx -ld --time-style=long-iso $HOME\projects
```

## Help in the terminal

```bash
gnux help lsx --directory
```
