---

An option of [lsx](/docs/v1.1/tools/lsx).

## Usage

```bash
lsx -t [FILE]...
lsx --sort-time [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-t` | `--sort-time` | none |  | sort by time, newest first; see `--time` |

## Examples

### Newest files first, in the long format

```bash tab="bash" tab-group="shell"
lsx -lt /var/log
```

```powershell tab="PowerShell" tab-group="shell"
lsx -lt $env:TEMP
```

### Sort by last access time (-u) or status change time (-c), showing that time

```bash tab="bash" tab-group="shell"
lsx -ltu cache/ && lsx -lt --time=ctime cache/
```

```powershell tab="PowerShell" tab-group="shell"
lsx -ltu cache; lsx -lt --time=ctime cache
```

### Print the name of the most recently modified file

```bash tab="bash" tab-group="shell"
lsx -t | headx -n 1
```

```powershell tab="PowerShell" tab-group="shell"
lsx -t | headx -n 1
```

## Help in the terminal

gnux help lsx --sort-time
