An option of [lnx](/docs/v1.1/tools/lnx).

## Usage

```bash
lnx --backup[=CONTROL] TARGET... [LINK_NAME|DIRECTORY]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--backup` | `CONTROL` (optional) |  | make a backup of each existing destination file; CONTROL is none (off), simple (never), existing (nil) or numbered (t) |

## Help in the terminal

```bash
gnux help lnx --backup
```
