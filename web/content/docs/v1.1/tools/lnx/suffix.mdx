---
title: "-S, --suffix"
description: "Override the usual backup suffix, '~', with SUFFIX."
---

An option of [lnx](/docs/v1.1/tools/lnx).

## Usage

```bash
lnx -S SUFFIX TARGET... [LINK_NAME|DIRECTORY]
lnx --suffix=SUFFIX TARGET... [LINK_NAME|DIRECTORY]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-S` | `--suffix` | `SUFFIX` |  | override the usual backup suffix, '~', with SUFFIX |

## Help in the terminal

```bash
gnux help lnx --suffix
```
