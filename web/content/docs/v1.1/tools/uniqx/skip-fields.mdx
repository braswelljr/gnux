---
title: "-f, --skip-fields"
description: "Avoid comparing the first N fields."
---

An option of [uniqx](/docs/v1.1/tools/uniqx).

## Usage

```bash
uniqx -f N [INPUT [OUTPUT]]
uniqx --skip-fields=N [INPUT [OUTPUT]]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-f` | `--skip-fields` | `N` |  | avoid comparing the first N fields |

## Examples

### Ignore the first field (a timestamp, say) when comparing

```bash tab="bash" tab-group="shell"
uniqx -f 1 events.log
```

```powershell tab="PowerShell" tab-group="shell"
uniqx -f 1 events.log
```
