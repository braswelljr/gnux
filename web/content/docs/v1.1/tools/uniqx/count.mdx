---
title: "-c, --count"
description: "Prefix lines by the number of occurrences."
---

An option of [uniqx](/docs/v1.1/tools/uniqx).

## Usage

```bash
uniqx -c [INPUT [OUTPUT]]
uniqx --count [INPUT [OUTPUT]]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-c` | `--count` | none |  | prefix lines by the number of occurrences |

## Examples

### Count the occurrences of each line

```bash tab="bash" tab-group="shell"
uniqx -c sorted.txt
```

```powershell tab="PowerShell" tab-group="shell"
uniqx -c sorted.txt
```

### Deduplicate in the portable gnux shell

```bash tab="bash" tab-group="shell"
gnux shell -c 'catx sorted.txt | uniqx -c'
```

```powershell tab="PowerShell" tab-group="shell"
gnux shell -c 'catx sorted.txt | uniqx -c'
```

## Help in the terminal

```bash
gnux help uniqx --count
```
