---
title: "-i, --ignore-case"
description: "Ignore differences in case when comparing."
---

An option of [uniqx](/docs/v1.1/tools/uniqx).

## Usage

```bash
uniqx -i [INPUT [OUTPUT]]
uniqx --ignore-case [INPUT [OUTPUT]]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-i` | `--ignore-case` | none |  | ignore differences in case when comparing |

## Examples

### Compare without regard to case

```bash tab="bash" tab-group="shell"
uniqx -i words.txt
```

```powershell tab="PowerShell" tab-group="shell"
uniqx -i words.txt
```

```bash
gnux help uniqx --ignore-case
```
