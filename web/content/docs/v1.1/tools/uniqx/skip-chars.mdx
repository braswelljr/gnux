---
title: "-s, --skip-chars"
description: "Avoid comparing the first N characters."
---

An option of [uniqx](/docs/v1.1/tools/uniqx).

## Usage

```bash
uniqx -s N [INPUT [OUTPUT]]
uniqx --skip-chars=N [INPUT [OUTPUT]]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-s` | `--skip-chars` | `N` |  | avoid comparing the first N characters |

## Examples

### Ignore the first 4 characters when comparing

```bash tab="bash" tab-group="shell"
uniqx -s 4 ids.txt
```

```powershell tab="PowerShell" tab-group="shell"
uniqx -s 4 ids.txt
```
