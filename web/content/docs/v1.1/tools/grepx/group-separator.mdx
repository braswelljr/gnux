---
title: "--group-separator"
description: "Print SEP on the line between groups of matches with context."
---

An option of [grepx](/docs/v1.1/tools/grepx).

## Usage

```bash
grepx --group-separator=SEP PATTERNS [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--group-separator` | `SEP` |  | print SEP on the line between groups of matches with context |

## Help in the terminal

```bash
gnux help grepx --group-separator
```
