---
title: "-s, --no-messages"
description: "Suppress error messages about files that do not exist or cannot be read."
---

An option of [grepx](/docs/v1.1/tools/grepx).

## Usage

```bash
grepx -s PATTERNS [FILE]...
grepx --no-messages PATTERNS [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-s` | `--no-messages` | none |  | suppress error messages about files that do not exist or cannot be read |

## Help in the terminal

```bash
gnux help grepx --no-messages
```
