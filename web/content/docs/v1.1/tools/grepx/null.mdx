---
title: "-Z, --null"
description: "Print a NUL byte after each FILE name."
---

An option of [grepx](/docs/v1.1/tools/grepx).

## Usage

```bash
grepx -Z PATTERNS [FILE]...
grepx --null PATTERNS [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-Z` | `--null` | none |  | print a NUL byte after each FILE name |

## Help in the terminal

```bash
gnux help grepx --null
```
