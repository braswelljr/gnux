---
title: "-H, --with-filename"
description: "Print the file name with output lines."
---

An option of [grepx](/docs/v1.1/tools/grepx).

## Usage

```bash
grepx -H PATTERNS [FILE]...
grepx --with-filename PATTERNS [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-H` | `--with-filename` | none |  | print the file name with output lines |

## Help in the terminal

```bash
gnux help grepx --with-filename
```
