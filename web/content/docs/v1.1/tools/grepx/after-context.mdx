---
title: "-A, --after-context"
description: "Print NUM lines of trailing context."
---

An option of [grepx](/docs/v1.1/tools/grepx).

## Usage

```bash
grepx -A NUM PATTERNS [FILE]...
grepx --after-context=NUM PATTERNS [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-A` | `--after-context` | `NUM` |  | print NUM lines of trailing context |

## Help in the terminal

```bash
gnux help grepx --after-context
```
