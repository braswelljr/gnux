An option of [grepx](/docs/v1.1/tools/grepx).

## Usage

```bash
grepx -R PATTERNS [FILE]...
grepx --dereference-recursive PATTERNS [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-R` | `--dereference-recursive` | none |  | likewise, but follow all symbolic links |
