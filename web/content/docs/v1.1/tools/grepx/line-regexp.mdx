---
title: "-x, --line-regexp"
description: "Match only whole lines."
---

An option of [grepx](/docs/v1.1/tools/grepx).

## Usage

```bash
grepx -x PATTERNS [FILE]...
grepx --line-regexp PATTERNS [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-x` | `--line-regexp` | none |  | match only whole lines |

## Help in the terminal

```bash
gnux help grepx --line-regexp
```
