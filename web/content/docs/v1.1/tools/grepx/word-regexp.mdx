---
title: "-w, --word-regexp"
description: "Match only whole words."
---

An option of [grepx](/docs/v1.1/tools/grepx).

## Usage

```bash
grepx -w PATTERNS [FILE]...
grepx --word-regexp PATTERNS [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-w` | `--word-regexp` | none |  | match only whole words |

## Examples

### Search a source tree for a whole word, with file names and line numbers

```bash tab="bash" tab-group="shell"
grepx -rnw 'TODO' src
```

```powershell tab="PowerShell" tab-group="shell"
grepx -rnw 'TODO' src
```

```text title="Output"

```
