An option of [whox](/docs/v1.1/tools/whox).

## Usage

```bash
whox -T [ FILE | ARG1 ARG2 ]
whox --mesg [ FILE | ARG1 ARG2 ]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-T` | `--mesg` | none |  | add user's message status as +, - or ? |

## Examples

### See who will receive a 'wall' broadcast (+ accepts messages)

```bash tab="bash" tab-group="shell"
whox -T
```

```powershell tab="PowerShell" tab-group="shell"
whox -T
```

## Help in the terminal

```bash
gnux help whox --mesg
```
