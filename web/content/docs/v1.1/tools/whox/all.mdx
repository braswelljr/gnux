An option of [whox](/docs/v1.1/tools/whox).

## Usage

```bash
whox -a [ FILE | ARG1 ARG2 ]
whox --all [ FILE | ARG1 ARG2 ]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-a` | `--all` | none |  | same as `-b -d --login -p -r -t -T -u` |

## Examples

### Show every record, including dead processes and the run level

```bash tab="bash" tab-group="shell"
whox -a
```

```powershell tab="PowerShell" tab-group="shell"
whox -a
```

## Help in the terminal

```bash
gnux help whox --all
```
