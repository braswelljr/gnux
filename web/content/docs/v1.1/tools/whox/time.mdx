An option of [whox](/docs/v1.1/tools/whox).

```bash
whox -t [ FILE | ARG1 ARG2 ]

```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-t` | `--time` | none |  | print last system clock change |
