An option of [whox](/docs/v1.1/tools/whox).

## Usage

```bash
whox -l [ FILE | ARG1 ARG2 ]
whox --login [ FILE | ARG1 ARG2 ]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-l` | `--login` | none |  | print system login processes |

## Help in the terminal

```bash
gnux help whox --login
```
