---
title: "-c, --no-create"
description: "Do not create any files."
---

An option of [truncatex](/docs/v1.1/tools/truncatex).

## Usage

```bash
truncatex -c OPTION... FILE...
truncatex --no-create OPTION... FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-c` | `--no-create` | none |  | do not create any files |

## Examples

### Empty every log that exists, without creating missing ones

```bash tab="bash" tab-group="shell"
truncatex -c -s 0 a.log b.log c.log
```

```powershell tab="PowerShell" tab-group="shell"
truncatex -c -s 0 a.log b.log c.log
```

## Help in the terminal

```bash
gnux help truncatex --no-create
```
