An option of [nprocx](/docs/v1.1/tools/nprocx).

## Usage

```bash
nprocx --all
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--all` | none |  | print the number of installed processors |

### Print the number of installed processors
