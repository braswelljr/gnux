---
title: "-h, --no-dereference"
description: "Affect each symbolic link, rather than the referent."
---

An option of [chmodx](/docs/v1.1/tools/chmodx).

## Usage

```bash
chmodx -h MODE[,MODE]... FILE...
chmodx --no-dereference MODE[,MODE]... FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-h` | `--no-dereference` | none |  | affect each symbolic `link`, rather than the referent |

## Help in the terminal

```bash
gnux help chmodx --no-dereference
```
