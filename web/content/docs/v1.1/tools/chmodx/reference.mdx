An option of [chmodx](/docs/v1.1/tools/chmodx).

## Usage

```bash
chmodx --reference=RFILE MODE[,MODE]... FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--reference` | `RFILE` |  | use RFILE's mode instead of specifying MODE values |

## Examples

### Give a new script the same permissions as an existing one

```bash tab="bash" tab-group="shell"
chmodx --reference=template.sh new.sh
```

```powershell tab="PowerShell" tab-group="shell"
chmodx --reference=template.sh new.sh
```

## Help in the terminal

```bash
gnux help chmodx --reference
```
