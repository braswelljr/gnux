An option of [ttyx](/docs/v1.1/tools/ttyx).

## Usage

```bash
ttyx -s
ttyx --silent
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-s` | `--silent` | none |  | print nothing, only return an exit status |

## Examples

### Refuse to ask for a password in a cron job or CI run

```bash tab="bash" tab-group="shell"
ttyx -s || { echox 'no terminal: set DB_PASSWORD instead' >&2; exit 1; }
```

```powershell tab="PowerShell" tab-group="shell"
ttyx -s; if ($LASTEXITCODE -ne 0) { Write-Error 'no terminal: set DB_PASSWORD instead'; exit 1 }
```

### Show progress only when a person is watching

```bash tab="bash" tab-group="shell"
ttyx -s && echox 'Copying 4.2 GB, this takes a few minutes...'
```

```powershell tab="PowerShell" tab-group="shell"
ttyx -s; if ($LASTEXITCODE -eq 0) { 'Copying 4.2 GB, this takes a few minutes...' }
```

### Get the exit status alone, for a test in a script

```bash tab="bash" tab-group="shell"
ttyx -s; echox $?
```

```powershell tab="PowerShell" tab-group="shell"
ttyx -s; $LASTEXITCODE
```

```text title="Output"
0
```
