---
title: "-3, --suppress-common"
description: "Suppress column 3 (lines that appear in both files)."
---

An option of [commx](/docs/v1.1/tools/commx).

## Usage

```bash
commx -3 FILE1 FILE2
commx --suppress-common FILE1 FILE2
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-3` | `--suppress-common` | none |  | suppress column 3 (lines that appear in both files) |

## Help in the terminal

```bash
gnux help commx --suppress-common
```
