---
title: "-z, --zero-terminated"
description: "Line delimiter is NUL, not newline."
---

An option of [commx](/docs/v1.1/tools/commx).

## Usage

```bash
commx -z FILE1 FILE2
commx --zero-terminated FILE1 FILE2
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-z` | `--zero-terminated` | none |  | line delimiter is NUL, not newline |

## Examples

### Compare NUL-terminated lists

```bash tab="bash" tab-group="shell"
commx -z -12 a.lst b.lst
```

```powershell tab="PowerShell" tab-group="shell"
commx -z -12 a.lst b.lst
```

gnux help commx --zero-terminated
