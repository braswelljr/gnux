---
title: "-c, --complement"
description: "Use the complement of SET1."
---

An option of [trx](/docs/v1.1/tools/trx).

## Usage

```bash
trx -c STRING1 [STRING2]
trx --complement STRING1 [STRING2]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-c` | `--complement` | none |  | use the complement of SET1 |

## Examples

### Put each word on a line of its own

```bash tab="bash" tab-group="shell"
catx essay.txt | trx -cs '[:alnum:]' '\n'
```

```powershell tab="PowerShell" tab-group="shell"
catx essay.txt | trx -cs '[:alnum:]' '\n'
```

### Keep only the printable characters and newlines

```bash tab="bash" tab-group="shell"
trx -cd '[:print:]\n' < binary.log
```

```powershell tab="PowerShell" tab-group="shell"
catx binary.log | trx -cd '[:print:]\n'
```
