---
title: "-P, --physical"
description: "Resolve all symlinks (default)."
---

An option of [pwdx](/docs/v1.1/tools/pwdx).

## Usage

```bash
pwdx -P
pwdx --physical
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-P` | `--physical` | none |  | resolve all symlinks (default) |

## Examples

### Resolve every symlink explicitly

```bash tab="bash" tab-group="shell"
cd link && pwdx -P
```

```powershell tab="PowerShell" tab-group="shell"
Set-Location link; pwdx -P
```

gnux help pwdx --physical
