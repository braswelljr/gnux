---
title: "-b, --binary"
description: "Read in binary mode."
---

An option of [md5sumx](/docs/v1.1/tools/md5sumx).

## Usage

```bash
md5sumx -b [FILE]...
md5sumx --binary [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-b` | `--binary` | none |  | read in binary mode |

## Examples

### Match the '*' binary-mode lines produced by tools on Windows

```bash tab="bash" tab-group="shell"
md5sumx -b setup.exe
```

```powershell tab="PowerShell" tab-group="shell"
md5sumx -b setup.exe
```

## Help in the terminal

```bash
gnux help md5sumx --binary
```
