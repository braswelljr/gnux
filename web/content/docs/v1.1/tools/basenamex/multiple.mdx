---
title: "-a, --multiple"
description: "Support multiple arguments and treat each as a NAME."
---

An option of [basenamex](/docs/v1.1/tools/basenamex).

## Usage

```bash
basenamex -a NAME [SUFFIX]
basenamex --multiple NAME [SUFFIX]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-a` | `--multiple` | none |  | support multiple arguments and treat each as a NAME |

## Examples

### Treat every operand as a NAME

```bash tab="bash" tab-group="shell"
basenamex -a /var/log/syslog /etc/hosts
```

```powershell tab="PowerShell" tab-group="shell"
basenamex -a C:\Windows\win.ini C:\Windows\System32\drivers\etc\hosts
```

### Separate the output with NUL bytes instead of newlines

```bash tab="bash" tab-group="shell"
basenamex -a -z a/b c/d | od -c
```

```powershell tab="PowerShell" tab-group="shell"
basenamex -a -z a\b c\d | Format-Hex
```

## Help in the terminal

gnux help basenamex --multiple
