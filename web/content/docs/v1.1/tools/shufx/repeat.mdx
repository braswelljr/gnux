---
title: "-r, --repeat"
description: "Output lines can be repeated."
---

An option of [shufx](/docs/v1.1/tools/shufx).

## Usage

```bash
shufx -r [FILE]
shufx --repeat [FILE]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-r` | `--repeat` | none |  | output lines can be repeated |

## Examples

### Roll a die five times (numbers may repeat)

```bash tab="bash" tab-group="shell"
shufx -i 1-6 -r -n 5
```

```powershell tab="PowerShell" tab-group="shell"
shufx -i 1-6 -r -n 5
```

### An endless stream of coin flips, cut short by headx

```bash tab="bash" tab-group="shell"
shufx -r -e heads tails | headx -n 4
```

```powershell tab="PowerShell" tab-group="shell"
shufx -r -e heads tails | headx -n 4
```

## Help in the terminal

```bash
gnux help shufx --repeat
```
