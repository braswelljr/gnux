title: "-e, --echo"
description: "Treat each ARG as an input line."
---

An option of [shufx](/docs/v1.1/tools/shufx).

## Usage

```bash
shufx -e [FILE]
shufx --echo [FILE]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-e` | `--echo` | none |  | treat each ARG as an input line |

## Examples

### Pick one of several words

```bash tab="bash" tab-group="shell"
shufx -e -n 1 red green blue
```

```powershell tab="PowerShell" tab-group="shell"
shufx -e -n 1 red green blue
```

### An endless stream of coin flips, cut short by headx

```bash tab="bash" tab-group="shell"
shufx -r -e heads tails | headx -n 4
```

```powershell tab="PowerShell" tab-group="shell"
shufx -r -e heads tails | headx -n 4
```
