title: "-z, --zero-terminated"
description: "Line delimiter is NUL, not newline."
---

An option of [shufx](/docs/v1.1/tools/shufx).

## Usage

```bash
shufx -z [FILE]
shufx --zero-terminated [FILE]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-z` | `--zero-terminated` | none |  | line delimiter is NUL, not newline |

## Examples

### Pick a random file from a NUL-separated list

```bash tab="bash" tab-group="shell"
find . -type f -print0 | shufx -z -n 1
```

```powershell tab="PowerShell" tab-group="shell"
lsx -1 | shufx -n 1
```

## Help in the terminal

```bash
gnux help shufx --zero-terminated
```
