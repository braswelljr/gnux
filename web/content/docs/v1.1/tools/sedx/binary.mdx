---
title: "-b, --binary"
description: "Open files in binary mode (always the case here)."
---

An option of [sedx](/docs/v1.1/tools/sedx).

## Usage

```bash
sedx -b {script-only-if-no-other-script} [input-file]...
sedx --binary {script-only-if-no-other-script} [input-file]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-b` | `--binary` | none |  | open files in binary mode (always the case here) |

## Help in the terminal

```bash
gnux help sedx --binary
```
