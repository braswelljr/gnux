---
title: "-n, --quiet"
description: "Suppress automatic printing of pattern space."
---

An option of [sedx](/docs/v1.1/tools/sedx).

## Usage

```bash
sedx -n {script-only-if-no-other-script} [input-file]...
sedx --quiet {script-only-if-no-other-script} [input-file]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-n` | `--quiet` | none |  | suppress automatic printing of pattern space |

## Examples

### Print only lines 10 to 20 of a log

```bash tab="bash" tab-group="shell"
sedx -n '10,20p' app.log
```

```powershell tab="PowerShell" tab-group="shell"
sedx -n '10,20p' app.log
```

### Show the block between two markers in a file

```bash tab="bash" tab-group="shell"
sedx -n '/BEGIN CERTIFICATE/,/END CERTIFICATE/p' bundle.pem
```

```powershell tab="PowerShell" tab-group="shell"
sedx -n '/BEGIN CERTIFICATE/,/END CERTIFICATE/p' bundle.pem
```

## Help in the terminal

```bash
gnux help sedx --quiet
```
