---
title: "-s, --separate"
description: "Consider files as separate rather than as a single continuous long stream."
---

An option of [sedx](/docs/v1.1/tools/sedx).

## Usage

```bash
sedx -s {script-only-if-no-other-script} [input-file]...
sedx --separate {script-only-if-no-other-script} [input-file]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-s` | `--separate` | none |  | consider files as separate rather than as a single continuous long stream |

## Help in the terminal

```bash
gnux help sedx --separate
```
