---
title: "-L, --dereference-all"
description: "With -R, traverse every symbolic link to a directory encountered."
---

An option of [chgrpx](/docs/v1.1/tools/chgrpx).

## Usage

```bash
chgrpx -L GROUP FILE...
chgrpx --dereference-all GROUP FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-L` | `--dereference-all` | none |  | with `-R`, traverse every symbolic `link` to a directory encountered |

## Examples

### Follow symbolic links met while recursing

```bash tab="bash" tab-group="shell"
chgrpx -R -L developers project/
```

```powershell tab="PowerShell" tab-group="shell"
chgrpx -R -L developers project\
```

## Help in the terminal

```bash
gnux help chgrpx --dereference-all
```
