---
title: "-h, --no-dereference"
description: "Affect symbolic links instead of any referenced file."
---

An option of [chgrpx](/docs/v1.1/tools/chgrpx).

## Usage

```bash
chgrpx -h GROUP FILE...
chgrpx --no-dereference GROUP FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-h` | `--no-dereference` | none |  | affect symbolic links instead of any referenced file |

## Examples

### Change a symbolic link itself

```bash tab="bash" tab-group="shell"
chgrpx -h staff link
```

```powershell tab="PowerShell" tab-group="shell"
chgrpx -h staff link
```

## Help in the terminal

```bash
gnux help chgrpx --no-dereference
```
