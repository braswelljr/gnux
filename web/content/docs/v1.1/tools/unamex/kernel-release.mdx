---
title: "-r, --kernel-release"
description: "Print the kernel release."
---

An option of [unamex](/docs/v1.1/tools/unamex).

## Usage

```bash
unamex -r
unamex --kernel-release
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-r` | `--kernel-release` | none |  | print the kernel release |

## Examples

### Print the kernel release

```bash tab="bash" tab-group="shell"
unamex -r
```

```powershell tab="PowerShell" tab-group="shell"
unamex -r
```

### Print the kernel name and release

```bash tab="bash" tab-group="shell"
unamex -sr
```

```powershell tab="PowerShell" tab-group="shell"
unamex -sr
```

## Help in the terminal

```bash
gnux help unamex --kernel-release
```
