---
title: "-n, --nodename"
description: "Print the network node hostname."
---

An option of [unamex](/docs/v1.1/tools/unamex).

## Usage

```bash
unamex -n
unamex --nodename
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-n` | `--nodename` | none |  | print the network node `hostname` |

## Examples

### Print the host name

```bash tab="bash" tab-group="shell"
unamex -n
```

```powershell tab="PowerShell" tab-group="shell"
unamex -n
```

## Help in the terminal

```bash
gnux help unamex --nodename
```
