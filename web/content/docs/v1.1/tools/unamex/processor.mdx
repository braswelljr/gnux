An option of [unamex](/docs/v1.1/tools/unamex).

## Usage

```bash
unamex -p
unamex --processor
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-p` | `--processor` | none |  | print the processor type (non-portable) |

## Help in the terminal

```bash
gnux help unamex --processor
```
