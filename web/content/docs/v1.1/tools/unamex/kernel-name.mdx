---
title: "-s, --kernel-name"
description: "Print the kernel name."
---

An option of [unamex](/docs/v1.1/tools/unamex).

## Usage

```bash
unamex -s
unamex --kernel-name
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-s` | `--kernel-name` | none |  | print the kernel name |

## Examples

### Print the kernel name and release

```bash tab="bash" tab-group="shell"
unamex -sr
```

```powershell tab="PowerShell" tab-group="shell"
unamex -sr
```

## Help in the terminal

```bash
gnux help unamex --kernel-name
```
