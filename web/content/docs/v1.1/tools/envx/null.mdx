---
title: "-0, --null"
description: "End each output line with NUL, not newline."
---

An option of [envx](/docs/v1.1/tools/envx).

## Usage

```bash
envx -0 [-] [NAME=VALUE]... [COMMAND [ARG]...]
envx --null [-] [NAME=VALUE]... [COMMAND [ARG]...]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-0` | `--null` | none |  | end each output line with NUL, not newline |

## Examples

### Print the environment NUL-separated, with the NULs made visible

```bash tab="bash" tab-group="shell"
envx -0 -i A=1 B=2 | catx -v
```

```powershell tab="PowerShell" tab-group="shell"
envx -0 -i A=1 B=2 | catx -v
```

## Help in the terminal

```bash
gnux help envx --null
```
