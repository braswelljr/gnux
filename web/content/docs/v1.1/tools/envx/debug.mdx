---
title: "-v, --debug"
description: "Print verbose information for each processing step."
---

An option of [envx](/docs/v1.1/tools/envx).

## Usage

```bash
envx -v [-] [NAME=VALUE]... [COMMAND [ARG]...]
envx --debug [-] [NAME=VALUE]... [COMMAND [ARG]...]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-v` | `--debug` | none |  | print verbose information for each processing step |

## Examples

### Trace each step envx takes before running the command

```bash tab="bash" tab-group="shell"
envx -v -C build pwdx
```

```powershell tab="PowerShell" tab-group="shell"
envx -v -C build pwdx
```

## Help in the terminal

```bash
gnux help envx --debug
```
