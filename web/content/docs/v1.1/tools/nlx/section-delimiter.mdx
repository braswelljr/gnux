An option of [nlx](/docs/v1.1/tools/nlx).

## Usage

```bash
nlx -d CC [FILE]...
nlx --section-delimiter=CC [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-d` | `--section-delimiter` | `CC` |  | use CC for logical page delimiters (default \:) |

## Help in the terminal

```bash
gnux help nlx --section-delimiter
```
