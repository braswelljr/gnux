An option of [nlx](/docs/v1.1/tools/nlx).

## Usage

```bash
nlx -l NUMBER [FILE]...
nlx --join-blank-lines=NUMBER [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-l` | `--join-blank-lines` | `NUMBER` |  | group of NUMBER empty lines counted as one (default 1) |

## Examples

### Collapse runs of empty lines so only every second one gets a number

```bash tab="bash" tab-group="shell"
nlx -b a -l 2 poem.txt
```

```powershell tab="PowerShell" tab-group="shell"
nlx -b a -l 2 poem.txt
```
