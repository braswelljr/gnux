---
title: "-w, --number-width"
description: "Use NUMBER columns for line numbers (default 6)."
---

An option of [nlx](/docs/v1.1/tools/nlx).

## Usage

```bash
nlx -w NUMBER [FILE]...
nlx --number-width=NUMBER [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-w` | `--number-width` | `NUMBER` |  | use NUMBER columns for line numbers (default 6) |

## Examples

### Turn a list of steps into a numbered checklist

```bash tab="bash" tab-group="shell"
nlx -w 2 -s '. ' steps.txt
```

```powershell tab="PowerShell" tab-group="shell"
nlx -w 2 -s '. ' steps.txt
```

```text title="Output"
 1. Back up the database
 2. Stop the service
 3. Run the migration
```

### Give records fixed-width, zero-padded IDs

```bash tab="bash" tab-group="shell"
nlx -n rz -w 5 -s , names.txt > names.csv
```

```powershell tab="PowerShell" tab-group="shell"
nlx -n rz -w 5 -s , names.txt > names.csv
```

```text title="Output"
00001,Ada
00002,Grace
00003,Linus
```

### Number lines left-aligned with no padding before the text

```bash tab="bash" tab-group="shell"
nlx -n ln -w 1 -s ' ' todo.txt
```

```powershell tab="PowerShell" tab-group="shell"
nlx -n ln -w 1 -s ' ' todo.txt
```

### Number lines in the portable gnux shell

```bash tab="bash" tab-group="shell"
gnux shell -c 'sortx names.txt | uniqx | nlx -w 3'
```

```powershell tab="PowerShell" tab-group="shell"
gnux shell -c 'sortx names.txt | uniqx | nlx -w 3'
```

## Help in the terminal

```bash
gnux help nlx --number-width
```
