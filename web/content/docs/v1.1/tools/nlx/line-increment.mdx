An option of [nlx](/docs/v1.1/tools/nlx).

## Usage

```bash
nlx -i string [FILE]...
nlx --line-increment=string [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-i` | `--line-increment` | `string` |  | line number increment at each line (default 1) |

## Examples

### Number in steps of 10, leaving room to insert lines later

```bash tab="bash" tab-group="shell"
nlx -i 10 -v 10 program.bas
```

```powershell tab="PowerShell" tab-group="shell"
nlx -i 10 -v 10 program.bas
```

## Help in the terminal

```bash
gnux help nlx --line-increment
```
