---
title: "-m, --chars"
description: "Print the character counts."
---

An option of [wcx](/docs/v1.1/tools/wcx).

## Usage

```bash
wcx -m [FILE]...
wcx --chars [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-m` | `--chars` | none |  | print the character counts |

## Examples

### Count characters rather than bytes

```bash tab="bash" tab-group="shell"
wcx -m unicode.txt
```

```powershell tab="PowerShell" tab-group="shell"
wcx -m unicode.txt
```

## Help in the terminal

```bash
gnux help wcx --chars
```
