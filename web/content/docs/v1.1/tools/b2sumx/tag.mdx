title: "--tag"
description: "Create a BSD-style checksum."
---

An option of [b2sumx](/docs/v1.1/tools/b2sumx).

## Usage

```bash
b2sumx --tag [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--tag` | none |  | create a BSD-style checksum |

## Examples

### Write lines that name the algorithm, so a mixed list can be checked with cksumx -c

```bash tab="bash" tab-group="shell"
b2sumx --tag release.tar.gz >> CHECKSUMS
```

```powershell tab="PowerShell" tab-group="shell"
b2sumx --tag release.zip >> CHECKSUMS
```
