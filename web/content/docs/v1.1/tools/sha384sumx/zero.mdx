An option of [sha384sumx](/docs/v1.1/tools/sha384sumx).

## Usage

```bash
sha384sumx -z [FILE]...
sha384sumx --zero [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-z` | `--zero` | none |  | end each output line with NUL, not newline, and disable file name escaping |
