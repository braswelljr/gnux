title: "-p, --base-dir"

---

An option of [mktempx](/docs/v1.1/tools/mktempx).

## Usage

```bash
mktempx -p DIR [TEMPLATE]
mktempx --base-dir=DIR [TEMPLATE]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-p` | `--base-dir` | `DIR` |  | use DIR as the directory, like `--tmpdir`=DIR |

## Examples

### Create it under a directory of your choice

```bash tab="bash" tab-group="shell"
mktempx -p out report.XXXX
```

```powershell tab="PowerShell" tab-group="shell"
mktempx -p out report.XXXX
```

### Fail quietly and handle it yourself

```bash tab="bash" tab-group="shell"
mktempx -q -p /nonexistent || echox 'no temp dir'
```

```powershell tab="PowerShell" tab-group="shell"
mktempx -q -p C:\nonexistent; if ($LASTEXITCODE -ne 0) { echox 'no temp dir' }
```
