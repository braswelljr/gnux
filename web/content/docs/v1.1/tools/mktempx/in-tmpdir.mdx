An option of [mktempx](/docs/v1.1/tools/mktempx).

## Usage

```bash
mktempx -t [TEMPLATE]
mktempx --in-tmpdir [TEMPLATE]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-t` | `--in-tmpdir` | none |  | interpret TEMPLATE as a single file name component, relative to $TMPDIR, else DIR (`-p`), else the temporary directory (deprecated) |

## Examples

### Use the deprecated -t form, relative to $TMPDIR

```bash tab="bash" tab-group="shell"
mktempx -t job.XXXXXX
```

```powershell tab="PowerShell" tab-group="shell"
mktempx -t job.XXXXXX
```
