---
title: "--suffix"
description: "Append SUFF to TEMPLATE; SUFF must not contain a slash."
---

An option of [mktempx](/docs/v1.1/tools/mktempx).

## Usage

```bash
mktempx --suffix=SUFF [TEMPLATE]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--suffix` | `SUFF` |  | append SUFF to TEMPLATE; SUFF must not contain a slash |

## Examples

### Give the file an extension

```bash tab="bash" tab-group="shell"
mktempx --suffix=.json data.XXXXXX
```

```powershell tab="PowerShell" tab-group="shell"
mktempx --suffix=.json data.XXXXXX
```

gnux help mktempx --suffix
