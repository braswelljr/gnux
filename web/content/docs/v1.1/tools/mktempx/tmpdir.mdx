An option of [mktempx](/docs/v1.1/tools/mktempx).

## Usage

```bash
mktempx --tmpdir[=DIR] [TEMPLATE]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
|  | `--tmpdir` | `DIR` (optional) |  | interpret TEMPLATE relative to DIR; if DIR is not given, use $TMPDIR if set, else the temporary directory |

## Examples

### Create it under the temporary directory instead

```bash tab="bash" tab-group="shell"
mktempx --tmpdir build.XXXXXX
```

```powershell tab="PowerShell" tab-group="shell"
mktempx --tmpdir build.XXXXXX
```

gnux help mktempx --tmpdir
