An option of [mktempx](/docs/v1.1/tools/mktempx).

## Usage

```bash
mktempx -u [TEMPLATE]
mktempx --dry-run [TEMPLATE]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-u` | `--dry-run` | none |  | do not create anything; merely print a name (unsafe) |

## Examples

### Print an unused name without creating anything

```bash tab="bash" tab-group="shell"
mktempx -u
```

```powershell tab="PowerShell" tab-group="shell"
mktempx -u
```

## Help in the terminal

```bash
gnux help mktempx --dry-run
```
