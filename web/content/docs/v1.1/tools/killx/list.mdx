---
title: "-l, --list"
description: "List signal names, or convert signal names to/from numbers."
---

An option of [killx](/docs/v1.1/tools/killx).

## Usage

```bash
killx -l [-s SIGNAL | -SIGNAL] PID...
killx --list [-s SIGNAL | -SIGNAL] PID...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-l` | `--list` | none |  | list signal names, or convert signal names to/from numbers |

## Examples

### List the signal names

```bash tab="bash" tab-group="shell"
killx -l
```

```powershell tab="PowerShell" tab-group="shell"
killx -l
```

### Find which signal ended a command that exited with 137

```bash tab="bash" tab-group="shell"
killx -l 137
```

```powershell tab="PowerShell" tab-group="shell"
killx -l 137
```

### Convert a signal name to its number

```bash tab="bash" tab-group="shell"
killx -l TERM
```

```powershell tab="PowerShell" tab-group="shell"
killx -l TERM
```

## Help in the terminal

```bash
gnux help killx --list
```
