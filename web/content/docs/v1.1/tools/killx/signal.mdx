An option of [killx](/docs/v1.1/tools/killx).

## Usage

```bash
killx -s string [-s SIGNAL | -SIGNAL] PID...
killx --signal=string [-s SIGNAL | -SIGNAL] PID...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-s` | `--signal` | `string` |  | specify the name or number of the signal to be sent |

## Examples

### Name the signal

```bash tab="bash" tab-group="shell"
killx -s KILL 1234
```

```powershell tab="PowerShell" tab-group="shell"
killx -s KILL 1234
```

## Help in the terminal

```bash
gnux help killx --signal
```
