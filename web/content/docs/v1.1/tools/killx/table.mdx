---
title: "-L, --table"
description: "Print a table of signal information (also -t)."
---

An option of [killx](/docs/v1.1/tools/killx).

## Usage

```bash
killx -L [-s SIGNAL | -SIGNAL] PID...
killx --table [-s SIGNAL | -SIGNAL] PID...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-L` | `--table` | none |  | print a table of signal information (also `-t`) |

## Examples

### Show the table of signals

```bash tab="bash" tab-group="shell"
killx -L
```

```powershell tab="PowerShell" tab-group="shell"
killx -L
```

## Help in the terminal

```bash
gnux help killx --table
```
