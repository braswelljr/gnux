title: "-z, --zero-terminated"
description: "Line delimiter is NUL, not newline."

An option of [cutx](/docs/v1.1/tools/cutx).

## Usage

```bash
cutx -z OPTION... [FILE]...
cutx --zero-terminated OPTION... [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-z` | `--zero-terminated` | none |  | line delimiter is NUL, not newline |

## Examples

### Process NUL-separated records

```bash tab="bash" tab-group="shell"
cutx -z -d / -f 1 paths.lst
```

```powershell tab="PowerShell" tab-group="shell"
cutx -z -d / -f 1 paths.lst
```

gnux help cutx --zero-terminated
