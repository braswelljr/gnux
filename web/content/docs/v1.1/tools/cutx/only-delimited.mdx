---
title: "-s, --only-delimited"
description: "Do not print lines not containing delimiters."
---

An option of [cutx](/docs/v1.1/tools/cutx).

## Usage

```bash
cutx -s OPTION... [FILE]...
cutx --only-delimited OPTION... [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-s` | `--only-delimited` | none |  | do not print lines not containing delimiters |

## Examples

### Skip lines that contain no delimiter, such as comments

```bash tab="bash" tab-group="shell"
cutx -s -d = -f 2 settings.ini
```

```powershell tab="PowerShell" tab-group="shell"
cutx -s -d = -f 2 settings.ini
```

gnux help cutx --only-delimited
