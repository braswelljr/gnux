---
title: "-a, --all"
description: "Write counts for all files, not just directories."
---

An option of [dux](/docs/v1.1/tools/dux).

## Usage

```bash
dux -a [FILE]...
dux --all [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-a` | `--all` | none |  | write counts for all files, not just directories |

## Examples

### Find files over 100 MB to clean up

```bash tab="bash" tab-group="shell"
dux -a -t 100M -h ~/Downloads
```

```powershell tab="PowerShell" tab-group="shell"
dux -a -t 100M -h $HOME\Downloads
```

## Help in the terminal

