---
title: "-L, --dereference"
description: "Dereference all symbolic links."
---

An option of [dux](/docs/v1.1/tools/dux).

## Usage

```bash
dux -L [FILE]...
dux --dereference [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-L` | `--dereference` | none |  | dereference all symbolic links |

## Help in the terminal

```bash
gnux help dux --dereference
```
