---
title: "-X, --exclude-from"
description: "Exclude files that match any pattern in FILE."
---

An option of [dux](/docs/v1.1/tools/dux).

## Usage

```bash
dux -X FILE [FILE]...
dux --exclude-from=FILE [FILE]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-X` | `--exclude-from` | `FILE` |  | exclude files that match any pattern in FILE |

## Help in the terminal

```bash
gnux help dux --exclude-from
```
