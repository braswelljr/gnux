---
title: "-s, --signal"
description: "Specify the SIGNAL to be sent on timeout; SIGNAL may be a name like 'HUP' or a number."
---

An option of [timeoutx](/docs/v1.1/tools/timeoutx).

## Usage

```bash
timeoutx -s SIGNAL [OPTION] DURATION COMMAND [ARG]...
timeoutx --signal=SIGNAL [OPTION] DURATION COMMAND [ARG]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-s` | `--signal` | `SIGNAL` |  | specify the SIGNAL to be sent on `timeout`; SIGNAL may be a name like 'HUP' or a number |

## Examples

### Send INT, like Ctrl-C, instead of TERM

```bash tab="bash" tab-group="shell"
timeoutx -s INT 1h ./crawler
```

```powershell tab="PowerShell" tab-group="shell"
timeoutx -s INT 1h .\crawler.exe
```

## Help in the terminal

gnux help timeoutx --signal
