---
title: "-f, --silent"
description: "Suppress most error messages."
---

An option of [chownx](/docs/v1.1/tools/chownx).

## Usage

```bash
chownx -f [OWNER][:[GROUP]] FILE...
chownx --silent [OWNER][:[GROUP]] FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-f` | `--silent` | none |  | suppress most error messages |

## Help in the terminal

```bash
gnux help chownx --silent
```
