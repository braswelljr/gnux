---
title: "-H, --dereference-args"
description: "With -R, follow symbolic links to directories given on the command line."
---

An option of [chownx](/docs/v1.1/tools/chownx).

## Usage

```bash
chownx -H [OWNER][:[GROUP]] FILE...
chownx --dereference-args [OWNER][:[GROUP]] FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-H` | `--dereference-args` | none |  | with `-R`, follow symbolic links to directories given on the command line |

## Help in the terminal

```bash
gnux help chownx --dereference-args
```
