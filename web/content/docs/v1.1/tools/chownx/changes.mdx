---
title: "-c, --changes"
description: "Like verbose but report only when a change is made."
---

An option of [chownx](/docs/v1.1/tools/chownx).

## Usage

```bash
chownx -c [OWNER][:[GROUP]] FILE...
chownx --changes [OWNER][:[GROUP]] FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-c` | `--changes` | none |  | like verbose but report only when a change is made |

## Help in the terminal

```bash
gnux help chownx --changes
```
