---
title: "-L, --dereference-all"
description: "With -R, traverse every symbolic link to a directory encountered."
---

An option of [chownx](/docs/v1.1/tools/chownx).

## Usage

```bash
chownx -L [OWNER][:[GROUP]] FILE...
chownx --dereference-all [OWNER][:[GROUP]] FILE...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-L` | `--dereference-all` | none |  | with `-R`, traverse every symbolic `link` to a directory encountered |

## Help in the terminal

```bash
gnux help chownx --dereference-all
```
