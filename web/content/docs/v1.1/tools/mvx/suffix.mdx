---
title: "-S, --suffix"
description: "Override the usual backup suffix, '~', with SUFFIX."
---

An option of [mvx](/docs/v1.1/tools/mvx).

## Usage

```bash
mvx -S SUFFIX SOURCE... DIRECTORY
mvx --suffix=SUFFIX SOURCE... DIRECTORY
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-S` | `--suffix` | `SUFFIX` |  | override the usual backup suffix, '~', with SUFFIX |

## Examples

### Replace a log with a new one, keeping the old one as server.log.old

```bash tab="bash" tab-group="shell"
mvx -S .old server.log.new server.log
```

```powershell tab="PowerShell" tab-group="shell"
mvx -S .old server.log.new server.log
```
