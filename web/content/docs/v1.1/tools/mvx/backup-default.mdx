An option of [mvx](/docs/v1.1/tools/mvx).

```bash

mvx --backup-default SOURCE... DIRECTORY
```

| --- | --- | --- | --- | --- |
| `-b` | `--backup-default` | none |  | like `--backup` but does not accept an argument |
