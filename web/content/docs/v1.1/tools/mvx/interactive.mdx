title: "-i, --interactive"

---

An option of [mvx](/docs/v1.1/tools/mvx).

## Usage

```bash
mvx -i SOURCE... DIRECTORY
mvx --interactive SOURCE... DIRECTORY
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-i` | `--interactive` | none |  | prompt before overwrite |

## Examples

### Ask before replacing an existing file

```bash tab="bash" tab-group="shell"
mvx -i new-config.yml config.yml
```

```powershell tab="PowerShell" tab-group="shell"
mvx -i new-config.yml config.yml
```

## Help in the terminal

```bash
gnux help mvx --interactive
```
