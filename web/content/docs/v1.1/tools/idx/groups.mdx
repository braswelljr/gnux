---
title: "-G, --groups"
description: "Print all group IDs."
---

An option of [idx](/docs/v1.1/tools/idx).

## Usage

```bash
idx -G [USER]...
idx --groups [USER]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-G` | `--groups` | none |  | print all group IDs |

## Examples

### List your groups by name

```bash tab="bash" tab-group="shell"
idx -Gn
```

```powershell tab="PowerShell" tab-group="shell"
idx -Gn
```

### Check membership of a group

```bash tab="bash" tab-group="shell"
idx -Gn | trx ' ' '\n' | grep -qx docker && echox member
```

```powershell tab="PowerShell" tab-group="shell"
if ((idx -Gn) -split ' ' -contains 'docker') { 'member' }
```

### Print IDs in the portable gnux shell

```bash tab="bash" tab-group="shell"
gnux shell -c 'idx -un && idx -Gn'
```

```powershell tab="PowerShell" tab-group="shell"
gnux shell -c 'idx -un && idx -Gn'
```

## Help in the terminal

```bash
gnux help idx --groups
```
