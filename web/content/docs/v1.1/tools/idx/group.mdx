---
title: "-g, --group"
description: "Print only the effective group ID."
---

An option of [idx](/docs/v1.1/tools/idx).

## Usage

```bash
idx -g [USER]...
idx --group [USER]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-g` | `--group` | none |  | print only the effective group ID |

## Examples

### Print the effective group ID

```bash tab="bash" tab-group="shell"
idx -g
```

```powershell tab="PowerShell" tab-group="shell"
idx -g
```

## Help in the terminal

```bash
gnux help idx --group
```
