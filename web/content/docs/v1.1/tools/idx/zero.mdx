title: "-z, --zero"
description: "Delimit entries with NUL characters, not whitespace; not permitted in default format."
---

An option of [idx](/docs/v1.1/tools/idx).

## Usage

```bash
idx -z [USER]...
idx --zero [USER]...
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-z` | `--zero` | none |  | delimit entries with NUL characters, not whitespace; not permitted in default format |

## Help in the terminal

```bash
gnux help idx --zero
```
