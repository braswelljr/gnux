An option of [xargsx](/docs/v1.1/tools/xargsx).

## Usage

```bash
xargsx -d CHARACTER [COMMAND [INITIAL-ARGUMENT]...]
xargsx --delimiter=CHARACTER [COMMAND [INITIAL-ARGUMENT]...]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-d` | `--delimiter` | `CHARACTER` |  | items in the input are separated by CHARACTER, not by whitespace; disables quote and backslash processing and logical EOF processing |

## Examples

### Treat each line as one item, blanks and quotes included

```bash tab="bash" tab-group="shell"
xargsx -d '\n' -a names.txt touchx
```

```powershell tab="PowerShell" tab-group="shell"
xargsx -d '\n' -a names.txt touchx
```
