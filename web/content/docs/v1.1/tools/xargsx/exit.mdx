---
title: "-x, --exit"
description: "Exit if the size (see -s) is exceeded."

An option of [xargsx](/docs/v1.1/tools/xargsx).

## Usage

```bash
xargsx -x [COMMAND [INITIAL-ARGUMENT]...]
xargsx --exit [COMMAND [INITIAL-ARGUMENT]...]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-x` | `--exit` | none |  | exit if the size (see `-s`) is exceeded |

## Help in the terminal

```bash
gnux help xargsx --exit
```
