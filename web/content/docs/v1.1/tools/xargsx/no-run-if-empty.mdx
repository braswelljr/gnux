An option of [xargsx](/docs/v1.1/tools/xargsx).

## Usage

```bash
xargsx -r [COMMAND [INITIAL-ARGUMENT]...]
xargsx --no-run-if-empty [COMMAND [INITIAL-ARGUMENT]...]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-r` | `--no-run-if-empty` | none |  | if there are no arguments, then do not run COMMAND; if this option is not given, COMMAND will be run at least once |

## Examples

### Do nothing at all when the search finds no file

```bash tab="bash" tab-group="shell"
findx . -name '*.orig' -print0 | xargsx -0 -r rmx
```

```powershell tab="PowerShell" tab-group="shell"
findx . -name '*.orig' -print0 | xargsx -0 -r rmx
```

### Show the size limits in effect without running anything

```bash tab="bash" tab-group="shell"
xargsx --show-limits -r < /dev/null
```

```powershell tab="PowerShell" tab-group="shell"
'' | xargsx --show-limits -r
```

## Help in the terminal

```bash
gnux help xargsx --no-run-if-empty
```
