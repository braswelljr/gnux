---
title: "-a, --arg-file"
description: "Read arguments from FILE, not standard input."
---

An option of [xargsx](/docs/v1.1/tools/xargsx).

## Usage

```bash
xargsx -a FILE [COMMAND [INITIAL-ARGUMENT]...]
xargsx --arg-file=FILE [COMMAND [INITIAL-ARGUMENT]...]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-a` | `--arg-file` | `FILE` |  | read arguments from FILE, not standard input |

## Examples

### Treat each line as one item, blanks and quotes included

```bash tab="bash" tab-group="shell"
xargsx -d '\n' -a names.txt touchx
```

```powershell tab="PowerShell" tab-group="shell"
xargsx -d '\n' -a names.txt touchx
```

## Help in the terminal

```bash
gnux help xargsx --arg-file
```
