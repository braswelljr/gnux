An option of [xargsx](/docs/v1.1/tools/xargsx).

## Usage

```bash
xargsx -i [COMMAND [INITIAL-ARGUMENT]...]
xargsx --replace[=R] [COMMAND [INITIAL-ARGUMENT]...]
```

## Details

| Short | Long | Value | Default | Meaning |
| --- | --- | --- | --- | --- |
| `-i` | `--replace` | `R` (optional) |  | replace R in INITIAL-ARGS with names read from standard input, `split` at newlines; if R is unspecified, assume \{\} |

## Help in the terminal

```bash
gnux help xargsx --replace
```
