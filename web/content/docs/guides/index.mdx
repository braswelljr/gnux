---
title: "Guides"
description: "Task-oriented guides for gnux, a portable, GNU-compatible implementation of the GNU core utilities' interface in Go: one statically linked binary that carries 22 tools, a Go library with an importable engine for every tool, and a portable shell that runs the same script on Linux, macOS and Windows. The reference pages describe each tool's flags one by one; these guides show how to put the tools to work, with hundreds of runnable examples, complete scripts, CI configurations and Go programs. The gnux command lines and shell scripts were run against a real gnux build, the outputs shown are captured from it, and every Go program was compiled and run."
---

## Pick a guide

| Guide | For | What you get |
|-------|-----|--------------|
| [Getting started](/docs/guides/getting-started) | Everyone | Every way to install, linking the tool names, the two invocation forms, GNU-name aliases, `--help`, `--version` and `--list` |
| [Cookbook](/docs/guides/cookbook) | Command-line users | Over 90 recipes grouped by task: inspecting files, copying and linking, safe deletion, backups, logs, paths, environment, timestamps, generated data and pipelines |
| [Portable scripting](/docs/guides/portable-scripting) | Script and build authors | The `gnux shell` language in depth and four complete scripts (scaffold, clean, log rotation, release staging) that behave identically on every platform |
| [Windows and PowerShell](/docs/guides/windows-and-powershell) | Windows users | Installing on Windows, links versus copies of `gnux.exe`, PowerShell's colliding aliases, quoting, and what degrades on NTFS |
| [CI and containers](/docs/guides/ci-and-containers) | CI and DevOps engineers | GitHub Actions, GitLab CI and Docker recipes, and one `gnux shell` script as a cross-OS build step |
| [Go library](/docs/guides/go-library) | Go developers | Embedding the engines: options, streams, captured output, injected prompts and clocks, errors, `cmd.RunTool`, `cmd.NewShell`, and seventeen complete programs |
| [Adoption](/docs/guides/adoption) | Users of GNU coreutils | All 22 tools side by side with their GNU counterparts, supported flags, every documented deviation and what is not implemented yet |
| [Troubleshooting](/docs/guides/troubleshooting) | Everyone | What each error and exit status means, prompts you did not expect, refusals, and a FAQ |
